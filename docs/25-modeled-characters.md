# 箱からの造形で人物を作り直す（試作 3.0、2026-10-30）

## オーナーの評価と判断

> 商業ゲームと比べて安っぽすぎる。最高の造形を本気で作ってほしい。動きもカクカクする時があって不自然。もっとダイナミックに。敵と主人公の造形がカッコ悪くて不自然すぎる。抜本的に直してほしい。アセットは本当に使えるものはないのか。アセットそのものを作れないのか。

### 使えるアセットはあるか（調べた事実、2026-10-30）

この開発環境から外へつながるのは GitHub と npm だけ。アセットの販売所や配布所（Asset Store、Sketchfab、Mixamo、BOOTH など）には接続できない。届く範囲で見つかった人物モデルは、three.js の見本（兵士、ロボット）、pixiv の VRM 見本（アニメの少女）、Kenney の三頭身のキャラクター。どれも侍でも刀の動きでもなかった。

## 作り方を変えた理由

試作 2.x までの人物は、形を粘土のように溶け合わせ、格子から削り出していた（符号付き距離と Surface Nets）。この方法には根本の限界がある。

- どれだけ細かくしても、形は膨らんだ、縁のぼやけたものになる
- 布の縁や折り目のような、くっきりした線が作れない
- 頂点の並びに意図がないので、曲げたときに崩れやすい
- 頂点が多く重い（体だけで約5万頂点、ページは約6.5MB）

## 新しい作り方（tools/model_characters.js）

商業ゲームの人物と同じ造りにした。

1. **粗い網（ケージ）を、意図した線の流れで組む**。体の部品は、断面の輪をつないで作る（ロフト）。拳や足は角の丸い箱
2. **服は、体とは別の厚みのある布の殻**。前の開き、袖口、裾には縁ができ、内側は裏地の色になる
3. **Catmull-Clark で2回細分して滑らかにする**。布の縁と袴のひだの山は「折り目（クリース）」として指定し、細分してもくっきり残す
4. **皮の重みは、輪を作るときに直接付ける**（高さで腰→腹→胸、腕の長さで二の腕→前腕、袴は腰から腿・脛へなだらかに）

頭は、細かい格子（4.2mm）の焼き出しを使う（tools/bake_characters.js）。

### 部品

| 部品 | 作り方 |
|---|---|
| 胴の肌、首 | 断面の輪をつないだ筒 |
| 着物（主人公） | 開いた弧の輪をつないだ布の殻。前は細く重なり、胸の上だけV字に開く。開きの縁に沿って、厚く折り返した襟が首の後ろへ回る |
| 羽織（主人公） | 肩から裾まで、開いた弧の布の殻。前は広く開き、内側は深紅。背と脇にひだ。裾は少し広がる |
| 羽織の袖 | 角の丸い四角の断面の布の殻。腕から下へ垂れ（袖の奥ほど下がる）、袖口は深紅 |
| 籠手（主人公） | 帯を巻いた筋のある筒 |
| 胴（相手） | 黒漆の筒。板の継ぎ目は、支えの輪を二重にした細い溝 |
| 袴 | 二本の脚として作る。腰の上では左右の内側が中心線で平らになって合わさり、一枚に見える。股から下は分かれて裾へ広がる。ひだは10本で、山を折り目として残す |
| 拳、足袋、草履 | 角の丸い箱を細分 |

## 動き

- 足が大きく離れたとき、瞬間移動していた（カクッと見える原因）。速い一歩（75ms）で追うようにし、一歩の途中でも動く体へ行き先を追い続ける。一歩の高さは、離れた距離に合わせる

## 結果

| | 試作 2.5（粘土） | 試作 3.0（箱からの造形） |
|---|---|---|
| 主人公の体 | 約4.8万頂点 | 約4.7万頂点（2回細分後） |
| 縁 | ぼやける | 布の縁、袖口、裾、ひだの山がくっきり |
| 袴 | 筒に近い。ひだは浅い | 腰で合わさり、股から分かれる。ひだの山が立つ |

## 残る弱点（率直に）

- 人の手で作ったモデルと手付けの動きには届かない（オーナーに伝えたうえでの選択）
- 手は拳の形の箱で、指はない
- 顔は前回の焼き出しのまま
- 面はまだ重い（袴の内側の面も全体に作っているため）。iPhone での重さは未確認
