# 設計の柱 v0

このゲームの憲法。仕様や表現で迷ったときは、ここに戻って判断する。
柱どうしがぶつかったときは、番号の小さい方を優先する。

## デザインの方向性（出発点）

オーナーが置いた「洗練の先にあるもの」のイメージ。ゲームの題材ではなく、目指す体験の質。

- 落ち着いた川の畔で、一人でコーヒーを飲む
- 真夜中の高速道路のサービスエリアで、白い息を吐きながらホットココアを飲む
- 早朝の温泉街を、浴衣で探索する

共通点：ひとりで静か。誰にも急かされない。寒さと温かさの対比。日常の外の時間。小さなものに集中している。何も起きない時間が心地よい。

今のスマートフォンが「わちゃわちゃした繁華街」なら、その反対側にあるもの。

**洗練は飾りではない。** 文字の説明をしないことは①学習を、中断させないことは②集中を、外から報酬を与えないことは③内から湧く動機を守る。洗練は面白さの構造から見ても必要な条件である。

## 柱1：世界には少数の一貫した法則があり、それは観察だけで見つけられる

**意味**
世界は気まぐれではなく、法則に従って動く。プレイヤーはその法則を、説明を読むのではなく、見て、試して見つける。

**なぜ必要か**
- ①学習：法則を言葉で教えると、「わかった！」の瞬間を奪う。
- ①学習：法則に例外や気まぐれがあると、パターンを学ぶこと自体が成り立たない。
- ③有能感：見つけた法則が裏切られないから、自分の理解を信じられる。

**するべきこと**
- 法則は物理法則のように一貫させる。例外を作るなら、例外にも法則がある。
- 最初の法則は、操作して数十秒以内に気づけるようにする。
- 法則に気づくための「観察できる手がかり」を必ず世界の中に置く。

**してはいけないこと**
- 文字のチュートリアルで法則を説明する。
- 作者の思いつきの仕掛け（観察から推測できない答え）を置く。「作者の意図当てクイズ」にしない。

**判定テスト**
- 説明文をすべて消しても、法則に気づけるか。
- 正解を知った人が「それは理不尽だ」ではなく「そうか、見えていたのに」と感じるか。

**参考**：SEKIROの敵の行動は一貫しているので、死ぬたびに学べる。

## 柱2：深さは法則の数ではなく、組み合わせから生む

**意味**
法則を増やして複雑にするのではなく、少ない法則が組み合わさることで、新しい状況と新しい発見が生まれる。

**なぜ必要か**
- ①学習：パターンは学び尽くした瞬間に退屈になる。1つの法則を理解したころに、組み合わせという次の層が現れることで、学びが続く。
- 洗練：表面は単純、中身は深い。

**するべきこと**
- 新しい法則を足す前に、既存の法則の組み合わせで新しい状況を作れないか考える。
- 「わかった！」の3段階を意識する：法則を見つける → 法則で予測が当たる → 法則どうしの組み合わせに気づく。

**してはいけないこと**
- 退屈を防ぐために、新しい要素を足し続ける。

**判定テスト**
- 法則の一覧が1画面に収まるか。それでも何時間も新しい発見があるか。

**参考**：囲碁と将棋。ルールは少ないのに、何百年たっても研究が終わらない。

## 柱3：上達はプレイヤーの頭の中に残る

**意味**
強くなるのはアカウントやキャラクターではなく、プレイヤー自身の理解と読む力。

**なぜ必要か**
- ③有能感：自分が見抜いたから成功した、と思えること。
- 本質的な面白さとそうでないものの境目（[02-fun-analysis.md](02-fun-analysis.md)）。

**するべきこと**
- 上達は数値ではなく体験で示す。以前苦労した状況が、今は一目で読めるようにする。
- 成功の原因が、プレイヤーの判断にあるとわかるようにする。

**してはいけないこと**
- レベル、経験値、課金による強化で、理解がなくても先へ進めるようにする。
- ガチャ、ログインボーナス、期間限定で引き止める。

**判定テスト**
- データを消して最初から遊んでも、上手い人は上手いか。

**参考**：将棋の棋力、ボスの攻略法、市場の見方は、本人の中に残る。

## 柱4：決定は取り消せず、結果はすぐに公正に返る。やり直しは一瞬でできる

**意味**
1回の挑戦の中では、判断に重みがある。結果はすぐに、納得できる形で返る。失敗しても、すぐにもう一度挑める。

**なぜ必要か**
- 取り消せないから、仮説を本気で確かめることになる（Kaggleの1日の提出回数の制限と同じ）。
- ②集中：結果がすぐ返ることがフローの条件。
- 手軽さ：重い決定と、気軽な再挑戦を両立させる。

**するべきこと**
- 決定から数秒以内に結果を見せる。
- 結果は、なぜそうなったかを観察できる形で見せる（次の仮説の材料になる）。
- 失敗から再挑戦までを、待ち時間なしにする。

**してはいけないこと**
- 「元に戻す」ボタンで試行錯誤を無制限にする（決定の重みが消える）。
- 失敗に重い罰（長い待ち時間、進行の喪失）を与える。

**判定テスト**
- 失敗したとき、プレイヤーは「運が悪かった」ではなく「読みが違った」と思うか。
- 失敗した直後に、もう1回やりたくなるか。

## 柱5：時間の主導権はプレイヤーにある。1回の遊びは数分

**意味**
世界がプレイヤーを急かさない。考える時間はプレイヤーのもの。1回の遊びは数分で区切りがつく。

**なぜ必要か**
- デザインの方向性：3つの情景に共通する「誰にも急かされない」。
- 手軽さ：電車の中や寝る前の数分で、満足できる区切りまで遊べる。
- ②集中：自分のペースで考えられることで、難しさと腕前の釣り合いを自分で取れる。

**するべきこと**
- 制限時間で追い立てない。
- 1回の遊びの単位（1つの問題、1つの場面）を数分にする。
- 途中で閉じても、その状態のまま待っている。

**してはいけないこと**
- 反射神経やリアルタイムの精密な操作を要求する。
- 「今やらないと損をする」仕組み。

**判定テスト**
- 遊んでいる途中に話しかけられても、困らないか。

---

## 柱6：中断させず、何も要求しない

**意味**
ゲームの方がプレイヤーを待っている。プレイヤーの集中と時間を奪うものを置かない。

**なぜ必要か**
- ②集中：中断はフローを壊す。
- ③内から湧く動機：外からの要求（通知、ノルマ）は、自分で選んで遊ぶ感覚を壊す。
- デザインの方向性：繁華街の反対側。

**するべきこと**
- 画面に出す要素は、そのとき必要なものだけにする。
- 自分から開きたくなる理由は、ゲームの中身だけにする。

**してはいけないこと**
- 広告、ポップアップ、赤い未読マーク、呼び戻すための通知、毎日ログインのノルマ。
- 長い読み込み待ち。

**判定テスト**
- 1週間開かなかったあとに戻ってきても、気まずさや損失を感じないか。

## 改訂の候補（議論中）

- **理解は層になり、深い法則は浅い法則をまとめる**：ケプラーの法則がニュートンの法則にまとめられたように、プレイヤーの理解が段階的に深まる構造。柱2を拡張するか、独立した柱にするかを検討中。[04-laws-and-understanding.md](04-laws-and-understanding.md) を参照。
