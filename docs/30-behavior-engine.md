# 行動エンジン：課題の分解と取り組み（試作 3.6、2026-10-30）

## オーナーの評価（試作 3.5）

> 吐息が丸いオブジェクトでダサすぎる。動きのダイナミックさがまだできていない。相手の行動パターンを本質的にあと20倍に。かなり単調。居合、回転斬り、弓、いろいろできるはず。動きの大袈裟なダイナミックさと爽快さはまだまだ。一旦は行動側のエンジンについて、本気で課題分解と取り組みを。

## 課題の分解：技を320に増やしても、なぜ単調なのか

試作 3.5 で技は320になったが、オーナーは「かなり単調」と感じた。技の数は単調さの原因ではなかった。

| # | 課題 | なぜ単調に見えるか |
|---|---|---|
| 1 | **判断の型が一つ** | 相手の頭の中が「回り込む → 連撃 → 隙 → 回り込む」の一本道だった。何をしてくるかの「種類」ではなく、「次に何の型が来るか」が読めてしまう |
| 2 | **間合いの使い方が一つ** | どの技も「近づいて斬る」。離れたら近づく、しかない。遠い間合いの攻め（弓、飛ぶ斬撃）、間合いを外す動き（跳び退き）がなかった |
| 3 | **構え（溜めの見せ場）がない** | 技はすぐ始まり、すぐ終わる。居合の溜め、待ちの構え、上段の構えのような「次に何か来る」緊張の時間がなかった |
| 4 | **こちらの行動に応じて相手の在り方が変わらない** | こちらが斬りかかってばかりでも、待ってばかりでも、相手の戦い方は変わらない（連撃の重みが少し変わるだけ） |
| 5 | **大技がない** | 体全体を使う大きな見せ場（高い跳躍からの兜割り、回転しながら詰め寄る旋風）がなく、どの技も同じ大きさに見える |
| 6 | **同じ戦術が続く** | 選び方に「さっきと違うことをする」仕組みがなかった |

## 取り組み：戦術の層を持つ行動エンジン

相手の判断を **戦術 → 技・構え・移動** の二層にした。

1. **戦術**を選ぶ：間合い、前半か後半か、こちらの癖（斬りかかり、弾きの連打、避け）で、それぞれの戦術の選ばれやすさが決まる。**使った戦術は選ばれにくくなり**、同じことが続かない
2. **戦術が、構え・移動・技の並びを組む**：技は、前の版の様式エンジンでさらに形が変わる

### 戦術（11）

### 戦術を選ぶ重み（抜粋）

- 近い（2.8m未満）：押し、待ち、跳び退きが選ばれやすい
- 中くらい：居合、上段、虚
- 遠い（3.5m超）：弓、飛ぶ斬撃、大跳躍、詰め
- こちらが斬りかかってばかり → 待ちの構えが増える
- こちらが弾きを連打 → 虚の連鎖が増える
- こちらが避けてばかり → 弓が増える
- 後半は旋風と大跳躍が増える

### 行動の幅（数え方）

前の版は「連撃一本道 × 技320」。今回は「戦術11 × 戦術ごとの変化（4〜7、押しは数千）× 技の様式」。戦術の層だけで、**判断の型が1 → 11**、構えと間合いを使った見せ場が **0 → 7種**（居合、待ち、上段、旋風、大跳躍、弓、飛ぶ斬撃）。「本質的に20倍」に届いているかは、遊んで判断してほしい。
