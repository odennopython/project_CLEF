# 44. 注意が続く設計：飽きる仕組みから考える（提案・判断待ち）

## オーナーの相談（2026-11-02）

> ただ単調に伸ばすというのは反対。もう一捻り欲しい。そもそも、どうやったら飽きるのか、どうやったらアテンションが持続するのか考えてください。雪山以外のステージを複数作る、目的を作る、何かを集める、敵を非常に強く（かつ面白く）する、エンドレスステージ（ゲームデザインをちゃんと考えるべき）をつくる。ひとひねり、ふたひねりするべき。

## 1. どうやったら飽きるのか

調べた知見：

- **楽しさは学ぶことで、模様を学び尽くすと退屈になる。** 簡単すぎても、模様が見えないほど難しすぎても退屈になる（ラフ・コスター『A Theory of Fun』。[講演資料](https://www.raphkoster.com/wp-content/uploads/2026/07/Austin-Game-Conference-2003-Keynote-Theory-of-Fun.pdf)、[本人のサイト](https://raphkoster.com/gaming/geekfun.shtml)）。
- **体験の質は、出来事の並びが興味をどれだけ保てるかで決まる。** 良い興味の曲線は、つかみ・上がっていく山・計算された谷・頂点でできている（ジェシー・シェル『The Art of Game Design』17章。[Routledge](https://www.routledge.com/9781138632059)、[講義資料](https://www.slideshare.net/slideshow/game-3400-level-design-experience-architecture/14335127)、[要約](https://notesbylex.com/interest-curve)）。
- **一つの仕掛けを、導入し、発展させ、ひねり、締める（起承転結）。** 任天堂の林田宏一氏が、四コマ漫画の構成から取り入れた（[Wikipedia](https://en.wikipedia.org/wiki/Koichi_Hayashida)、[Game Developer](https://www.gamedeveloper.com/design/the-secret-to-i-mario-i-level-design)、[MCV](https://www.mcvuk.com/development/video-nintendos-level-design-secrets-in-four-steps)）。

ここから、飽きる仕組みを七つに分ける。

| 飽きる仕組み | このゲームで今起きていること |
|---|---|
| ① 予測が当たり続ける（模様を学び尽くした） | 相手の型を覚えると、合目が変わっても同じ読みで勝てる |
| ② 新しい模様の補充が、覚える速さに追いつかない | 新しい法則は合目に一つ。覚えるのに数戦、その後は同じ |
| ③ 変化が表面だけ | 景色が変わっても、読み方が変わらないなら、新しさはすぐに消える（雪山を砂漠に塗り替えるだけの新ステージはこれ） |
| ④ 意味がない | 勝っても負けても、世界にも自分にも何も残らない |
| ⑤ 緩急がない | 戦い → 走る → 戦い の同じ強さが続く。谷も頂点も無い |
| ⑥ 選べない | 道も、戦い方の方針も、選ぶ場面が無い。運ばれているだけ |
| ⑦ 謎が無い | 「この先に何があるのか」「あれは誰なのか」が無い |

## 2. どうやったら注意が続くのか

七つの裏返し。

| 注意が続く条件 | 作り方 |
|---|---|
| ① 学ぶ模様が、覚える速さに合わせて補充される | 新しい読み方を要する相手と状況を、起承転結の単位で出す |
| ② 新しい模様は、知っている法則の組み合わせから出る | 柱2。新しさの多くを、足し算でなく組み合わせで作る |
| ③ 変化は、読み方を変える | 新しい場所は、見た目でなく「相手の起こりの見え方」を変える |
| ④ 行いが、世界と自分に残る | 拾った物、倒した相手、倒れた場所が、次に登るときに残っている |
| ⑤ 緊張と緩みの波 | 戦わない谷（休む、眺める、謎に触れる）を、山場の前に置く |
| ⑥ 自分で選ぶ | どの記憶に入るか、どの流儀を背負うか、どの誓いを立てるか |
| ⑦ 謎が少しずつ解ける | 先を行く者は誰か、白狐は誰か、なぜ皆が名を捨てるのか |

## 3. 提案：「刀の記憶」——ひとひねり

### ひとひねり目：雪山以外の場所は、刀の中にある

九合目の**刀塚**と、山の道の脇に突き立った刀。あれはすべて、白峰で倒れた者たちの刀。

- 刀に触れると、**その刀の持ち主が白峰に来る前の、最後の戦いの記憶**に入る。
- 記憶の中は雪山ではない。その人が生きた土地と季節：雨の港町、紅葉の山寺、燃える城下、夜桜の里、雷雨の河原、嵐の竹の海、砂塵の古戦場…。
- 記憶の中で、その人が越えられなかった相手と戦う。越えると、刀を抜ける。

これで、要望の四つが一つにつながる。

| 要望 | 「刀の記憶」でどうなるか |
|---|---|
| 雪山以外のステージ | 刀ごとに、土地も季節もまったく違う記憶の場所 |
| 何かを集める | 刀（とその記憶）を集める。道の脇の刀はただの飾りではなく、入口だった |
| 目的 | 先人が誰で、何を目指し、なぜ倒れたのかを知る（文字なしで、場所と相手で） |
| 敵を非常に強く | 記憶の相手は、その人を殺した者。一人ひとりに、読み方の「問い」が一つある |

### 記憶の場所は、見た目でなく「読み方」を変える（③の対策）

このゲームの芯は、相手の起こりを読んで一瞬に応えること。記憶の場所ごとに、**起こりの見え方**を変える。

| 記憶の場所 | 季節・天気 | 読み方の変化 |
|---|---|---|
| 雷雨の河原 | 夏の夜、雷雨 | 闇の中、相手は稲光の一瞬だけ見える。稲光の間隔と音で読む |
| 夜桜の里 | 春の夜 | 花吹雪で起こりは隠れるが、刃の通る筋だけ花びらが渦を巻く。刃の軌跡で読む |
| 紅葉の山寺 | 秋 | 鐘が鳴るたびに、相手が構えを替える。鐘の数を数えて読む |
| 燃える城下 | 冬の夜、火事 | 梁が落ちて足場が狭まっていく。間合いの外へ逃げられなくなる |
| 雨の港町 | 梅雨 | 波が甲板を洗う一瞬は、両者とも跳ぶしかない。波の拍子を戦いに組み込む |
| 嵐の竹の海 | 野分 | 竹が風でしなり、横薙ぎを止めたり通したりする（二合目の竹の法則のひねり） |
| 砂塵の古戦場 | 晩夏 | 砂塵で遠くが見えない。足音（足元の砂煙）で、背後からの相手を読む |
| 地底の氷穴 | — | 灯りは自分の提灯だけ。近づくほど見える |

### ふたひねり目：集めた刀が、白峰と白狐を変える

- 刀を抜くと、その人の**流儀**（戦い方の癖）を一つ背負える。流儀は強化ではなく**引き換え**：例「弾きの間は狭くなるが、反撃は深く入る」「避けると遠くまで流れるが、出鼻が取りやすい」。背負えるのは一つか二つ（Hollow Knight のチャームのように、限られた枠で遊び方を変える。[Game Developer の分析](https://www.gamedeveloper.com/design/secondary-systems-analysis---hollow-knight)）。
- **九合目の白狐は、こちらの癖を覚える。** 流儀を背負えば癖が変わり、白狐の読みが外れる。白狐との戦いが、毎回違う駆け引きになる。
- 先を行く者の刀も、七合目にある。彼の記憶に入ると、彼が何を追って登ったのかが分かる（白狐の正体の手がかり）。

※ 流儀は「強化はしない」という決まり（[35](35-game-design.md)）との関係で、オーナーの判断が要る。強くはならず、遊び方が変わるだけ、という線で提案する。

### 物語のひねり：風を継ぐことは、山に縛られること

文字を使わずに、遊びの中で気づかせる。

1. 一度目の登頂：十合目で三人の風を越え、暁の頂に立つ。主人公は面を棚に納め、**次の白狐になる**。
2. 二度目の登り：九合目で、白い面の影がこちらを見ている——**それは前の自分**（前の登りでの、自分の癖を映す）。白狐の面の棚には、自分が納めた面がある。
3. 刀の記憶を集めると、白狐たちが皆、もとは頂を目指した登山者で、頂で風を継いだあと、山を離れられなくなったことが分かる。
4. 最後の目的が変わる：**風を継ぐのではなく、風を放つ**。すべての記憶を集め、十合目の大将（のちに置く）を越えると、山の掟が解ける。

一度目は「頂へ」、二度目からは「なぜ皆が頂を目指し、なぜ戻れないのか」へ、目的が変わる。

## 4. 敵を「非常に強く、かつ面白く」

強さを、体力や攻撃力の数字で作らない。**新しい問い**で作る。

| 作り方 | 内容 |
|---|---|
| 主ごとの問い | 主一人に、その者にしかない読み方を一つ。例：霧縫いは霧に消え、足跡でしか来る方向が分からない。双弓の兄弟は、兄が引き絞る間に弟が射る。垂氷の行者は、踏み込むたびに足元を凍らせる |
| 宿敵 | 自分を最も多く倒した相手を、山が覚えている。その相手は、こちらから奪った笠を被って、次の登りでまた現れる。越えれば笠を取り戻す |
| 段（周回） | 越えた山に、法則を一つずつ足して登り直す。Hades の Heat のように、どの法則を足すかを自分で選ぶ（[Hades の解説](https://rpgsite.net/feature/10287-hades-pact-of-punishment-heat-modifiers-and-how-to-maximize-your-rewards)） |

## 5. エンドレス：雲上の回廊——ちゃんと設計する

ただ敵が無限に出るだけのモードにはしない。

| 要素 | 内容 | 理由 |
|---|---|---|
| 場所 | 十合目の上、雲の上に続く、終わりの無い参道 | 物語の中に置く（風の通り道） |
| 一日一つの山 | その日の参道の組み合わせ（勢力・武器・法則・天気）は、日付で決まり、誰が登っても同じ。公式の挑戦は一日一回 | Spelunky の日替わり（[Spelunky Wiki](https://spelunky.fandom.com/wiki/Daily_Challenge_Mode_(HD))）。同じ条件なので、腕だけが差になる。「明日はどんな山か」が、また開く理由になる |
| 難しさの上がり方 | 数字でなく、法則の組み合わせで上がる。十段ごとに、それまでの主を組み合わせた門番 | 柱2。新しい模様が、上るほど補充される |
| 誓い | 登る前に誓い（例：避けを使わない、弾きの間が狭い）を立てると、登った高さが重く数えられる | 自分で難しさを選ぶ（⑥）。Hades の Heat と同じ考え方 |
| 記録 | 数字の表は出さない。**倒れた高さに、自分の刀が突き立つ**。次に登ると、自分の刀が見える。越えると刀を抜いて、また先へ | 文字を出さない方針（[14](14-feedback-language.md)）。記録が世界に残る（④） |

## 6. 全体の構成と長さ

| 部 | 中身 | 長さの見積もり |
|---|---|---|
| 一 | 白峰を登る（今の一〜十合目）。暁の頂で風を継ぐ | 約1.5時間 |
| 二 | 二度目の白峰。刀の記憶（十ほど）に入り、雪山以外の土地で先人たちの最後の戦いを越える。流儀を集める。白狐が自分になる | 記憶1つ30〜45分 × 10 ＝ 約6〜8時間 |
| 三 | 宿敵と段。山が覚えている相手との再戦。法則を足して登り直す | 約2〜3時間 |
| 四 | 風を放つ。すべての記憶を集め、十合目の大将へ | 約1時間 |
| 雲上 | 雲上の回廊（エンドレス）。一日一つの山 | 終わり無し |

本編で約11〜14時間、雲上の回廊と段で、さらに長く遊べる。**ただ伸ばすのではなく、部ごとに目的が変わる**（頂へ → 先人を知る → 宿敵を越える → 風を放つ → 自分の記録の刀を越える）。

## 7. 進め方の提案

1. **刀の記憶を一つ作って確かめる**：雷雨の河原（稲光の一瞬だけ相手が見える）。記憶の入り方、新しい読み方、越えたときの刀の抜き方を試す。面白さが立つかを、オーナーが遊んで判断する。
2. 主ごとの問いを、一合目から順に入れる（単調さの直接の対策）。
3. 雲上の回廊の最小版（一日一つの山、倒れた高さに刀が立つ）。
