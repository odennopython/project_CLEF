## ここまでの流れ

1. 配信先と技術の方針を決めた（iOS、Macなしで開発）
2. 技術はゲームの内容で変わるので、先に方向性を決めることにした
3. 面白さを人間工学・心理学の観点で分解した
4. オーナーが本質的に面白いと感じたゲーム6本を分解し、共通構造を見つけた
5. 「世界の法則を読む」を主軸に決めた
6. 設計の柱 v0 を作った
7. 北極星を「世界のすべての法則」とし、少数の規則から法則が創発する世界を軸に決めた
8. 操作の核を「最小の一触れで最大の結果を起こす」に決めた
9. デザイン案を2回出したが、どちらも不採用。出発点を「現象」から「プレイヤーが磨き続ける技能」に変えることにした
10. 三人称視点の3Dで、静かな探索とボスとの死闘を組み合わせる方向に。ボス戦の核は弾き・見切り。柱5を見直した
11. 「返し」の試作 0.1 を作り、公開した
12. オーナーの評価を受けて、試作 0.2 に更新した（間合い、駆け引き、魅せ）
13. 「人がカクカク」の評価を受けて、試作 0.3 で人物の形と動きを作り直した
14. iPhoneで試せるようにした（GitHub Pages）。オーナーの評価を受けて、試作 0.4 で操作と人体と大太刀を作り直した
15. 試作 0.5：文字を消し、結果を手応えの組み合わせで伝えるようにした。体の状態で残りの体幹と進み具合を表した
16. ボス1体との一騎打ちを極めることに決めた。試作 0.6 でボスの技・分岐・AIを設計し、試遊の記録を書き出せるようにした
17. 試作 0.7：「相手に効いているかわからない」を受けて、戻らない傷と、傷の節目で欠ける笠、斬られた瞬間の反応を入れた
18. 試作 0.8：人物を、一続きの皮膚・英雄的な比率・対照的なシルエット・縁取りの光で作り直した
19. 試作 0.9：音を作り直した。人物はコードで作る方法の限界に来たため、本物の人体モデルと動きの素材を使う方針を提案した（判断待ち）
20. 試作 1.0：オーナーの依頼で、コードで作る方式のまま、人体を彫刻し、骨と皮で動かす本物のゲームの人物と同じ構造にした
21. 試作 1.1：高品質を定義し、主人公の意匠、エフェクト、振り、音の低品質な部分をすべて補修した
22. 試作 1.2：「臭そうなおっさん」の評価を受けて、和装の自然な格好よさを7つの原則で定義し、主人公を作り直した
23. 試作 2.0：ゲームの名を「風の伝説」に。音を物理に基づく合成で作り直した。見た目をアニメ調（ゼルダの伝説くらい）で作り込む方向に変え、主人公（笠、黒の和装、背中の鞘）と相手（葦名弦一郎を参考にした鎧武者）を作り直した。斬撃を滑らかにし、大袈裟にした
24. 試作 2.1：斬りの結果（斬れた、浅い、弾かれた、空振り）ごとに、軌跡の色と三日月の形を分けた。斬れたときは体を横切る斬り線を出す
25. 試作 2.2：斬撃を、刀の通り道から求めた振りの面に描く大きな円弧にした（滑らかで、刀が通っていない部分まで大きい）。振り抜きの姿勢を足し、ひねり・沈み・踏み込みを大きくした
26. 試作 2.3：音を刀同士の会話（キン、ガキッ、ガィン）だけに絞り、雑音の層をなくした。相手の袴を左右の脚に分かれる形にした。人物の面を細かくし、刀を長くし、鞘を背負わせ、構えと弾きを大袈裟にした
27. 試作 2.4：音から雑音の素をすべてなくした（残響を雑音なしの反射に）。陰を柔らかい2段に、輪郭線を細い藍色に。袴に股の割れと布の揺れ。背景を夜の雪山（空、月、三重の山並み、起伏する雪原、杉、岩）に作り直した
28. 試作 2.5：安っぽさを7つの原因に分解して解決した。肩幅を狭め、羽織にひだと裾の返し、布の質感、月の光の本物の影、ダボっとした袴、相手に黒漆の陣笠
29. 試作 3.0：使えるアセットがないことを確かめ、オーナーの選択で、人物の体を箱からの造形（ケージ、厚みのある布の殻、折り目つきの Catmull-Clark 細分）で作り直した。足の瞬間移動をなくした
30. 試作 3.1：有料アセットの細部の作り方（法線・光沢・くぼみの影・光の物理に基づく描き方・小物）をコードで再現した。顔は面覆いと面頬で覆い、本物の眼球を入れた
