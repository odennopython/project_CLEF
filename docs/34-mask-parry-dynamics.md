# 笠の消失、面の厚み、大袈裟な弾きと動き（試作 4.0、2026-10-30）

## オーナーの評価（試作 3.9）

> 主人公の顔が横から見るとペラペラ。なぜか主人公が笠をかぶっていない。弾きはもっと大袈裟に。刀を少し曲げる程度ではわかりにくい。一瞬ぐっと刀を横に、姿勢を低く構えてほしい。全体的にモーションは大袈裟に、ダイナミックに。

| 依頼 | 原因・やったこと |
|---|---|
| 笠がない | 負けて飛び散るとき、体に付いた物を集める処理で、頭の骨を二度数えていた。二度目の記録では「元の場所＝空間」になり、やり直したときに笠と鞘が頭や背中へ戻らず、倒れた場所に残っていた。骨を一つずつ数えるようにした（負け → やり直しのあとも笠が頭にあることを試験で確かめた） |
| 横から見て顔がペラペラ | 狐面が、顔の前半分だけを覆う浅い殻で、顔から浮いていた。面を顔の横から耳の後ろまで回り込む深い形にし、内側にもう一枚の殻を重ねて厚みを持たせ、顔に密着させた |
| 弾きを大袈裟に | 構え：一瞬でぐっと腰を落とし（沈み 0.36 → 0.6）、刀を真横に寝かせて前へ突き出し、体を大きくひねる。弾けたとき：まずその低く受け止めた形を0.12秒見せ、さらにぐっと沈み、それから刀を大きく跳ね上げる（以前は弾けた瞬間に跳ね上げへ移っていたので、受け止めの形が見えなかった） |
| 避けを大袈裟に | 跳ぶ向きへ体を大きく倒し、低く滑り込む。横へ跳ぶ角度と距離を大きく（角度 0.6 → 0.85、距離 +0.25 → +0.5） |
| 斬られたこちら | 大きくのけぞる（後ろへ反る 0.34 → 0.6） |
| 斬られた相手 | 大きくひねられてのけぞり（ひねり 0.6 → 0.95）、押し込まれる距離を長く（0.3 → 0.55、重い斬り 0.8 → 1.2） |
