# 山の合目と開発者モード、震えの解消、斬り抜け（試作 4.5、2026-10-31）

## オーナーの判断（2026-10-31）

- 5人と戦うこの単位が合目の単位。**一合目はこのレベルの連戦でよい**。本格的に作る
- **負けたら直前の山小屋から**（とりあえず）
- **獣・妖・巨体は入れない**。雑兵だけでいろいろ50種。何にせよ、基本的にはみんな武器で攻撃してくる
- **九合目を「自分の癖を学ぶ白狐の剣士」**にする。頂上（ラスボス）は改めて考える
- **群れは3人まで**
- ゲームバランスのテストのため、タイトル画面に**開発者モード**（何をテストするか選べる）

## 合目（一〜五合目）

一つの合目は五つの戦い：一人 → 二人がかり → 三人の群れ → 一人 → 合目の主。

| 合目 | 一 | 二 | 三 | 四 | 主 |
|---|---|---|---|---|---|
| 一合目 | 雑兵 | 雑兵×2 | 雑兵×3 | 足軽 | 一合目の門番（刀の手練） |
| 二合目 | 足軽 | 足軽＋雑兵 | 足軽×2＋雑兵 | 手練 | 槍の老兵（槍の頭） |
| 三合目 | 手練 | 足軽＋手練 | 足軽×3 | 流派の者 | 霧の追跡者（忍者刀の頭） |
| 四合目 | 流派の者 | 手練×2 | 足軽×2＋手練 | 流派の者 | 弓の兄弟（弓の頭と流派の者の二人がかり） |
| 五合目 | 手練 | 流派の者＋手練 | 手練＋足軽×2 | 頭 | **白峰の浪人** |

- 格ごとの相手は、名簿（[37-enemy-roster.md](37-enemy-roster.md)）から、同じ合目で重ならないように選ぶ。通るたびに顔ぶれが変わる
- **山小屋＝合目の始め**。負けたら、その合目の山小屋から（顔ぶれは組み直す）
- 合目を越えると、次の合目の名（「二合目」）が静かに浮かんで消え、そのまま次の合目の山小屋から始まる。進み具合は保存され、始めの画面に小さく「三合目から」と出る
- 五合目の主を越えると、終わりの画面（「五合目を越えた」）。六合目より上は、これから作る

地形の法則（竹、霧、狭い道…）は、まだ入れていない。

## 開発者モード

始めの画面の左下に、ごく小さく「開発」。開くと：

| 項目 | 中身 |
|---|---|
| 試すもの | 合目を通しで／一人の相手／群れ（同じ格） |
| 合目、何戦目から | 合目の途中から始められる |
| 相手 | 名簿の60種、各合目の主、白峰の浪人から一人 |
| 群れの人数・格 | 1〜3人、格を選ぶ |
| 倒れない | こちらの崩しが一定以上溜まらない |
| 自動で遊ぶ | 弾き中心の自動操作 |
| 時間の速さ | 0.5〜2倍 |
| 進み具合を一合目に戻す | 保存した進み具合を消す |

## 震え（小刻みにカクカク動く）の原因と解消

| 原因 | 解消 |
|---|---|
| 動きをつなぐばねの「目標の速さ」：時間をごく遅くする瞬間（4%）は1コマが短く、目標がわずかに動くだけで値が何百倍にも跳ね、体がビクッと震えた | 目標の速さに上限を設け、長いコマは細かく刻んで解く |
| 速いばねと遅いばねの切り替え：振りの始まりと終わりで、ばねの硬さが一瞬で変わり、ガクッと動いた | 切り替えずに、約0.07秒かけて滑らかに混ぜる |
| 位置の押し合い：踏み込みの移動と「重ならないように押し戻す」処理が、毎コマ逆向きに綱引きした | 押し戻すときは、移動の行き先ごとずらす |

測定（1コマ16msで固定し、自動の試合1500コマで、刀先の位置が前のコマと逆向きに動いた回数）：相手の刀 47 → 22、主人公の刀 56 → 10。相手の頭の逆向きの動きは、ほとんどが斬られてのけぞる瞬間（意図した反動）だった。

## 弾きの構え

さらに低く（沈み 0.6 → 0.74）、刀を**斜め（右下から左上）**に立てて前へ突き出す。

## 斬り抜け（勝負の一閃）

横からの単調な画をやめ、二つの画で見せる：

1. **一の画**：相手の斜め前の低い位置から、こちらへ駆けてくる主人公を見る。主人公は相手の体を駆け抜ける
2. **二の画**（一瞬で切り替え）：駆け抜けて背中合わせに止まった主人公の前の、低い位置から。手前に残心の主人公、奥で相手が斬り分かれる。カメラはゆっくり回り込む

斬り口は、駆け抜けた向きに垂直な斜めの面（肩から脇腹）。一閃の瞬間に画面を白く飛ばす光とぼかしを弱め、画が見えるようにした。

## 群れの配置

番を待つ相手は、番の相手から左右に約41°離れた持ち場に立ち、互いに2m以上離れる（一か所に固まらない）。
