# 46. 技の獲得・五つの世界・エンドレス（方針決定 2026-11-04）

## オーナーの決定（原文の要点）

- ステージは、いまの白峰を含めて**5つ＋エンドレス（本編）**。世界観を守り、同じ量感で、飽きない工夫を入れる。
- いまの問題：十合目をクリアしても**文字が出るだけで達成感がない**。
- **ステージを越えるごとに技を一つ獲得**する。技は五つ。最終戦の相手がその技を使い、勝つと使えるようになる。
- 一つ目はダブルタップの飛び道具（くない）。赤く光る、防御できない攻撃。メリットとデメリットを作る。
- 残る四つは、**長押しで素早く居合の構え**に入り、上・下・右・左へフリックして出す。長押しはスッと押したらすぐ「カチン」と構える（テンポが重要）。
- 最終的に、**全部を使わないとエンドレスでまともに戦えない**作りにする。
- 説明の箱（チュートリアル）を、最初のステージに入るときと、技を取るたびに出す。誰も読まない前提でわかりやすく。
- タイトルのあとに**地図**を置く。地図は一合目の五合目まで進むと手に入り、ファストトラベルができる。次のステージが開くと地図にも現れる。戦闘中の休止と、不正（負けが確定したら地図へ逃げる）への対策を考える。
- 残り四つのステージは、それぞれ個性を持たせて飽きさせない。エンドレスは本編と呼べるものにし、**非常に強い敵がランダムに乱入**する（理不尽ではなく、うまい敵）。

## 解釈で決めたこと（食い違いの指摘）

| 項目 | 指摘と決定 |
|---|---|
| 五つ目の技の方向 | 原文は二つ目と同じ「上」にフリックと書かれている。上は居合切りで使うので、**下**にした（上・下・右・左で四つに揃う）。違っていたら言ってほしい |
| 「はじき」の名前 | このゲームの弾きは、これまで「返し」と呼んできた（試作名も返し）。通常の弾きを「**返し**」、居合の弾きを「**月影**」と呼ぶ。画面に出す名前は、技を得たときのカード以外ない |
| 鬼人化の発動条件 | 「相手の攻撃に合わせて」＝避けと同じ窓（刃が届く直前の、約320msの内）。ずれたら発動せず、避けにもならない（居合の構えで待っているので、斬られる） |
| 「ダメージが通らない」 | このゲームの体力にあたるのは**崩し（体幹）**。守りのある敵は、条件を満たさない攻撃の崩しが約1/10になる。体力の数字は増やさない |

## 技の名前と世界観

| 順 | 技 | 名前 | 出し方 | 由来 |
|---|---|---|---|---|
| 1 | くない | **緋燕（ひえん）** | ダブルタップ | 赤い光を曳いて低く飛ぶ。燕のように速く、返せない。忍びの飛び道具 |
| 2 | 居合切り | **疾風断ち（はやてだち）** | 居合から上 | 風の名を持つ者の技。距離を詰めて一太刀。必ず弾かれるが、体幹を大きく削る |
| 3 | 鬼人化 | **鬼面（きめん）** | 居合から右（相手の技に合わせる） | 山では名を捨てて狐の面をつける。面を**裏返す**と鬼の面。名を捨てた者が行き着く先。攻めが強くなる代わりに、解けるのも早い。赤い気をまとう |
| 4 | 鬼神解放・見切り切り | **輪華（りんか）** | 居合から左（相手の技に合わせる。鬼面の間だけ） | 見切りの一太刀のあと、相手のまわりを輪になって斬り巡る。斬り筋が花のように開く。最後に「カチン」と納刀 |
| 5 | 居合弾き | **月影（つきかげ）** | 居合から下（相手の技に合わせる） | 夜の山で、刃が月を映す一瞬の弾き。雑兵（雑兵・足軽・手練）は一撃で斬り伏せる |

### なぜ全部が必要か（メリハリの設計）

- 雑兵：**月影**で一撃（刃を見て、一度に決める）。ふつうに崩すと、後の世界ほど硬くて時間がかかる。
- 手練・流派の者：疾風断ちで崩しを稼ぎ、通常の返しと反撃。
- 守りのある強敵：**鬼面**を取らないと崩しが通らない。
- 最強格（主・エンドレスの乱入者）：**鬼面の間に輪華**を決めないと崩しが通らない。

→ 敵の格ごとに、使う技が違う。強い技ほど、読みの窓が狭く、失敗の代償が大きい。「全部を使い分ける」遊びになる。

### 技のメリット・デメリット

| 技 | メリット | デメリット |
|---|---|---|
| 緋燕 | 離れた敵の技を止められる。防御されない。連鎖の途中を切れる | 三本まで。1本は4秒で戻る。投げる間は返しが出せない（0.26秒）。敵の格が高いほど崩しは小さい |
| 疾風断ち | どんなに遠くても届く。雑兵は一度で崩れる。遠距離の敵に強い | 主には効きが薄い。1.8秒は使えない。出したあとの隙がある |
| 鬼面 | 攻撃力が上がる。守りのある敵に崩しが通る。9秒間 | 窓を外すと斬られる。時間で解ける |
| 輪華 | 大きな崩し。見ていて気持ちいい | 鬼面の間だけ。窓を外すと斬られる |
| 月影 | 雑兵を一撃で倒せる | 窓が狭く、外すと受けにもならず斬られる。強い敵には崩しだけ |

## 「成功が気持ちいい」の設計（輪華）

調べた手がかり：
- 「Juice it or lose it」（Jonasson & Purho, 2012）の要点：同じ動作に、止め（ヒットストップ）・小さな揺れ・光・音・粒の**重ね**を足すと手応えが増える。重ねすぎや大きすぎる揺れは逆効果。[二次資料のまとめ](https://eastondev.com/blog/en/posts/dev/20260521-game-feedback-feel/)（原典の動画は [YouTube](https://www.youtube.com/watch?v=Fy0aCDmgnxg)）
- モンスターハンターの太刀「見切り斬り」：攻撃に合わせて入力すると、わずかな無敵の間で避けつつ反撃が始まり、成功すると連携技（気刃大回転斬り）につながる。入力の窓は狭く、失敗すると反撃が出ない。[Icy Veins の解説](https://icy-veins.com/monster-hunter-wilds/long-sword-guide)（正確な窓のフレーム数は出典なし。コミュニティの目安）

ここから決めたこと（設計の判断）：
1. **成功の瞬間を止める**（70〜130ms）。そのあとゆっくりから戻す。
2. **一度で終わらず、段階を踏む**：見切りの一閃 → 輪の連斬（六太刀）→ 納刀の「カチン」。連続で盛り上がり、最後に静かになる。
3. **音で終わらせる**：締めの納刀音を高く澄ませ、その直後に一瞬の無音を置く。
4. **揺れは小さく、光は多く**。画面の揺れは抑え、斬り筋・光の輪・粒で見せる。
5. 失敗しても**理不尽にならない**：外した理由が構えの姿で見える（構えたまま斬られる）。

## 地図（風纏）と中断の仕様

- 名前：地図の巻物は「**風纏（かぜまとい）**」。風を纏って山と山のあいだを渡る。
- 手に入れる時：一合目の**五合目の山小屋**。
- タイトル → 地図（行ける所だけ明るい）→ 選んだ所の山小屋から始まる。初回、地図がない間はタイトルから直接一合目へ。
- 戦闘中の休止：**休止はできる。ただし戦いの中で地図には戻れない**。
  - 休止中は、「続ける」と「この合目の山小屋から出直す」だけ。
  - 戦いは休止中に止まるが、**相手の構えは見せない**（画面は暗くぼかす）。休止して相手の技を観察・準備する悪用を防ぐ。
  - 負けは確定したとき（倒れる演出に入ったとき）以降は、休止・地図への逃げができない。
  - 「出直す」を選んでも、負けた扱いと同じ（その合目の山小屋から）。逃げ得は無い。
- 地図から行ける場所は、各合目の**山小屋**まで（戦闘の途中には戻らない）。

### 世界が進むと、敵はどう変わるか（技を使い分けさせる）

- 雑兵ほど硬くなる（崩れにくい）：世界2〜5と回廊で、崩しの通りがそれぞれ ×0.85, ×0.65, ×0.5, ×0.4, ×0.32。**月影で一撃**にする理由が生まれる。
- 守り（ward）：世界3の頭、世界4の流派の者と頭、世界5の手練以上、回廊の流派の者と頭に付く。1＝鬼面がないと崩しが通らない（約1/10）。2＝鬼面の間に輪華でないと通らない（約1/12）。
- 新しい勢力：神狐衆（朱と白、赤い狐面）、湖衆（藍と青緑）、花守衆（黒と桃色）、砂の民（砂と藍）。動きの癖と奥の手も別（拍子・応え・手がかりのどれかを一つだけ変える）。

## エンドレス「雲上の回廊」（本編）

- 地図で、五つの技がそろうと開く。入り口は夜明けの雲の上の鳥居。
- **一つの層＝五戦**（一人→二人→三人→一人→主）。層が上がると、相手の格が上がる。主は、これまでに出会った主のうちの一人（守り2）。層を越えるたびに、鳥居をくぐって次の層へ（体力が戻る）。
- **倒れたら第一層から**。最高の層を記録する（回数制限や強化はない。技と腕だけで登る）。
- **全部の技がないと通らない作り**：雑兵は月影、手練以上は鬼面、主と乱入者は鬼面の間の輪華、遠くの敵には疾風断ちか緋燕。
- 休止は、戦いの中では地図に戻れない。出直すと第一層から（倒れたのと同じ）。

### 乱入者「無銘（むめい）」

- **設定**：白峰の掟は「名を捨てる」。無銘は、名どころか、狐の面すら捨て、白紙の面だけを残した先代の風。先代の風は頂で次の者を待つ（白狐）が、無銘は頂を降り、回廊をさまよい、登ってくる者を試す。強さの理由は特別な力ではなく、**ただひたすら基本を磨いたこと**。
- **作り**：理不尽ではなく、うまい敵。飛び道具も、地形も、ごまかしもない。刀一本で、読みを読み返す（白狐と同じ、相手の癖を覚える作り。窓は狭いが、必ず起こりが見える）。守り2。二つの形（前半・後半）。
- **乱入の起き方**：層ごとに一度まで、主の前のどこかの戦いの前に、確率で現れる。層が深いほど起きやすい（約13%から最大45%）。現れる前に鐘が鳴り、空気が張る。
- **報酬**：強化はない。斬った数が数えられ（記録）、終わりの画面で見える。
- 乱入者を倒すと、そのまま続きの戦いへ。

### 率直な限界（まだのこと）

- **手で遊んだ感触は未確認**。長押し110msの「カチン」のテンポ、二度押しの受け付け（320ms）、鬼面・輪華・月影の窓（約320ms/180ms）は、実機で調整が必要。
- 世界2〜5は、白峰の十に対して五つの景色ずつ（量は約半分）。景色の細部（道端の物語、人物の剣客、刀の記憶）は白峰ほど入っていない。
- 世界2〜5の主は、敵の動きの傾向（戦術の重み）で個性を出した段階。白峰の主のような専用の「問い」（霧縫いのような仕組み）は、霧船頭と狐火遣いのほかは未実装。
- 無銘は「うまい敵」としての学習型の作りを流用。専用の技や演出は未実装。
- 輪華の演出（円の連斬とカチン）は、手応えの重ね方（止め、連続、納刀音）を設計から入れたが、気持ちよさの判断は遊んで見る必要がある。
- エンドレスの難しさの曲線（層ごとの格、乱入の確率）は仮の値。
- 実機（iPhone）の重さは未確認。

## 開発者モードと地図（試作 6.2）

- **開発者モード**（メインメニューの「開発」）：持っている技を一つずつ選べる（合目を選ぶと、その手前の世界で得る技にそろい、あとで外せる）。地図（風纏）を持つ／地図の全ての場所と世界を開放、は保存される。
- **ステージ俯瞰**：開発者モードのボタン。天井と霧を外し、道に沿って上から眺める。ドラッグ（上下＝道に沿って進む、左右＝回す）、ホイール・二本指で拡大縮小、「角度」で見下ろしの角度を切り替え、前／次で景色を移る。
- **地図**：一覧表をやめ、羊皮紙の絵地図にした。下から白峰（山、十の山小屋）、紅蓮寺（寺）、城、水月の里（湖）、風紋の海（砂）、雲上の回廊（雲）。行った所は灯り、まだの所は暗く、前の世界を越えていない世界は霧に隠れる。山小屋をタップするとそこへ移る。
