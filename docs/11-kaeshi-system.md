## 2. 弾きの本質の分解

弾きは、ミリ秒の中で回る「知覚 → 判断 → 実行 → 結果」のループ。人間工学の観点から、要素ごとに分解する。

### ① 知覚：予備動作（起こり）が読めるか

- 人間の反応時間は、目で見てからおよそ0.2〜0.25秒、音を聞いてからおよそ0.15〜0.17秒（単純な反応の場合のおおよその値）。**音の方が速く反応できる**。
- 選択肢が増えるほど、反応は遅くなる（ヒックの法則）。
- したがって、良い弾きは**反応ではなく予測**で成り立つ。予備動作が十分に長く、読めば間に合うように作る（柱5）。
- スマホは**音を消して遊ばれることが多い**。予備動作は目だけで完全に読めるようにし、音は補強にする。

### ② 判断：どう応じるか

- 応じ方の選択肢が1つ（SEKIROの通常の弾き）だと、判断の深さが浅い。
- 選択肢が多すぎると、ヒックの法則で間に合わなくなる。
- **2〜3個の、意味の違う応じ方**が最適。

### ③ 実行：入力の仕方

- タッチ画面の強み：**狙う必要のない入力**（画面のどこを触ってもよい）は、狙う時間がゼロになる（フィッツの法則）。
- タッチ画面の弱み：押した感触がない。指で画面が隠れる。入力から画面に反映されるまで、数十ミリ秒の遅れがある。
- はじく動作（フリック）は「タイミング」と「方向」を1つの動作で伝えられる。ただしフリックの長さは人によって違うので、**タイミングは指が触れた瞬間で判定し、方向はその後の指の動きで判定する**必要がある。

### ④ 結果：手応え

- ヒットストップ（当たった瞬間に数フレームだけ時間を止める）、火花、音、カメラの揺れ、振動を重ねる。
- 「ぎりぎり成功」と「完璧」の違いが、手応えでわかること。

### ⑤ 危険と見返り

- 判定の時間が短いほど、見返りが大きい。
- 失敗の代償がはっきりしている。

### ⑥ リズムと緩急

- 敵の連続攻撃のリズムを読む。
- わざとリズムを外す攻撃（遅らせる、フェイント）が、反応ではなく読みを試す。武蔵の言う「拍子を外す」。

### ⑦ 攻守の循環

- 弾くことで何かが溜まり、流れが変わる（SEKIROの体勢）。

### ⑧ 選択の自由

- 同じ攻撃に、安全な応じ方と、危険だが見返りの大きい応じ方がある。どこまで危険を取るかがプレイヤーの選択になる（③自律）。

### ⑨ 学習

- 予備動作を学び、腕を磨く（①）。
- 敵ごとにすべてを暗記し直すのか、読み方そのものが他の敵にも通じるのか。

### ⑩ 疲労と体

- 親指の疲れ、1回の戦闘の長さ、持ち方（片手か両手か）。

### ⑪ 公正さ

- 失敗の原因が自分の読み違いだとわかる（柱4）。

## 3. SEKIROとモンハンの、超えるべき点（提案者の評価）

| 点 | SEKIRO | モンスターハンター |
|---|---|---|
| 判断の深さ | 通常の攻撃への応じ方はほぼ「弾く」1つ。深さは危険な攻撃への対処にある | 武器によってはカウンターが限られた場面だけになる |
| 学習の性質 | 敵ごとに動きを覚え直す。覚えた知識は他の敵にあまり通じない | 同様。モンスターごとに覚え直す |
| 自分の意思の表現 | 弾いた力は消えるだけで、どこへ返すかを選べない | 同様 |
| 状態の見せ方 | 体勢を画面のゲージで見せる | 体力などを画面の表示で見せる |
| 操作 | コントローラー前提 | コントローラー前提 |
| 1回の長さ | ボス戦は数分程度 | 1回の狩りが十数分から数十分と長い |

## 4. 提案：「返し」

**一言で：相手の力の起こりを読み、指を置き、はじく。受けた力の向きを自分で決めて、相手を崩す。**

### 要素1：ひとつの動作「はじく」

- 画面の**下半分のどこでも**、指を置いて、はじく。
- **指が触れた瞬間**がタイミング、**はじいた方向**が力を返す向き。
- 狙う必要がないので、フィッツの法則による操作の負担がない。動詞は1つだけ（柱2）。

### 要素2：三つの先（タイミングの段階）

同じ「はじく」動作でも、触れる瞬間によって意味が変わる。

| 段階 | 触れる瞬間 | 危険 | 見返り | 体験 |
|---|---|---|---|---|
| **後の先** | 攻撃が届く瞬間 | 小 | 受け流す。少し崩す | SEKIROの弾きに近い。頻繁に、リズムよく |
| **対の先** | 攻撃と完全に同時 | 中 | 相手の力をそのまま返す。大きく崩す | 刃と刃が噛み合う手応え |
| **先の先** | 攻撃の起こり（動き出しの瞬間） | 大 | 攻撃が始まる前に断つ。一気に崩す | モンハンの見切りに近い。**反応では絶対に間に合わず、読みでしか取れない** |

- 1つの動作の上に、SEKIROの頻繁な弾きと、モンハンの危険な見切りが**連続的に並ぶ**。
- どこまで危険を取るかはプレイヤーが選ぶ（③自律）。
- 先の先は反射神経ではなく**読み**のごほうびになる（柱5）。

### 要素3：返す向きを選ぶ

- はじいた方向へ、相手の力を返す。テニスで打球を狙った場所へ返すのと同じ。
- 返した力を、相手の重心の逆側に返せば大きく崩れる。柱にぶつければ相手がよろける。別の敵に返すこともできる。
- 弾いた力が消えるだけのSEKIROと違い、**受けた力の使い道をプレイヤーが決める**。同じ攻撃にも複数の正解がある（③自律）。

### 要素4：体は物理に従う（読み方が他の敵にも通じる）

- すべての敵の動きは、**重さ、慣性、関節の動く範囲**という一貫した物理に従う。
  - 重い攻撃ほど起こりが長い。
  - 振りかぶった方向と重心の位置で、攻撃の軌道と、崩しやすい返し方向が決まる。
- その結果、**読み方そのものが技能になり、初めて会う敵にも通じる**。上達した人は初見でも読める。敵ごとに暗記し直すSEKIROやモンハンを、ここで超える。
- これは柱1（法則は一貫している）と、プロジェクト全体の軸「世界の法則を読む」を、戦闘にそのまま持ち込んだもの。

### 要素5：状態は体で見せる

- 画面にゲージは出さない（洗練）。
- 相手の崩れは、構えの乱れ、呼吸、足のふらつき、音で見せる。プレイヤーの分身も同じ。
- 状態を読むこと自体が観察になる（①）。

### 要素6：拍子と虚実

- ボスごとに固有の拍子（リズムの癖）がある。
- 拍子をわざと外す攻撃、フェイント（虚）がある。「待つ」ことも選択肢になる（Ghost of Tsushimaの一騎打ちのように、動かないことが最強の手になる場面）。

### 要素7：一閃

- 相手の体勢が完全に崩れたら、一回はじくだけで決着する。最小の一触れで最大の結果。
- 決着の後に、静けさが戻る（残心）。

### 要素8：練習は世界の中で自然に起きる

- 探索の途中で出会う小さな生き物や敵が、ボスと同じ物理と拍子を持っている。
- 探索そのものが、ボスへの練習になる。モードの切り替えはない（[07-interaction.md](07-interaction.md) の決定）。

## 5. 人間工学の設計

| 項目 | 設計 |
|---|---|
| 持ち方 | **縦持ち・片手**。画面の上3分の2に敵、下3分の1が親指の領域。指で敵が隠れない |
| 入力領域 | 画面の下半分のどこでも。狙いはいらない |
| タイミング判定 | 指が触れた瞬間で判定する。はじく長さの個人差に左右されない |
| 方向の判定 | 方向の数は場面ごとに2〜3に絞る。角度の許容は広く取る |
| 遅延の補正 | 入力の遅れを、プレイヤーの成功タイミングの分布から自動で補正する（音楽ゲームの判定補正と同じ考え方）。設定画面は作らない |
| 音を消している人 | 予備動作は目だけで完全に読める。音は補強 |
| 判定の時間 | 反応の速さではなく、読みで応えられる長さを基準にする |
| 1回の長さ | ボス戦1回は1〜3分。負けたらすぐにやり直せる（柱4） |
| 色覚 | 色だけに頼らず、形と動きで伝える |

## 6. 比較

| 本質 | SEKIRO | モンスターハンター | 返し |
|---|---|---|---|
| 判断の深さ | 浅い（弾くだけ） | 場面が限られる | 三つの先 × 返す向き |
| 危険と見返り | 一定 | 大きいが限られた場面 | 1つの動作の上で、プレイヤーが選ぶ |
| 学習 | 敵ごとに暗記 | 敵ごとに暗記 | 物理に従うので読み方が他の敵にも通じる |
| 自分の意思の表現 | なし（力は消える） | なし | 受けた力の向きを決める |
| 状態の見せ方 | ゲージ | 画面の表示 | 体で見せる |
| 操作 | コントローラー | コントローラー | 片手の親指1本 |
| 1回の長さ | 数分 | 十数分〜数十分 | 1〜3分 |

## 7. 試作で確かめる仮説

1. 指が触れた瞬間でタイミングを判定し、はじいた方向で向きを決める操作が、気持ちよく感じられるか。
2. 三つの先の違いが、手応えではっきりわかるか。
3. 物理に従う予備動作が、初めて見る攻撃でも読めるか。
4. ゲージなしで、体の様子だけで相手の崩れが読めるか。
