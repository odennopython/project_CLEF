# ゲームデザイン案 20（不採用）

## 不採用の理由（オーナーの指摘を受けた自己批判、2026-10-29）

この20案は、ここまでの議論から具体化したものではなく、型に当てはめて量産したもの。同じ失敗を繰り返さないために残す。

1. **型に当てはめた**：すべて「物理現象＋静かな情景＋一度だけ触れる＋目標」という同じ構造。違うのは題材だけ。
2. **方針の上下関係を逆にした**：上位方針①②③より先に、情景（洗練）から選んだ。結果、静かだが面白さが検証されていない物理のおもちゃになり、参考の6本にある「ゾクッとする」「本気になれる」緊張がない。
3. **核を誤解した**：「最小の一触れで最大の結果」を「一度しか触れられない」制約として使い、答えが1つの一発勝負のパズルにした。本来は、上達した結果として少ない介入で済むようになる到達点。一発勝負では、1回の遊びの中でループが回らない。
4. **決定事項を無視した**：オープンワールド（モードで分けない）、作者も知らない法則の発見、柱2（組み合わせによる深さ）を満たしていない。
5. **検証していないことを検証したように書いた**：「一羽で群れが変わる」などの急所は想定にすぎず、比較表の◎◯も根拠のない印象。

### 案を出す前に答えるべきだった問い

| 問い | なぜ重要か |
|---|---|
| 数分の1回の遊びの中で、ループは何周回るか | 1周で終わる一発勝負では①も②も起きない |
| 世界はプレイヤーに何をしてくるか | 世界がただの的では緊張が生まれない。自分の法則で応じてくる存在である必要がある |
| 失敗すると何を失うか | 本気になれるには失うものが必要 |
| 何時間か遊んだあと、プレイヤーの中で何が変わっているか | 理解の層をどう積むか（柱2・柱3） |
| 発見した法則を、次の行動でどう使えるか | 発見が次の力になる構造。参考：Outer Wilds（進み方が知識だけで決まる） |

## すべての案が満たす条件

- 少数のミクロな規則から法則が創発する世界（[06-emergent-world.md](06-emergent-world.md)）
- 操作の核：**最小の一触れで最大の結果を起こす**（[07-interaction.md](07-interaction.md)）
- 世界は止まって待っている。触れて確定すると、世界が自分の法則で動く（柱5）
- 練習と本番、問題と探索をモードで分けない。1つの世界の中に自然に混ざっている
- 目標は見えていて、方法が隠れている。文字の説明はしない
- 1回の遊びは数分。上達はプレイヤーの頭の中に残る
- 画面は世界だけ。触れる操作はタップ・ドラッグ・ピンチのみ

各案の「一触れの急所」は、核の条件である「読める増幅」がどこにあるかを示す。

### 1. 霜の窓
- **背景**：冬の早朝、結露した窓ガラス。外はまだ暗い。
- **操作**：ガラスの一点に指を当てて、霜の結晶の種を1つ置く。
- **ゲーム**：霜は湿気と温度の流れに沿って枝分かれしながら育つ。窓の向こうに見える灯り（目標）だけを残して、霜でガラスを覆う。窓ごとに湿気の流れ方が違う。
- **一触れの急所**：種を置く位置で、枝どうしの湿気の奪い合いが決まり、全体の形が変わる。
- **世界の規則**：結晶成長（拡散と異方性成長）

### 2. 灯籠流し
- **背景**：夏の夜の川。岩の間を流れる水面に、灯籠が浮かんでいる。
- **操作**：水面に一度だけ指で触れて、小さな渦を作る（位置と強さ）。
- **ゲーム**：灯籠を対岸の決まった場所へ集める。岩の後ろには、渦が左右交互に生まれる列（カルマン渦）ができる。その流れに自分の渦をどう乗せるかを読む。
- **一触れの急所**：流れが不安定な場所に置いた小さな渦は、川全体の流れで大きく育つ。
- **世界の規則**：流体（格子ボルツマン法）。現実の流体力学に持ち帰れる。

### 3. 群れ
- **背景**：夕暮れの空。何千羽もの鳥が、ひとつの生き物のように形を変えて飛ぶ。
- **操作**：一羽だけに触れて、向きを変える。
- **ゲーム**：群れ全体を、山の切れ目に通す、二つに分ける、決まった形にする。一羽の向きの変化が、隣へ、またその隣へと伝わっていく。
- **一触れの急所**：群れの端の、他の鳥に影響を与えやすい位置の一羽を見抜く。
- **世界の規則**：ボイド（離れる・揃える・集まるの3規則）

### 4. 苔庭
- **背景**：雨上がりの寺の庭。石の上に苔が模様を描いている。
- **操作**：一滴の水を落とす。
- **ゲーム**：苔は斑点、縞、迷路のような模様に育つ。条件によっては、斑点が自分を複製して増えていく。庭の石（目標）を苔で包む、または苔から守る。庭の場所によって模様の育ち方が違い、新しい模様を見つけたら名前を付けて残せる。
- **一触れの急所**：模様が生まれる寸前の不安定な場所に落とした一滴が、庭全体に広がる。
- **世界の規則**：反応拡散系（グレイ–スコット模型）。発見の余地が非常に大きい。

### 5. 雪の斜面
- **背景**：静かな雪山の斜面。積もった雪は崩れる寸前で保たれている。
- **操作**：一粒の雪を落とす。
- **ゲーム**：雪が一定量を超えると、隣へ崩れて連鎖する。一粒で雪崩を起こし、谷の決まった場所まで届かせる。または、登山道だけを崩さずに残す。
- **一触れの急所**：世界全体が「崩れる寸前」に保たれていて、一粒が大雪崩を起こしうる。しかも、崩れる順番を変えても結果は同じという性質がある（アーベル砂山）。そのため運ではなく、完全に読める。
- **世界の規則**：砂山模型（自己組織化臨界）

### 6. 野焼き
- **背景**：早春の山里。枯れ草の野を焼いて、新しい芽吹きを待つ伝統。
- **操作**：一か所に火を入れる。
- **ゲーム**：火は風と草の湿り気に従って広がる。焼くべき区画だけを、一度の火入れで焼き切る。民家や林には届かせない。
- **一触れの急所**：風上か風下か、湿った帯の手前か奥か。どこに入れるかで燃え方がまったく変わる。
- **世界の規則**：延焼のセルオートマトン。ただし、火は静けさの方向性と緊張感でぶつかる可能性がある。

### 7. 小さな星系
- **背景**：静まり返った宇宙。いくつかの星と月が回っている。
- **操作**：一つの天体を、一度だけ小さく押す。
- **ゲーム**：月を安定した軌道に乗せる。他の星の引力を利用して、遠くの星へ届かせる（スイングバイ）。前に押すと、かえって遠くへ上がって遅くなる、という直感に反する法則を読む。
- **一触れの急所**：近くを通る星の引力を使うと、小さな押しが大きな軌道の変化になる。
- **世界の規則**：万有引力。現実の軌道力学に持ち帰れる。三体以上ではカオスになりやすいので、読める範囲に設計する必要がある。

### 8. 潮だまり
- **背景**：早朝の磯。潮が引いたあとの水たまりの中で、小さな粒が集まって生き物のように動いている。
- **操作**：違う種類の粒を一つ落とす。
- **ゲーム**：粒どうしは種類ごとに引き合ったり反発したりする。そこから細胞のような塊、追いかけっこをする群れ、分裂する構造が生まれる。塊を分裂させる、二つを合体させる、決まった場所へ移動させる。新しい「生き物」を見つけたら、名前を付けて残せる。
- **一触れの急所**：塊の構造の弱い一点に、合わない粒を一つ入れると、全体が組み変わる。
- **世界の規則**：パーティクルライフ。発見の余地が非常に大きい。

### 9. 菌の道
- **背景**：森の倒木の裏。黄色い粘菌が、網のように広がっている。
- **操作**：餌を一つ置く。
- **ゲーム**：粘菌は餌と餌を結ぶ最短の網を自分で作る。散らばった集落（目標）を、決まった形の網でつなぐ。実際に粘菌は、東京近郊の鉄道網に近い網を作ったことが知られている。
- **一触れの急所**：餌一つで、網全体が組み変わる。
- **世界の規則**：粘菌の行動模型（痕跡を残して、痕跡をたどる）。現実に持ち帰れる。

### 10. 墨流し
- **背景**：和紙と、水を張った水盤。
- **操作**：水面に筆で一度だけ触れる。
- **ゲーム**：墨は水の流れに沿って伸び、折りたたまれる。手本の模様を、最小の筆の回数で水面に再現する。
- **一触れの急所**：流れが引き伸ばされる場所に触れると、小さな動きが大きな模様の変化になる。ゆっくりした流れでは、逆に動かすと元に戻るという不思議な法則もある。
- **世界の規則**：流体（ゆっくりした流れ）

### 11. 生命の碁
- **背景**：縁側に置かれた碁盤。石は置かれたあと、規則に従って生まれたり消えたりする。
- **操作**：石を一つ置く。
- **ゲーム**：詰碁や詰将棋のように、「一石で、この形を動く形に変えて、あの角まで届かせる」といった問題を解く。この世界独自の規則なので、ずっと形を保つもの、点滅するもの、移動するものを、誰も知らない状態から見つけて名前を付けられる。
- **一触れの急所**：形の急所に一石置くと、まったく別の形へ変わる。
- **世界の規則**：ライフゲーム型のセルオートマトン（独自の規則）

### 12. 磁石の海
- **背景**：夜の静かな研究室。無数の小さな方位磁針が、互いの影響で揃おうとしている。
- **操作**：一つの磁針をひっくり返す。または、一か所だけ温める。
- **ゲーム**：揃った向きの領域が広がったり縮んだりする。一つの反転から、決まった形の領域を育てる。冷たいと固まり、熱いとばらばらになり、その境目の温度では、小さな変化が全体に広がる。
- **一触れの急所**：相転移の境目の温度では、一つの反転が全体に広がりうる。
- **世界の規則**：イジング模型（相転移）。現実の物理に持ち帰れる。見た目が抽象的になりやすい。

### 13. 雲の峠
- **背景**：早朝の峠。谷に雲海が広がっている。
- **操作**：地面の一点を温める。
- **ゲーム**：温められた空気は上がり、冷えて雲になる。決まった谷の上に雲を作り、乾いた畑に雨を降らせる。
- **一触れの急所**：空気が不安定な場所を一点温めるだけで、上昇気流が自分で育つ。
- **世界の規則**：対流（レイリー–ベナール対流）、雲の生成

### 14. 夜の水路
- **背景**：夜の細い水路。
- **操作**：水面を一度押す。
- **ゲーム**：この水路の波は崩れずに形を保ったまま進み、ぶつかってもすり抜ける（ソリトン）。波を作って、決まった場所でぶつけて大きな波にし、小舟を押し出す。
- **一触れの急所**：押す強さで波の速さが決まる（大きい波ほど速い）。押す順番と強さで、どこで追いつくかが読める。
- **世界の規則**：非線形波動方程式（KdV方程式）。津波の理解に持ち帰れる。

### 15. 島の生態系
- **背景**：無人の小さな島。
- **操作**：一種類の生き物を、一匹だけ放す。
- **ゲーム**：草、虫、鳥、獣は、食べる・食べられるの関係でつながっている。荒れた島を、森が戻り、鳥が帰ってくる状態にする。生態系を崩壊させずに、最小の導入で。
- **一触れの急所**：生態系の要になる一種（キーストーン種）。イエローストーン国立公園では、オオカミを戻したことで川の流れまで変わったことが知られている。
- **世界の規則**：空間的な捕食・被食関係。現実の生態学に持ち帰れる。1回の時間が長くなりやすい。

### 16. 街の灯
- **背景**：深夜の街。灯りは隣の灯りが点くと、少し遅れて点き、しばらく休む。
- **操作**：一つの灯りを点ける。
- **ゲーム**：光は波のように街を伝わる。遠くの塔まで光を届ける、自分で回り続ける渦巻きの光を作る、逆に止まらない渦巻きを一回の点灯で消す。
- **一触れの急所**：休んでいる灯りと、点く準備ができた灯りの境目。タイミングと位置が合えば、一つの点灯で渦巻きが生まれたり、消えたりする。心臓の不整脈と、それを止める除細動も同じ原理。
- **世界の規則**：興奮性媒質。現実の医学・生物学に持ち帰れる。

### 17. 氷の湖
- **背景**：凍った湖。氷に閉じ込められた小舟がある。
- **操作**：氷の一点を叩く。
- **ゲーム**：ひびは、氷にかかった力の集中に沿って走る。一叩きで、小舟から岸までの水路を割る。
- **一触れの急所**：力が集中している場所を見抜けば、小さな一叩きで長いひびが走る。
- **世界の規則**：破壊（ばねの網の応力伝播）。現実の材料力学に持ち帰れる。

### 18. 蛍の川辺
- **背景**：夏の夜の川辺。何百匹もの蛍が、ばらばらに光っている。
- **操作**：一匹の蛍を、好きな瞬間に光らせる。
- **ゲーム**：蛍は隣の光につられて、自分の光るタイミングを少しずらす。やがて全体が一斉に光り始める。全体を揃える、光の波を川に沿って流す、二つの群れに分けて交互に光らせる。
- **一触れの急所**：どの蛍を、どの瞬間に光らせるか。タイミングが合えば、一つの光が全体を引き込む。
- **世界の規則**：結合振動子（同期現象）。現実の生物、心臓のペースメーカー、電力網に持ち帰れる。

### 19. 深夜の高速道路
- **背景**：真夜中の高速道路。車の列が流れている。
- **操作**：一台の車を、一瞬だけ減速させる。
- **ゲーム**：事故も工事もないのに、渋滞が自然に生まれて後ろへ伝わっていく（自然渋滞）。一台の減速のタイミングで、渋滞の波を消す。逆に渋滞を作って、合流を助ける。
- **一触れの急所**：渋滞の波の手前で、少しだけ速度を落とす。実際に、一台の自動運転車が周りの渋滞の波を消せることが実験で示されている。
- **世界の規則**：交通流のセルオートマトン。現実の運転に持ち帰れる。

### 20. 砂丘
- **背景**：夜明けの砂丘。風が砂を運んでいる。
- **操作**：一握りの砂を置く。
- **ゲーム**：小さな砂の盛り上がりは、風によって三日月形の砂丘に育ち、ゆっくり移動し、ぶつかり合う。砂丘を動かしてオアシスを守る、道をあける。
- **一触れの急所**：小さな盛り上がりは風で自分から大きくなる。どこに置くかで、砂丘がどこに育つかが決まる。
- **世界の規則**：砂の輸送と堆積の模型。現実の地形に持ち帰れる。

## 構造の案：組み合わせ

北極星は「世界のすべての法則」なので、1つの現象に絞らず、**1つの世界の中の地域ごとに違う現象がある**形もありうる（雪の斜面、蛍の川辺、街の灯が、同じ地図の上にある）。深い層に降りると、別々に見えた現象が実は同じ原理でつながっていると気づく（雪崩・街の灯・蛍は、どれも「隣に伝わる」規則でできている）。オープンワールドの構造と、理解の層（[04-laws-and-understanding.md](04-laws-and-understanding.md)）が一致する。
