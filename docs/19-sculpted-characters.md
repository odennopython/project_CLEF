# 彫刻して骨と皮で動かす人物（試作 1.0、2026-10-29）

## オーナーの依頼

> 今の方式で、あなたの限界を超えたハードワークで、アセット並みのものを作ってください。

## 作り方を変えた

これまで（試作 0.1〜0.8）：部品（円柱、球、輪を連ねた管）を組み合わせて、毎フレーム形を作っていた。どれだけ直しても「人形」から抜け出せなかった。

今回：本物のゲームの人物と同じ構造にした。

| 段階 | 内容 | 道具 |
|---|---|---|
| 1. 彫刻 | 人体を、筋肉や骨の形（楕円体、先細りの棒、角の丸い箱）を滑らかに溶け合わせた立体として数式で定義する。腿、ふくらはぎ、二の腕、前腕、三角筋、僧帽筋、肋、頭蓋、顎、頬骨、眉の稜線、鼻、耳、目のくぼみ、口、柄を握った拳と親指、足袋、草鞋と鼻緒、帯の結び目、袴のひだ、着物のしわ、脚絆の巻き目 | `tools/bake_characters.js` |
| 2. 削り出し | その立体から、格子の上で滑らかな表面を一度だけ削り出す（Surface Nets）。表面へ頂点を寄せ、法線は立体の勾配から取る | 同上 |
| 3. 陰影の焼き込み | くぼみに溜まる影（環境遮蔽）と、布の織り目のむらを、頂点の色に焼き込む。色の境目は、近い部品の色を距離で混ぜて滑らかにする | 同上 |
| 4. 骨と皮の重み | 骨盤・腰・胸・首・頭・上腕・前腕・手・腿・脛・足（左右）と、袴の裾の18本。各頂点が骨からの距離に応じて、どの骨にどれだけついて行くかを計算する | 同上 |
| 5. 動かす | ゲームの動きが計算した関節の位置に合わせて、毎フレーム骨を回す。袴の裾の骨は、腰のひねりにはついて行くが、前後左右の傾きは打ち消して、重さで下へ垂らす | `prototype/kaeshi/index.html` |

自分は約1万8千頂点、相手は約3万8千頂点。墨の輪郭線は、同じ骨で動く皮を法線の向きに膨らませて描く。

焼き出した結果は、`node tools/bake_characters.js 0.0135` で index.html の中に埋め込まれる（約2.5MB）。

## 途中で見つけて直したこと

- 指の形の式で、2次元の値を3次元の長さの関数に渡していて、全体の距離が計算できなくなっていた。
- 面の表裏が逆で、人物の内側から反対側を見ていた（前から見ると背中のたすきが見えた）。
- 色を一番近い部品だけで決めていたため、境目がぎざぎざになっていた。
- 相手が膝をつくと、袴が板のように前へ振り上がった。袴の裾の骨を加えて、重さで垂れるようにした。

## 限界

- 人の彫刻家が作ったモデルや、本物の質感（画像）、指の関節には及ばない。
- iPhoneでの描画の重さは未確認（この環境のソフトウェア描画では、相手の頂点数が多いぶん、かなり遅くなった）。
