# 面白さの分解

## 1. 分解の観点

| 観点 | 何を見るか | 代表的な理論 |
|---|---|---|
| **① 学習・上達** | 「わかった！」「できるようになった」の瞬間がどこにあるか | ラフ・コスター『しあわせのランゲージ』：面白さとはパターンを学ぶこと |
| **② 集中（没頭）** | 難しさと自分の腕前が釣り合っているか。目標がはっきりしているか。結果がすぐ返ってくるか | チクセントミハイの「フロー理論」 |
| **③ 自分の内から湧く動機** | 自分で選べるか（自律）、できるようになっている実感があるか（有能感）、人や世界とつながっている感覚があるか | 自己決定理論 |
| ④ 手触り | 操作してから反応が返るまでの速さと質。音、振動、動きのなめらかさ | スティーヴ・スウィンク『ゲームフィール』、フィッツの法則 |
| ⑤ どんな種類の楽しさか | 感覚、空想、物語、挑戦、仲間、発見、表現、没入 | MDAフレームワーク |
| ⑥ 時間の作り | 1回にどれくらい遊ぶか。繰り返しの1周がどれくらいか | — |
| ⑦ 外から与えられる報酬との区別 | 報酬の仕組みを全部外しても面白いか | アンダーマイニング効果 |

**オーナーの指向**：①②③が中心。⑤は①②③に従う（8分類で言えば挑戦と発見）。⑥は手軽に。④は中心ではないが、②と洗練を支える要素として必要。

### ⑦ ガチャが本質的な面白さではない理由

ガチャは、いつ当たるかわからない報酬、損をしたくない気持ち、見逃したくない不安を利用する。人を**引き止める**力は強いが、**面白さ**とは別物。報酬で動かされると、遊ぶこと自体の楽しさが薄れることも知られている。

## 2. 参考ゲームの分解

オーナーが「本質的な面白さがある」と感じたゲーム。

| ゲーム | 中心になっている面白さ | 失敗したとき | 上達がどう見えるか |
|---|---|---|---|
| 将棋 | 相手の手を読む。すべての情報が見えていて、運がない | 負けた原因は自分の判断。対局後の振り返りで学べる | 段位、レーティング |
| ポケモン対戦 | 見えない情報を読み合う。パーティ構築という事前の準備。確率の管理 | 読み負けたのか、運が悪かったのかを見分けられる | レート |
| SEKIRO | 敵の行動パターンを覚えて対処する。厳しいが理不尽ではない | 死ぬたびに敵の行動を1つ覚える | ボスを倒せる |
| ELDEN RING | どこに行くかを自分で選べる。難しさを自分で調整できる | 回り道で解決できる | 倒せなかった敵を越えた瞬間 |
| 株取引 | 不確実な中での判断。仮説を立てて結果で確かめる | 損失。運と実力の区別が難しい | 長い期間の成績 |
| Kaggle | 仮説を立てて検証するループ。正確なスコア | スコアが下がる。過学習の罠 | 順位表 |

## 3. 共通する構造

6本はどれも同じループでできている。

```
① 世界の裏に、隠れた構造がある
② 観察して、仮説（頭の中のモデル）を作る
③ 仮説に基づいて判断し、取り消せない形で決める
④ 世界が、はっきりと公正に結果を返す
⑤ 予想と結果のズレから、頭の中のモデルを直す → ②に戻る
```

| | 隠れた構造 | 取り消せない決定 | 結果 |
|---|---|---|---|
| 将棋 | 相手の意図、局面の真実 | 指した一手 | 勝敗 |
| ポケモン対戦 | 相手の型と選択 | 選んだ技・交代 | 勝敗 |
| SEKIRO | 敵の行動の法則 | 行動の選択 | 生き残るか死ぬか |
| ELDEN RING | 世界の構造と秘密 | 進む道、挑む相手 | 発見するか、死ぬか |
| 株取引 | 市場の動き | 売買 | 損益 |
| Kaggle | データの裏にある法則 | 提出（1日の回数に制限がある） | スコア |

**面白さの正体**：自分の頭の中のモデルが、取り消せない決定を通して確かめられ、精度が上がっていくこと。

**本質とそうでないものの境目**：上達したものが**プレイヤーの頭の中に残る**こと。ガチャのゲームで強くなるのはアカウントだが、6本で強くなるのはプレイヤー自身。

**共通して入っていないもの**：ガチャ、ログインボーナス、物語でプレイヤーを引っ張る作り。

このループは科学の方法そのもの（観察 → 仮説 → 実験 → 修正）でもある。[04-laws-and-understanding.md](04-laws-and-understanding.md) を参照。

## 4. 設計で決める部品

| 部品 | 選択肢 | 決定 |
|---|---|---|
| 時間の主導権 | プレイヤー／世界 | **プレイヤー** |
| 結果が返る速さ | すぐ／遅れて | **すぐ** |
| 1周の長さ | 数秒〜数時間 | **数分** |
| 読む対象 | 他者の意図／世界の法則／確率 | **世界の法則** |
| 法則の種類 | 物理・自然現象／生き物／人の営み／抽象的なもの | 検討中（物理・自然現象が有力） |

## 5. 分析の途中で修正したこと

- 当初はSEKIROの表面的な特徴（弾きの音）を核に持ち込もうとしていた。6本のうち1本だけの特徴なので撤回した。
- 「CLEF＝音楽」という結びつけも根拠がないため撤回した。
- 既存ゲームのジャンル（読み合い、見切り、探究）で分類するのをやめ、構造の部品で考えるようにした。
