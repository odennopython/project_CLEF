# 二人がかりと群れ（試作 4.3〜4.4、2026-10-31）

## 作り方：攻める番を交代する

今の戦いの仕組み（判定、崩し、時間の遅れ、カメラ）は、「攻めてくる相手一人」を前提にできている。これを壊さずに二人を相手にするため、**攻める番を二人で交代する**形にした。

- **番の相手**：これまでどおり攻め、守り、かわす
- **番を待つ相手**：間合いの外（約4.5m）で自分の武器の構えを取り、ときどき鋭く回り込む。番の相手とは重ならない
- **交代**：番の相手が構え直している（回り込み中で、技を出していない）ときに、3〜6秒ごとに待っていた方が前へ出る。前へ出た相手はすぐに攻めてくる
- **一人を斬ったら**：残った方が前へ出る。二人とも斬ると、道の次へ進む
- 斬り分けた一人目の破片は、二人目を斬るまで雪の上に残る

一度に二人が同時に斬りかかってくることはない。弾きと見切りの読み（一瞬の判断）を保ったまま、**二人に囲まれる圧と、相手が入れ替わることで技の流れが切り替わる緊張**を出す。

## 重さ

二人目の人物は、形（頂点のデータ）を一人目と共有しているので、形の分は重くならない。装束・笠・面・武器・鎧の板は、それぞれ持つ。

## 道

道の二番目を、雑兵・足軽の二人がかりにした：一人 → **二人がかり** → 手練一人 → 五合目の主。

## 群れ（試作 4.4）

番を待つ相手を一覧にして、三人の群れにした。

- 番を待つ相手は、**番の相手を中心にした前の弧（左右）**に立つ。カメラの後ろへ回り込まないので、囲まれている圧がいつも画面に見える
- 交代は、待っている中から一人を選ぶ。待つ相手が多いほど、交代の間が短い（2.4〜5.2秒）
- 一人を斬るたびに、待っていた一人が前へ出る

道：一人 → 二人がかり → **三人の群れ** → 手練一人 → 五合目の主。

## まだやっていないこと

- 四人以上の群れ：描く人物が増えるので、iPhone での重さを確かめてから
- 番を待つ相手の飛び道具（弓やクナイの相手が、待ちながら射る）：判定の仕組みを、番でない相手からの攻撃に広げる必要がある
