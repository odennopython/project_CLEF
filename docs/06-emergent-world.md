# 創発世界の設計

上位方針①②③と、表現の方向性（洗練）から、創発世界に必要なことを導く。

## ① 学習・上達：秩序とカオスの境目

| 世界の性質 | 例 | ①学習 |
|---|---|---|
| すぐ止まるか、単調に繰り返す | 多くの規則 | 学ぶことがすぐなくなる |
| 完全にでたらめ（カオス） | ノイズのような世界 | パターンがないので学べない |
| **秩序とカオスの境目** | ライフゲーム | **長く残る構造、動く構造、ぶつかり合う構造があり、法則として学べる** |

**絶対条件**：世界の規則は、秩序とカオスの境目にあること。

また、創発には**非線形**な規則（要素どうしが影響し合い、足し算以上のことが起きる）が必要。

## ② 集中：核となる操作は「予測」（撤回。[07-interaction.md](07-interaction.md) で再検討）

何でもできる箱庭は目標がなく、集中が起きない。そこで核となる操作を予測にする。

```
観察する → 世界に触れる（介入）→ 結果を予測して確定する（取り消せない）
→ 時間を進める → 予測と照らし合わせる → 見つけた法則を手帳に記録する
```

| 条件 | どう満たすか |
|---|---|
| 目標がはっきりしている | 予測を当てること |
| 結果がすぐ返る | 時間を進めれば数秒でわかる |
| 柱4：決定は取り消せない | 予測の確定がそのまま取り消せない決定になる |
| 柱5：時間の主導権 | 時間を進めるのも止めるのもプレイヤー |

科学の方法（仮説 → 予言 → 観測）と同じ形。

## ③ 内から湧く動機

| 要素 | 創発世界での形 |
|---|---|
| 自律 | 何を試すか、どこを観察するかを自分で決める |
| 有能感 | 予測が当たるようになっていく。自分の手帳に法則がたまっていく |
| つながり | **発見に名前を付けて残せる**（ライフゲームの「グライダー」や、彗星に発見者の名前が付くように）。他の人の発見は静かに参照するだけで、競争はさせない |

「自分が世界で初めて見つけた」という事実そのものが報酬になる。北極星の「新しい法則の発見」と③を直接結びつける仕組み。発見の共有にはサーバーが必要なので、後の段階で作る。

## 洗練との相性

- 要素が少ない（点、粒、場）のに、深さは規則の組み合わせから生まれる（柱2そのもの）
- 画面に触れる＝世界に小石を落とす。ボタンもメニューもいらない
- 静かに動き続ける世界を眺める時間が、そのまま余白になる

## 世界のミクロな規則の候補

紙の上では決められない。面白い創発が生まれるかは、動かしてみないとわからない。

| 候補 | 内容 | 特徴 |
|---|---|---|
| ライフゲーム系 | マス目の上の、生と死の規則 | 実績があり、構造がはっきりしている。有名なので既知の発見が多い |
| Lenia | ライフゲームをなめらかにした連続版 | 生き物のような構造が生まれる。見た目が美しい |
| パーティクルライフ | 粒どうしが引き合う・反発する規則 | 少ない規則から、細胞や生き物のようなものが出てくる |
| 格子ガス | 粒の衝突の規則 | 本物の流体の法則（ナビエ–ストークス方程式）が生まれる。現実に持ち帰れる |
| 非線形の波（ソリトン） | 非線形な場 | 波から粒子のようなものが生まれる。現実の物理（粒子は場の励起）と同じ構造 |

## 次のステップ（提案）

規則を試す**実験室**（開発用の道具）をブラウザ上に作る。製品ではなく、判断材料を集めるための試作。

- 候補を切り替えて動かせる
- 触って介入できる
- 比べる基準：
  1. 秩序とカオスの境目にあるか
  2. 人間が法則として学べる構造があるか
  3. 静かで美しいか
  4. スマホで軽く動くか
