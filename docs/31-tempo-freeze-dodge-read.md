# テンポ、フリーズ、避けの見切り（試作 3.7、2026-10-30）

## オーナーの評価（試作 3.6）

> 溜めの遅らせ（ディレイ）を入れすぎると、少しテンポが悪くなる。プレイ中にフリーズするようになったので、最適化もしてほしい。避けるのが結構強いので、使いすぎると相手が見切り状態になり、避けた主人公に出際の攻撃をして崩せるようにしてほしい。見切り状態は、文字ではなく、オーラのようなものでわかるように。

## フリーズ

### 原因（再現して確かめた）

**本当に止まっていた。** 試作 3.6 で入れた「待ちの構え」に斬りかかると、構えの情報を消したあと、相手の状態が「構え」のまま1コマ残っていた。次のコマでその消えた情報を読もうとして例外が起き、**ゲームのループそのものが止まっていた**（試験で再現：`Cannot read properties of null (reading 'kind')`、その後ゲームの時間が進まない）。

### 直したこと

| 対策 | 中身 |
|---|---|
| 原因の修正 | 待ちの構えを破られたら、すぐ構えの状態を抜ける。構えの情報がないときは安全に抜ける |
| ループを止めない | どこかで例外が起きても、次のコマは必ず描く（同じ種類の不具合が出ても、画面は固まらない） |
| 初めて出る物の下ごしらえ | 火花、光、煙、斬撃、弓、矢、飛ぶ斬撃、斬り分けの破片を、始める前に一度すべて描いておく。初めて画面に出る瞬間に描き方の準備が走ると、そこで一瞬止まる |
| 矢と飛ぶ斬撃の使い回し | 撃つたびに作らず、前もって作った物を使い回す |
| 影を軽く | 影は2コマに1回描き直す。影の細かさを 1024 → 768 |

この環境での1コマの時間（中央値）は、667ms → 583ms（約12%軽く）。iPhone の実機では確かめていない。

## 避けの見切り

- 9秒の間に4回避けると、相手が**避けを読む状態**になる（7秒間）
- その間、相手の体のまわりから**青白い気が炎のように立ちのぼる**（文字は出さない）
- その間に避けると、時間はゆっくりにならず、**反撃の機会もない**。間を置かずに、避けた先へ**出際斬り**が来る（踏み込みの深い、重い一撃。弾けば防げる。当たれば大きく崩される）
- 避けを読む状態は、出際斬りを出すたびに少し延びる

避けは強い逃げ道だったが、使いすぎると読まれ、弾きを混ぜる理由ができる。
