# 有料アセットの作り方で作り込む（試作 3.1、2026-10-30）

## オーナーの要望

> 有料アセットの水準を、アセットの作り方から学んで、あらゆる手を使って作ってほしい。顔がかなり気持ち悪い。かなりの完成度、きめ細かさ、クオリティを要求している。ゼルダと言ったが、SEKIRO やエルデンリング並みの造形への作り込みが最低でも欲しい。

## 率直な前提

SEKIRO やエルデンリングの人物は、専門家の分業で、数百万ポリゴンの彫刻と、写真から作った質感（スキャン）で作られている。この環境でコードだけで同じものを作るのは現実的ではない。そう伝えたうえで、有料アセットの作り方のうち、コードで使えるものはすべて使う。

## 有料アセットの細部は何でできているか

| 層 | 中身 | 今回の対応 |
|---|---|---|
| 形 | 彫刻した高い密度の形を、軽い網に落とす | 箱からの造形（[25-modeled-characters.md](25-modeled-characters.md)） |
| 法線マップ | 織り目、毛穴、擦り傷のような細かい凹凸 | 数式で作る凹凸を、描くときに法線へ足す（素材ごとに11種） |
| 光沢マップ | 漆は鏡のよう、布は艶がなく、肌は少し艶 | 素材ごとに光沢を変え、ゆらぎと擦り傷を入れる |
| くぼみの影 | しわや目の窪みの暗さ | 焼き出しで入れる（目の窪みは暗く） |
| 光の物理に基づく描き方 | 映り込みと、光の当たり方が素材で変わる | アニメの陰の段と墨の輪郭線をやめ、光の物理に基づく材質と、夜空・月の映り込みにした |
| 小物 | 紐、縫い目、結び目、家紋 | 縅の紐を形として通す、三本撚りの縄、家紋、手甲の布巻き |

## 顔

顔の気持ち悪さは、口元と顎の造形で一番出ていた。そこを意匠で覆う（商業ゲームでもよく使われる判断で、格好よさのための選択）。

- 主人公：黒い布の面覆いで、鼻から下を覆う
- 相手：黒漆の面頬（細く鋭い鼻、頬当て）と、喉を守る三段の垂れ（よだれかけ。縅の紐と金の覆輪）
- **目は本物の眼球**：まぶたの切れ込みに眼球を入れる。白目には上まぶたの影が落ち、虹彩には放射の筋と縁の濃い輪がある。表面は濡れたように光り、空と月が映る。目は相手を見据える
- 眉と、上のまつ毛の線は、絵で描く
- 頭は 3.4mm の格子で焼き出す（前回 4.2mm）

## 細部

- 相手の鎧：板ごとに深紅の縅の紐を形として通し、上の縁に金の覆輪。胴にも、板ごとに縦の紐が並ぶ
- 主人公：羽織の背と胸に家紋（丸に三つ巴）。三本撚りの紫の縄の帯。布を巻いた手甲
- 布：袖のしわ、袴の膝のたるみ

## 残る弱点（率直に）

- 顔は、近くで見るとまだ商業品質ではない（まぶたの縁の形、目の窪みの陰）。遊ぶときの距離では目と眉が読める
- 指はまだない（手甲で包んだ拳）
- 重さ：ページは約 7.7MB。この環境での描画は前回より重い（光の物理に基づく描き方と、細かい凹凸のため）。iPhone での重さは未確認
