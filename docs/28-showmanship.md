# 「魅せ」とダイナミックさが足りない理由：なぜなぜ分析（試作 3.4、2026-10-30）

## オーナーの評価

> 動きのダイナミックさや、プレイを通しての「魅せ」が少ない。理由をなぜなぜして、構造的に複数考えてほしい。相手の動きのパターンが非常に単調なので、20倍くらいに増やしてほしい。相手の顔がぺったんこで、横から見ると米粒のよう。勝ったときは、相手が斬撃で斬り落とされ、追撃の斬撃でバラバラになるくらいでもいい。

## なぜなぜ分析

### 1. 相手の動きが単調に見える

- なぜ単調か → 出てくる連撃が少ない（前半11、後半13の連撃、技は17）
- なぜ少ないか → 連撃を一つずつ手で並べていたため、増やすほど作る手間が比例して増えた
- なぜ手で並べると増えないか → 連撃を「部品」として設計していなかった。入り・繋ぎ・決めが一体になっていて、組み替えられなかった
- **根本**：技と連撃の作り方が、組み合わせで広がる構造になっていなかった

### 2. 戦いに起伏がない（ずっと同じ調子）

- なぜ起伏がないか → 相手の間合いの取り方と、技の速さの種類が少ない
- なぜ少ないか → ほとんどの技が「前へ少し踏み込んで斬る」同じ型で、速さも中程度にそろっていた
- なぜそろったか → 技を「斬る向き」で作り分けていて、「間合い」と「緩急」の軸で作り分けていなかった
- **根本**：技の設計の軸が一つ（向き）だけだった。退きながら斬る、遠くから飛び込む、溜めきって一瞬で抜く、小さく速く刻む、の軸がなかった

### 3. 勝った瞬間に気持ちよさの爆発がない

- なぜ爆発がないか → 一閃のあと、相手が膝をついて倒れるだけ
- なぜ倒れるだけか → 人物が一つの皮で、骨に沿って曲がることしかできなかった
- なぜ曲がることしかできないか → 体を斬り分ける仕組みがなかった
- **根本**：「勝った」という結果を、体の変化で最大に見せる手段を持っていなかった。報酬の頂点が演出として設計されていなかった

### 4. 動きが地味に見える

- なぜ地味か → 姿勢と姿勢の間をばねでつないだだけで、溜め・打ち・決めの緩急が弱かった（試作 3.3 で一部解消）
- なぜ緩急が弱いか → 動きを「姿勢の目標」で作り、「時間の使い方」で作っていなかった
- **根本**：モンスターハンターやエルデンリングのような、溜めの長さと打ちの速さの差（1対3〜1対5）を、技ごとに設計していなかった

### 5. 顔に魅力がない（ぺったんこ、米粒）

- なぜ魅力がないか → 粘土方式の顔は造形の精度が足りず、横から見ると平たく前後に長い
- なぜ足りないか → コードで彫る方式では、顔のような繊細な形の作り込みに限界がある
- **根本**：顔で勝負できない作り方で、顔を見せていた。面で覆うのが正しい判断（試作 3.2〜3.4）

### 6. 自分の上達が画面に表れない

- なぜ表れないか → 弾きを続けても、見た目の変化は火花の大きさと音の高さだけ
- なぜだけか → 連続の成功を、相手の崩れ方や演出の段階として設計していなかった
- **根本**：上達の手応えを段階的に見せる「演出の段」がない（今回は未対応。次の課題）

## 今回やったこと

| 原因 | 対応 |
|---|---|
| 1 連撃が組み替えられない | 連撃を **入り・繋ぎ・決め** の三つの句に分けて設計し、組み合わせで作るようにした。句はどれも手で設計したもの（入りは間合いの取り方、繋ぎは前の技の残心から自然に出る返し技、決めは重い技・危険な技・分岐）。回転斬りの三は回転斬りの二の後だけ、のように、流れとして不自然なつながりは除く |
| 2 技の軸が一つ | 技を **17 → 43** に増やした。間合いの軸（退き薙ぎ、大薙ぎ、飛び込み斬り）、緩急の軸（居合：溜めきって一瞬で抜く、小袈裟・小逆袈裟、大袈裟）、高さの軸（面突き、下段突き、斬り上げ）、返し技（返しの袈裟・逆袈裟・斬り上げ・振り下ろし、二段突き、返しの突き、返しの体当たり）、左右の対（左袈裟、左逆袈裟、逆足払い、逆回転斬り）、回転斬りの三 |
| 3 勝ちの爆発がない | 勝負の一閃で、相手を **刀の通った面で上下に斬り分ける**。上の半身は面に沿って滑り落ち、下の半身は崩れる。笠・鎧の板・弓・面・刀は飛び散る。勝ったあとに上を入力すると、**追撃で残った塊をすべて斬る**（最大6回、塊は最大64）。血は出さない（断面は灼けた鋼の色） |
| 5 顔 | 相手も狐面（黒狐：黒漆に朱と金の隈取り）。面の下は黒い頭巾で、額から首まで覆う |

### 連撃の数

| | 以前 | 今 |
|---|---|---|
| 技 | 17 | 43 |
| 連撃（前半） | 11 | 2,783 |
| 連撃（後半） | 13 | 3,494 |

連撃の数は約250倍になった。ただし、遊んで感じる違いは「連撃の数」より「技の種類と、入り方の違い」で決まる。技の種類は約2.5倍で、20倍の体感に届いているかは遊んで確かめる必要がある。
