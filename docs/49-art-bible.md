# 49. 風の伝説の画の指針（アートバイブル、試作 7.0 時点）

[Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios)（読んだ上での採用点は末尾）の「画の基準を先に一枚で決め、全ての制作物をそこへ寄せる」考え方を取り入れた。**短く保つ**（長い文書は、良いゲームを作らない：同リポジトリ自身の計測でも、文書の多い版が最下位だった）。

## 一言

**月明かりと灯りだけで見る、静かな日本の夜。** 色は少なく、光の当たる所だけが色づく。動きは大きく、止まりは静か。

## 形の言葉

- 人物：頭と背の形で勢力が分かる（編み笠・陣笠・頭襟・兜）。遠目の影で見分けがつくこと。
- 建物：直線と水平（梁・柱・屋根の反り）。屋根の線が空を切る。
- 自然：樹・岩・山は、大きな塊に、小さな凹凸が乗る。
- 面ごとに、**空間の形**を変える（[47](47-fresh-stages.md)）：外／屋内／廊下／階段／水／砂。

## 光

- 主役の光は、月と灯り（行灯・灯籠・焚き火）。灯りは暖色、月は冷色。
- 影は冷たく、光は暖かい（世界ごとの色調整で作る：雪山＝青、紅蓮寺＝夕映え、城の広間＝灯りの暖色、水月＝青緑、風紋＝金）。
- 屋内は、天井で空を隠し、障子・金襖が灯りを返す。
- 画面を白く飛ばさない。技の光は、刃の軌跡と火花に絞る。

## 色

| 世界 | 地 | 空 | 差し色 |
|---|---|---|---|
| 白峰 | 青白い雪 | 深い藍 | 灯りの橙、朱の鳥居 |
| 紅蓮寺 | 褐色と朱 | 夕映えの紫 | 紅葉の赤、朱の柱 |
| 城 | 土と石、畳 | 暗い藍 | 桜の桃、金襖 |
| 水月の里 | 暗い青緑 | 深い藍 | 蛍の黄緑、舟の灯り |
| 風紋の海 | 月の砂 | 紺 | 大きな月、骨の白 |
| 雲上の回廊 | 金の石 | 夜明けの金 | 朱の鳥居 |

## 質感

- 平らな一色にしない（細かな濃淡・微細な凹凸・雪のきらめきを、全ての面に）。
- 布は、糸の目とゆるいしわ。金属は、鈍い鋼と、赤い刃の縁（防げない印）。
- 遠景は、ぼかして奥行きを出す。

## 動き

- ダイナミックに、しかしカクつかず、ぬるぬる。止まりは静かに（構え・残心）。
- 足は滑らせない（走る・踏みとどまる、を足運びで見せる）。

## 禁止

- 画面に文字を出す（技を得た場面と説明の箱を除く）。血の表現。画面全体を白く飛ばす閃光。髪の毛のような線の雷。蛍のような光の粒で刃物を表すこと。

## 確かめ方（見た目を変えたとき）

1. 縦長の画面で、**前の版と並べて撮る**（雪山の戦い、石段の戦い、屋内の戦い、技の瞬間）。
2. 指針の「禁止」に当たる物が無いか、見る。
3. 気づいた点を記録して直す。**実機（iPhone）での見え方と重さは、未確認のまま**のことが多いので、必ず「未確認」と書く。

## 採用したもの／しなかったもの（Claude Code Game Studios を読んで）

- 採用：①画の基準（アートバイブル）を先に短く決める ②見た目を変えた作業は、**起動して、見て、画像を残す**まで閉じない（既にやっている）③縦に一本通す検証（バーティカルスライス）の考え方。
- 採用しない：49のエージェントと74の技（作業手順）を丸ごと入れること。**このリポジトリは、一人の作り手と一つのゲームで、手順の重さは益より害が大きい**。同リポジトリ自身の計測でも、文書が多い構成が、遊んだ評価では最下位だった。
- 注意：このリポジトリは**手順と組織の雛形**で、画（絵・3D）を作る道具ではない。画の質を直接は上げない。
