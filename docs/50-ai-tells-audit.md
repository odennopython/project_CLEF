# 50. 「生成AI丸出し」の洗い出しと対処（試作 7.3、2026-11-16）

オーナーの依頼：生成AIが作ったと一目で分かる、きつい部分を全部洗い出して直す。
方法：縦長画面でタイトル・メニュー・戦闘・チュートリアル・技獲得・敗北の各画面を撮り、見た目と文面を点検した。

## 直したもの（7.3）
| 症状 | 対処 |
|---|---|
| タイトルが中央寄せ・字間広めの定型配置で、操作説明の小文字が並ぶ | 縦書き（右寄せ）、朱の落款、操作説明の行は削除 |
| タイトル画面が、起動時の演出の残りで強くブレていた | タイトル中は画面効果（ズーム・色ずれ・画角）を強制的にゼロに |
| メニューが「丸い枠のボタンの中央縦並び」という定型 | 左寄せの罫線リストに。文言を短く |
| 技の獲得カードで長い名前（神纏切り）が折り返し、「り」だけ落ちる | 名前の長さで文字の大きさを自動調整、折り返さない |
| チュートリアルと画面下のヒントが重なる | チュートリアル表示中はヒントを隠す。操作の円に矢印を添える |
| 開発用の「記録」「試遊の記録を写す」が常時見える | 開発者モードに入ったときだけ表示 |
| 画面全体が白く霞んで見える | 霧の濃さと奥行きぼけを弱め、コントラストを回復 |

## 直せていないもの（正直に）
- **人物・建物・木の形そのもの**：箱・球・円錐から作った造形で、ここが一番「作り物」に見える。直すには生成した3Dか大規模な造形が必要で、この環境では画像・3Dを生成できない（[48](48-asset-pipeline.md)）。
- **地図の絵**：SVGをコードで組んだもの。絵として描き起こすには画像生成が要る。
- 人物の顔・髪・衣のバリエーションが少ない。敵の見分けは帽子と色が中心。
- 固有名詞・技名・世界名の和風の語感が、定番の組み合わせに寄っている面がある。主観的な判断で、オーナーの目で見て決めてほしい。
- 実機（iPhone）での見え方・重さは未確認。

## 追補（試作 7.4）：字体と、白い霞
- **字体**：Web字体の外部読み込み（Shippori Mincho＋Zen Kaku Gothic）をやめた。見出し・技名・タイトルは **Yuji Syuku**（筆の書体）、本文と操作表示は **Zen Old Mincho**。使う文字だけに絞った（サブセット化）woff2を、HTMLに埋め込み。通信に依らず、端末で必ず同じ字体で出る。以前は、外部が読めないとき端末の標準字体に落ち、見た目が不揃いになる弱点があった。出典：いずれも Google Fonts の OFL ライセンスの字体（google/fonts リポジトリ）。
- **画面の締まり**：最終段で黒を締め、中間調にS字をかけた。雪山の七合目は霧の色と濃さを調整。撮り比べで、奥行きとコントラストは増した。
- 未確認：実機での字体の見え方と、画面の重さ。公開HTMLは約10MBに増えた（字体の埋め込み分）。
