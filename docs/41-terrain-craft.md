# 41. 地形の作り込み：九合目まで飽きさせないために（試作 4.7）

## オーナーの依頼（2026-10-31）

> 地形に関してはゲームの雰囲気だから、かなり丁寧に作り込んで欲しい。十合目になった時に飽きがこないように、丁寧に魂を込めて作ってね。

## なぜ飽きるのか（試作 4.6 の地形の分解）

| 原因 | 試作 4.6 の状態 |
|---|---|
| 1. 登っている感じがない | 道が九合目までずっと同じ高さ。山を登る遊びなのに、平らな所を歩いているだけ |
| 2. 遠景がどこでも同じ | 空・月・星・遠くの山並みは、どの合目でも変わらない。頂上も見えない。進んだ実感がない |
| 3. 一つの合目の中の五つの開けが同じ | 同じ丸い広場に灯籠が四つ。違うのは、散らした木の種類だけ |
| 4. 空気が動かない | 雪が降るほかは、止まった絵 |
| 5. 縦の画面で見える所に物がない | iPhone を縦に持つと、画面の横幅は中央から左右に約13度しかない。道の横8〜12mに置いた物は、戦っている間も歩いている間も、ほとんど映らない（撮って確かめて分かった） |

## お手本から学んだこと（調べた事実）

| お手本 | 事実 | ここでの使い方 |
|---|---|---|
| Journey | 砂漠から雪へ、場面ごとに色と光と形だけで別の場所に見せた（[Game Developer: art design of Journey](https://gamedeveloper.com/art/video-deconstructing-the-art-design-of-i-journey-i-)）。色の移り変わりは画家の扱いに任された（[Copcomm](https://digital.copcomm.com/i/77744/44)）。旅の目的地は遠くに見える山で、そこへ向かって進む（[Wikipedia: Journey](https://en.wikipedia.org/wiki/Journey_(2012_video_game))） | 合目ごとに夜の時刻と光を進める（麓の深い夜 → 霧 → 月の冴える崖 → 吹雪 → 夜明け前）。白峰の頂がいつも行く手に見え、登るほど大きくなる |
| 「ウィニー」（目印）の考え方 | 全体から見える大きな目印、区域の中で見える目印、部屋の中で見える目印、の三段で置く。目印は隠してから、近くでまた見せると効く（[tancoque.design.blog](https://tancoque.design.blog/)） | 三段：白峰の頂（全体）／合目の山小屋・大鳥居・凍った大滝（区域）／開けの出口の情景（開け） |
| 変化と繰り返しの釣り合い | 繰り返しすぎは退屈、変えすぎは混乱。形が同じでも、飾り・遊び・雰囲気を変えれば新しく感じる（[itch.io devlog: levels that aren't boring](https://itch.io/devlog/1131262/making-levels-that-arent-boring-even-when-theyre-all-the-same-shape.amp)） | 開けの形と広さ（戦いの決まり）は同じに保ち、開けごとに飾りと雰囲気を変える |

環境で物語る（言葉を使わず、置いた物で出来事を伝える）ことは、上の資料には直接の出典がない。ここでは設計の判断として行う。

## 作ったもの

### 1. 登る道（坂と石段）

- 開けは平らな台地（戦う広さは今までどおり、前後7.6mは平ら）。台地と台地の間を、坂か石段で登る。
- 合目ごとに登り方を変えた（下の表の「登り」）。一合目は坂と石段が半々、三合目（霧の参道）は石段の参道、六合目は氷の崖の石段、八合目の尾根は上り下りがある、九合目は全部急な石段。九合目までで約140m登る。
- 石段は段ごとに石の色が少しずつ違い、踏面の奥にだけ雪が残る（手前は踏まれて石が出る）。両脇に縁石。
- 歩くとき、足は段の上面を踏む。腰は段の中ほどの高さに沿う。石段と上り坂では足取りが少し遅くなる。カメラは主人公の高さについて行き、行く手の高さを見る。
- 戦いは今までどおり平らな所で行う（原点に開けを置き、歩き着いたら世界ごと高さもずらす）。

### 2. 道の表面

先に登った者たちの足跡と、踏み跡の二本の筋が残る雪の道。三合目は参道の石畳、四・八・九合目は岩の道、六合目は白いひびの入った氷。縁は雪に溶ける。

### 3. 遠景と時刻

| 合目 | 光と時刻 | 遠景 |
|---|---|---|
| 一 | 月の高い深い夜、星が濃い | 白峰の頂がわずかに見える |
| 二 | 竹林の青い夜 | |
| 三 | 霧で月がにじむ。星は見えない | 霧が濃く、遠くの山並みも頂も隠れる |
| 四 | 月が冴える。星が最も濃い | 崖の下に雲海 |
| 五 | 雪原を月が照らす | 雲海。山並みが少し下に沈む |
| 六 | 氷の青い光 | 雲海が上がってくる |
| 七 | 白い霧 | |
| 八 | 吹雪で月も星もほとんど見えない | 地平がわずかに明るむ |
| 九 | 夜明け前。地平が赤く染まる | 雲海がすぐ下。山並みは足もとより低い。頂は大きく迫る |

月の光の色と強さ、空と地の照り返し、星の濃さ、霧の濃さは、合目の境を歩いて越える間にゆっくり移る。

白峰の頂は、主峰と三つの肩でできている。尾根と谷筋が縦に刻まれ、谷には岩が出る。裾は霞んで空に溶ける。

### 4. 45の開けの情景

開けの形と広さは同じまま、開けごとにその場所にしかない物を置いた。主役の物は**縦の画面に映る所**（開けの出口の両脇。道から3〜6m、奥へ9〜14m）に置き、戦っている間は背景に、歩いて近づく間は目印になるようにした。

| 合目 | 一 | 二 | 三 | 四 | 五（主） |
|---|---|---|---|---|---|
| 一 | 御神木（注連縄と紙垂、玉垣） | 焚き火の跡と天幕（まだ熾火が赤い） | 古い墓と大きな枯れ木 | 倒木と、突き立った刀 | 一の鳥居と幟 |
| 二 | 竹垣の小径 | 筧と蹲踞（落ちる水がそのまま氷柱に） | 地蔵の列と風車（風で回る） | 伐った竹の束 | 茶屋（野点傘と緋毛氈の縁台） |

### 5. 先に挑んだ者たちの跡

雪に突き立った刀と、傾いた笠。道の脇に、一合目では一つ、九合目では十六。九合目の岩の足場は、まわりに刀が並ぶ。言葉を使わずに、この山で倒れた者の多さを伝える。

### 6. 動く空気

- 霧の帯：地面すれすれを、薄い帯がゆっくり流れる（三・七合目で濃い）。顔の前は塞がない。
- 竹の葉：二合目で、くるくると舞い落ちる。
- 細氷：六・七・九合目で、空気中の氷の粒が光を受けてまたたく。
- 風車は風で回り、幟と祈りの旗ははためく（吹雪の尾根では激しく）。焚き火の炎はゆらぐ。
- 動く物は、見えている合目の物だけ動かす。

## 重さ

- 静かな物は、合目ごとに材質ごとに一つの形にまとめた（描く回数を減らす）。
- 樹氷・杉・竹の細かさを、見た目が変わらない所まで落とした。
- 描く合目は、いる合目と、70m以内に近づいた次の合目だけ。
- 測った値（ソフトウェア描画、縦長の画面）：一コマに描く回数は約150〜210、三角形は約66万〜96万。三角形の約60万は人物（体・頭・影）で、地形を作り込む前から同じ。地形の分は約10万〜35万。

## 試験

| 試験 | 結果 |
|---|---|
| 九つの合目と45の開けを、縦長の画面（iPhone と同じ比）で、戦いの視点と歩いて近づく視点の両方から撮った | 開けの出口の情景が、戦いの背景と近づく目印に入ることを確かめた。直した点：横に置いた情景が映らない（出口の両脇へ移した）、白峰が三角のテントに見える（裾を広く、尾根と谷筋と岩場を刻んだ）、霧の中で遠くの山並みが黒く浮く（霧の濃さで薄く）、吹き溜まりが青い円盤に見える（取り除いた）、氷と笠が金属のように光る（材質を直した） |
| 一合目の二つ目の開けから、焚き火の脇を通って石段を登る | 足は段を踏み、カメラは高さについて行く。上の台地に三人の相手が空を背に待つのが見える |
| 合目の境を越える（一→二、四→五、九の主） | 歩いて次の合目へ。合目の名が出て、進み具合が保存される。九合目の主の後は終わりの画面 |
| 戦いの決まり、負けてやり直す、iPhone 表示（play） | 前の版と同じ結果。例外なし（弾いた直後の反撃の数え漏れは、試験の測る時間の問題で、前の版の検証と同じ） |

動く空気（霧の帯、竹の葉、細氷、風車、幟、旗、焚き火）は、例外なく動いていることまでは確かめた。静止画では動きの良し悪しは判断できないので、実際に見て判断してほしい。

## まだのこと

- 十合目（頂上）は、主が決まってから作る。夜明けの頂は、九合目の空と白峰で予告してある。
