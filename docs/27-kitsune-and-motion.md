# 狐面と、動きの引っかかりの解消（試作 3.2、2026-10-30）

## オーナーの要望

> 顔はかなり気持ち悪い。古典的な狐面をかぶせて誤魔化そう。体や動きの問題（カクつく、動きが不自然、ダイナミックさが足りない、ちょこちょこ動いて地味、引っかかってカクカクする）を解決してほしい。

## 狐面（主人公）

古典的な白い狐の面を、形と絵で作った。

- 形：顔を覆う殻から、鼻先が狐の口吻として前へ伸びる。頬はわずかに膨らむ。尖った三角の耳（内側は朱）。後ろへ回る朱の結び紐
- 絵：目の周りの朱と金の隈取り（目尻へ跳ね上がる）、細く吊り上がった黒い目の穴、朱の麻呂眉、額の宝珠（朱の炎と金の玉）、黒い鼻先、口の端が吊り上がる朱の笑み、頬の朱の線と黒い髭の点
- 質感：白い漆のような、ほどよい艶

相手は黒漆の面頬のまま。

## 動きの問題の原因と解決

| 症状 | 原因 | 解決 |
|---|---|---|
| 引っかかってカクッとする | 打撃や弾きの瞬間に、時間を**完全に止めて**いた（80〜420ms）。止まった画面から急に元の速さへ戻るので、引っかかりに見えた | 完全には止めず、ごくゆっくり（4%）にする。戻るときは一気に戻さず、約70msかけて滑らかに速さを戻す |
| ちょこちょこ動く | 相手が回り込む向きを0.6〜1.3秒ごとに切り替えていた。速さも、次の瞬間に満速、止まるときは即停止だった | 回り込む時間を1.1〜2.0秒に延ばし、向きは35%の確率でしか変えない。速さに慣性を入れ、重さのある体のように加速・減速する |
| 足が細かく動く | 足と体のわずかなずれ（0.17）でも、すぐ小さな一歩を踏んでいた | ずれが0.3を超えるまで踏まず、一歩はゆったり（125 → 170ms） |
| 構えが止まって地味 | 構えの姿勢が完全に静止していた | 重心がゆっくり左右に移り、体がわずかにひねられ、刀先が小さな円を描く「生きている構え」にした |
| コマ落ち | 描画が重い | 描く解像度の上限を下げた（画面の 1.75倍 → 1.5倍） |

## 残る弱点（率直に）

- 動きはまだ、手付けのキーフレームではなく、姿勢の間をばねでつないでいる。本当にダイナミックで自然な動きにするには、構え・打ち・振り抜き・足運びを手付けで作り直す段階が要る
