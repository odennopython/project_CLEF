# 狐面と、動きの引っかかりの解消（試作 3.2、2026-10-30）

## オーナーの要望

> 顔はかなり気持ち悪い。古典的な狐面をかぶせて誤魔化そう。体や動きの問題（カクつく、動きが不自然、ダイナミックさが足りない、ちょこちょこ動いて地味、引っかかってカクカクする）を解決してほしい。

## 狐面（主人公）

古典的な白い狐の面を、形と絵で作った。

- 形：顔を覆う殻から、鼻先が狐の口吻として前へ伸びる。頬はわずかに膨らむ。尖った三角の耳（内側は朱）。後ろへ回る朱の結び紐
- 絵：目の周りの朱と金の隈取り（目尻へ跳ね上がる）、細く吊り上がった黒い目の穴、朱の麻呂眉、額の宝珠（朱の炎と金の玉）、黒い鼻先、口の端が吊り上がる朱の笑み、頬の朱の線と黒い髭の点
- 質感：白い漆のような、ほどよい艶

相手は黒漆の面頬のまま。

## 動きの問題の原因と解決

| 症状 | 原因 | 解決 |
|---|---|---|
| 引っかかってカクッとする | 打撃や弾きの瞬間に、時間を**完全に止めて**いた（80〜420ms）。止まった画面から急に元の速さへ戻るので、引っかかりに見えた | 完全には止めず、ごくゆっくり（4%）にする。戻るときは一気に戻さず、約70msかけて滑らかに速さを戻す |
| ちょこちょこ動く | 相手が回り込む向きを0.6〜1.3秒ごとに切り替えていた。速さも、次の瞬間に満速、止まるときは即停止だった | 回り込む時間を1.1〜2.0秒に延ばし、向きは35%の確率でしか変えない。速さに慣性を入れ、重さのある体のように加速・減速する |
| 足が細かく動く | 足と体のわずかなずれ（0.17）でも、すぐ小さな一歩を踏んでいた | ずれが0.3を超えるまで踏まず、一歩はゆったり（125 → 170ms） |
| 構えが止まって地味 | 構えの姿勢が完全に静止していた | 重心がゆっくり左右に移り、体がわずかにひねられ、刀先が小さな円を描く「生きている構え」にした |
| コマ落ち | 描画が重い | 描く解像度の上限を下げた（画面の 1.75倍 → 1.5倍） |

## 残る弱点（率直に）

- 動きはまだ、手付けのキーフレームではなく、姿勢の間をばねでつないでいる。本当にダイナミックで自然な動きにするには、構え・打ち・振り抜き・足運びを手付けで作り直す段階が要る
- iPhone での重さは未確認（ページは約 7.9MB）

## 試作 3.3（2026-10-30）

オーナーの評価：「髪と狐面が干渉して、面の中から髪が生えている。動きはゲームだからダイナミックに。ただし崩れたり、ふにゃっとしたり、ちょこちょこしたりはだめ。顔が細長すぎて、横から見ると米粒のよう。モンスターハンターやエルデンリングの骨格と動きを見習って、自然だけどダイナミックに」。

### 顔と面

| 問題 | 原因 | 直し方 |
|---|---|---|
| 面の中から髪が生える | 前髪と顔の前の房が、面を突き抜けていた | 主人公は前髪と顔の前の房を作らない。髪は頭頂と後ろへ跳ねる房だけ |
| 横から見て米粒のよう | 頭も顔も前後に長く、面も前へ大きく突き出していた | 頭と顔の前後の長さを詰めた。面は顔に沿う浅い殻にし、顔の横まで回り込ませた。鼻先の突き出しを小さくした |
| 面の横から肌がのぞく | 面が前半分だけを覆っていた | 面の下に黒い頭巾（顔全体、頬、首を一周）。耳も頭巾の中 |
| 隠れた顔の絵が透ける | 面の下の顔に眉と目を描いていた | 主人公は顔の絵と眼球を描かない |

### 動き：モンスターハンターやエルデンリングに学ぶ

両作の動きに共通するのは「溜め → 一瞬の打ち → 決めの一拍 → 戻り」と、体が姿勢にきびきび追いつく硬さ（崩れない）。

- **決めの一拍**：振り抜いた形で一拍止める（袈裟・逆袈裟 85ms、振り下ろし 120ms、反撃 110ms）。重い技は振りかぶりでも溜める（振り下ろし 50ms、反撃 60ms）。打ちの速さは変えない
- **硬いばね**：揺れ戻りがなく（減衰 1.0）、速く追いつく（体 4.4 → 6.2、斬りの間 10 → 13）。柔らかいばねは、姿勢が崩れてふにゃっと見える原因だった
- 入力の受け付け（打ちの瞬間、次の入力を受け付ける時刻）は変えていない
