# 47. 新鮮に感じるステージとは（試作 6.1）

## オーナーの指摘（2026-11-04）

> ステージが、最初の山の焼き回しになっていないか。似ている。どんなステージだと新鮮感を感じるか、どんなステージだとその変化を楽しめるか、という視点から入ってほしい。紅葉の寺堂や、城（城下→城内→天守閣）など。他のステージと異なる特色をよく考えてほしい。

**指摘は正しい。** 試作 6.0 の世界2〜5は、同じ「外の道」の仕組みのまま、地面の色・空・小物を替えただけだった。違いは色と飾りの一軸にとどまり、歩いたときの形（開けた野外の一本道）は白峰と同じだった。

## 新鮮さの五つの軸（設計の判断）

調べた事実から、ステージの違いを五つの軸に分けた（軸の分け方は設計の判断）。

| 軸 | 内容 | 6.0の世界2〜5 |
|---|---|---|
| ① **空間の形** | 歩く形：屋外／屋内／廊下／階段／水の上。見える遠景と天井の有無 | 同じ（野外） |
| ② 光と色 | 時刻、主役の色、光源（月・灯・炎） | 違う |
| ③ **戦いの決まり** | 空間と結びついた決まり（廊下で横に避けられない、など） | 白峰の決まりの再利用 |
| ④ 敵の種類と癖 | 勢力、武器、動き | 違う |
| ⑤ 場所の役割 | 何をする場所か（寺、城、市場…）。置かれた物が語る | 弱い |

**規則**：新しい世界は、①の**空間の形**を必ず変え、③か④のどちらかも変える。①を変えずに色だけ替えても、新鮮には感じられない。ただし変えすぎない（逆U字）：戦いの核は変えず、一つの世界で変えるのは①＋一つか二つ。

## 世界の作り直し（試作 6.1）

世界2〜4を作り直した。並びは、起承転結になるように、**外→中→上→水→砂**と空間の形を変えていく。

### 世界2「紅蓮寺」：紅葉の寺堂 — 外から、堂の中へ
| 景色 | 空間の形 | 決まり |
|---|---|---|
| 壱 仁王門の石段 | 屋外。急な石段と仁王の門、紅葉 | なし |
| 弐 紅葉の参道 | 屋外。紅葉が吹き荒れる | 吹雪（紅葉の風：追い風・向かい風） |
| 参 **本堂** | **屋内**。畳、朱の柱、梁、障子の灯り、金の仏 | なし（天井の下で、月も星も見えない。一変化：景色が閉じる） |
| 肆 **回廊** | **廊下**。片側が障子、片側が庭。幅が狭い | 細い道（横へ大きく避けられない） |
| 伍 五重塔と奥の院 | 屋外・高所の足場。塔を背に | 足場 |
| 主 | 韋駄天（疾風断ち）。仏法の守護神で、足が速いことで知られる | 遠くから詰める |

### 世界3「城」：城下→城内→天守閣 — 横へ広がり、上へ登る
| 景色 | 空間の形 | 決まり |
|---|---|---|
| 壱 **城下町** | 屋外の**通り**。町家が両側に並び、行灯と桜 | なし |
| 弐 **大手門と桝形** | 高い石垣に囲まれた**中庭**。門をくぐる | 待ち伏せ（石垣の陰から） |
| 参 **御殿の大広間** | **屋内**。金の襖、畳、燭台、床の間 | なし（広い。燭台の灯りが頼り） |
| 肆 **天守への階** | **狭い階段**を、層ごとに登る。床が高くなる | 細い道 |
| 伍 **天守閣** | **最上階**。屋根の下で、四方は吹きさらしの縁。大きな月と雲 | 足場 |
| 主 | 天守の鬼武者（鬼面）。名を捨てた城主 | 鬼面なしでは崩せない |

### 世界4「水月の里」：水の上
白峰・寺・城は、どれも**石と木の地面**だった。ここは水。板道、舟、湖上の舞台。霧と蛍。
主は水鏡の舞手（輪華）：波紋のように円を描いて斬る。

### 世界5「風紋の海」：砂
遠景を山並みではなく**何もない平らな地平**にし、大きな月と風紋と沈んだ船だけにする。引き算の景色。

## 率直な限界
- 屋内の景色は、天井の梁と壁（障子・金襖）、畳、柱、燭台で作った**第一版**。細部（絵、仏像の造形、町家の作り込み）は粗い。
- 「戦いの決まり」の新しいもの（障子が破れる、燭台が消える等）は、まだ入れていない。今は既存の決まり（細い道・待ち伏せ・足場・風）を、空間の形と結びつけて割り当てた。次の課題。
- 五つの軸の分け方と「①を必ず変える」は、調べた事実から導いた設計の判断で、遊んで確かめる必要がある。
