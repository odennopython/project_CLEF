# 白峰の山：壮大な道のりのレベルデザイン（提案、2026-10-31）

## オーナーの方針（決定）

> 敵の種類は、根幹的なものを50種類くらいまで増やす予定。山を登るのは良いアイデアだが、かなり壮大な道のりにしたい。今のボスは五合目くらいのレベル感。ただし一合目につき一人のボスというより、もう少し凝ったレベルデザインにして、頂上までをかなり長い道のりにしたい。

## 二つの達成感の対比

決定事項（[01-decisions.md](01-decisions.md)「壁の形」）にある「たどり着く達成感」と「越える達成感」を、山の上でそのまま交互に置く。

- **たどり着く**：静かな道（探索の区間）。急かされない。景色が変わり、山小屋の灯りが見える
- **越える**：戦いの区間と、合目の主

## 山の全体（十合目）

今のボス「白峰の浪人」は五合目の主。夜の麓から登り始め、頂上で夜が明ける。

| 合目 | 景色と地形 | 地形の法則（戦いに効く） | 主に出会う敵 | 主 |
|---|---|---|---|---|
| 一 | 麓の杉林、雪の参道、石灯籠 | なし（基本を学ぶ） | 野伏り（刀・棒）、雪狼 | なし（最初の手練が門番） |
| 二 | 竹林と沢、細い道 | 竹が刃を止める（横薙ぎが竹に当たると止まる） | 槍、鎖鎌、二人組 | 槍の老兵 |
| 三 | 霧の参道、古い社 | 霧で遠くが見えない（起こりが近くまで見えない） | 影の流派（虚）、忍び | なし（霧の中の追跡者） |
| 四 | 吊り橋と崖、岩の道 | 狭い（横に避けられない区間がある） | 弓、薙刀、崖上の射手 | 弓の兄弟（二人） |
| **五** | **山小屋と鳥居、雪原** | なし | 浪人の弟子たち | **白峰の浪人（今のボス）** |
| 六 | 凍った滝、氷の斜面 | 氷（踏み込みが滑って伸びる。避けが遠くまで流れる） | 大太刀、剛の流派 | なし（滝の上の門番） |
| 七 | 樹氷の森 | 樹氷の陰から襲われる | 人の手練（獣と妖は出さない：オーナー決定） | 樹氷の主（金砕棒の頭） |
| 八 | 吹雪の尾根 | 風（向かい風で技が遅れ、追い風で速まる。風向きは変わる） | 飛刃、天狗の面の剣士 | 天狗 |
| 九 | 岩稜と鎖場 | 足場が限られる（一歩しか退けない） | 手練の混成、二流派を混ぜた剣士 | 二刀の剣聖 |
| 九（改） | — | — | — | **白狐の剣士**（オーナーの判断で九合目の主に） |
| 十 | 頂上の社、日の出 | なし | — | 未定（改めて考える） |

### 頂上の相手：白狐の剣士

主人公と同じ白い狐面の剣士。**それまでの道のりで、プレイヤーがどう戦ってきたかを覚えて戦う**（[10-boss-angles.md](10-boss-angles.md) の案E「自分を学ぶボス」）。弾きに頼ってきたなら弾きを崩し、避けに頼ってきたなら避けを読む。最後の壁は、自分自身の癖。題の「風」は、この剣士と主人公の物語の芯にする（物語は言葉で語らず、景色と相手で見せる）。

## 一つの合目の中身：区間の組み合わせ

一つの合目は **5〜8の区間** と、合目の **山小屋**（休み処）でできている。区間は種類を組み合わせる。

| 区間の種類 | 中身 |
|---|---|
| 静かな道 | 戦いのない探索。景色、足跡、遠くの灯り。脇道に隠れた物（社の絵馬、古い刀） |
| 一騎打ち | 手練一人と向き合う |
| 待ち伏せ | 道の途中で、脇から急に斬りかかられる（起こりを読む練習） |
| 二人がかり | 二人を同時に相手にする（片方を弾きながら、もう片方の位置を見る） |
| 群れ | 雑兵を何人も（一人ずつは弱い。囲まれないように間合いを使う） |
| 試し | 戦いではない技の試し（吊り橋の上で矢を弾きながら渡る、など） |
| 主 | 合目の主（すべての合目にいるわけではない） |

**道の分かれ**：合目の中で道が分かれる（尾根道と沢道など）。道ごとに出会う区間が違う。どちらを選ぶかは取り消せない。

**ローグライク性**：区間に出てくる敵の顔ぶれ、待ち伏せの場所、天気は、通るたびに少し変わる（合目ごとの出会いの表から選ぶ）。法則は変わらない（柱1）。負けたら山小屋からやり直すが、同じ区間でも同じ戦いにはならない。

**山小屋**：焚き火で休み、**誓い**（ルールの取引）を選び直せる。社の証がここにも積もる。

## 敵の体系（根幹の50種）

50種を一つずつ作るのではなく、**組み合わせの体系**で作る（柱2：法則を足すのでなく、組み合わせで深くする）。

| 軸 | 種類 |
|---|---|
| 格 | 雑兵（群れで出る）、手練（一騎打ち）、主（合目の主） |
| 武器 | 刀、大太刀、槍、薙刀、鎖鎌、二刀、棒、弓、素手、忍具 |
| 流派（戦術の重み） | 居合、旋風、弓、剛、影、飛刃、待ち … |
| 固有の法則 | 敵ごとに一つだけ（例：弾かれても怯まない、虚が半分、斬撃を弾き返すと当たる） |
| 体 | 人（今の体の仕組みの使い回し）、獣、妖、巨体 |

目安の内訳：

- 人の手練・雑兵：約35種（武器 × 流派 × 法則の組み合わせ。体の仕組みは今のものを使い回せる）
- 獣・妖：約10種（新しい骨組みが要る）
- 主：約5〜7体（固有の大技と、二つ目の構え）

### 率直な見積もり

今の白峰の浪人一人に、造形・動き・行動エンジンでかなりの手間がかかった。50種を同じ密度で作るのは、今のやり方（コードで人物を作る）では現実的に重い。

- **人の敵**は、体の仕組み・動き・行動エンジンを使い回し、**武器と装束と戦術の重みと法則**を変えて作る。これは今の仕組みの延長で作れる（1種あたりの手間は、浪人の一部）
- **獣・妖・巨体**は、骨組みと動きを新しく作る必要があり、手間が大きい。ここは本番の制作体制（人物の素材、[18-character-pipeline.md](18-character-pipeline.md)）の判断と結びつく
- **武器**（槍、薙刀、鎖鎌、二刀、弓）は、それぞれ間合いと技の形が違うので、武器ごとに技の姿勢を作る必要がある

## 頂上のあと：段

頂上の白狐を制すると、山全体の **段** が一つ上がる。段ごとに、山に法則が一つ加わる（敵が誓いを持つ、二流派を混ぜる、天気が厳しくなる、主が二つ目の構えを最初から使う…）。何度でも登り直せる、長い壁。

## 次の一歩（提案）

壮大な山の全体を一度に作るのではなく、**一合目〜五合目の縦の切り身**を先に作り、旅として楽しいかを確かめる。

1. 区間の仕組み（静かな道、一騎打ち、待ち伏せ、二人がかり）と、山小屋での再開
2. 人の敵を4〜6種（野伏り、槍、鎖鎌、弓、影、浪人の弟子）
3. 地形の法則を二つ（二合目の竹、四合目の狭い道）
4. 五合目の主として、今の白峰の浪人を置く

## 判断が必要なこと

1. **負けたら直前の山小屋から**でよいか（麓からではない）
2. **獣・妖・巨体**を敵に入れるか（人だけで50種にするか）。入れるなら、制作の手間が大きく増える
3. **頂上の相手を「自分の癖を学ぶ白狐の剣士」**にする案でよいか
4. 次の一歩として、**一〜五合目の縦の切り身**から作り始めてよいか
