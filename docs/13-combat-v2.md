# 戦闘システム v2（試作 0.4）

## オーナーの評価（2026-10-29、iPhoneで試した後）

- 操作がわかりにくい。ただし、これくらいシンプルな方がいい。
- 操作は今10点。避けて斬るだけ？ 避けたらカウンターに繋げたい。
- 下・上・左・右のフリックで、スタイリッシュに爽快に。でもSEKIROのように本質的に面白く戦わせて。
- 見た目：指の関節以外の人体を再現してほしい。実際より激しく大きく動いてよい。刀はモンハンのように大げさに、大太刀に。
- 視点が近すぎる。もう少し離れて、自分を少し小さく。

## わかりにくかった原因

同じフリックが、タイミングによって別の意味になっていた（判定の時間内なら返し、それ以外なら移動）。どの瞬間に何が起きるかを、プレイヤーが予測できなかった。返す向きの法則（流し）も、説明なしでは誰も気づけない。

## 新しい原則

**向きの意味は、いつでも同じ。タイミングが変えるのは「質」だけ。**

SEKIROも同じ作りになっている。弾きのボタンはいつ押しても「構える」で、刃が届く直前に押した場合だけ「弾き」になる。

## 操作

| フリック | いつでも | ちょうど良い瞬間なら |
|---|---|---|
| **上** | 斬る（続けて3連撃） | 相手の動き出しに合わせれば「出鼻」：攻撃を断ち切る |
| **下** | 受ける（構える） | 刃が届く直前なら「弾き」：相手の体幹を大きく削り、反撃の機会が生まれる |
| **左・右** | 避ける | 刃が届く直前なら「見切り」：時間がゆっくりになり、反撃の機会が生まれる |
| **上（反撃の機会に）** | — | 「反撃」：跳び込んで大きく斬る |
| **上（相手が崩れたら）** | — | 「一閃」 |

### 赤く光る技（弾けない）

| 技 | 対処 |
|---|---|
| 薙ぎ払い | 左右で避ける（見切りなら反撃へ） |
| 突き | 左右で避ける。または刃が届く直前に上で踏み込み、刃を踏みつける「見切り踏み」（体幹を大きく削る） |

## SEKIROの本質との対応

| SEKIROの本質 | 0.4での形 |
|---|---|
| 攻め続けないと、相手の体幹が回復する | 相手の体幹は、崩しが途切れると回復する |
| 弾きで、相手の攻撃が自分の攻めになる | 弾き → 反撃。見切り → 反撃 |
| 相手もこちらの攻撃を弾いてくる | 隙のない相手に斬りかかると弾かれ、続けると反撃が来る。剣戟の打ち合いになる |
| 危険な技への、専用の対処 | 赤く光る技は弾けない。避けるか、見切り踏み |
| 連打は通用しない | 下の連打は弾きの時間が短くなる。上の連打は相手に弾かれ、反撃される |

## 攻めと守りの循環

```
相手の攻撃 ─→ 弾き / 見切り ─→ 反撃（上）─→ 相手がよろめく ─→ 連撃（上上上）
    ↑                                                      │
    └──── 相手の隙がなくなると、こちらの斬りが弾かれ、反撃が来る ←┘
```

## 見た目

- 人体：骨盤、腰、胸、首、頭、鎖骨、肩、肘、手首、股関節、膝、足首、足。指の関節以外を再現する。
- 戦いの時は袖をたすきで縛るので、腕の動きが見える。袴は細身（裾を脛で絞る）にして、膝の動きが見えるようにする。
- 動きは実際より大きく激しく：大きなひねり、深い踏み込み、跳び込み、大きな弧。
- 刀は大太刀。刃渡りを長くし、振りの弧と軌跡を大きくする。
- カメラを引き、自分を少し小さくする。

## 実装と検証の結果（試作 0.4、2026-10-29）

### 自動試験（Chromium）

| 試験 | 結果 |
|---|---|
| 刃が届く70ms前に下 → 上 | 弾き → 反撃 |
| 刃が届く380ms前に下 | 受け |
| 刃が届く90ms前に右 → 上 | 見切り → 反撃 |
| 赤い薙ぎ払いに左 | 見切り |
| 赤い薙ぎ払いに下 | 被弾（弾けない） |
| 赤い突きの140ms前に上 | 見切り踏み |
| 振り下ろしの起こりに上 | 出鼻 |
| 何もしない | 被弾 |
| 構えている相手に上×2 | 弾かれ、相手の反撃が始まる |
| 隙に上×3 | 3連撃が入る |
| 完璧に遊ぶ | 36秒で勝利（弾き7・反撃6・斬り13・被弾0） |
| 何もしない | 負け、やり直せる |

### 釣り合いの調整

最初は完璧に遊ぶと22秒で勝ててしまった（反撃と連撃の繰り返しが強すぎた）。崩しの量を下げ、相手の体幹の回復を早め、1つの隙に入る斬りを3太刀までにした（それ以上は相手が抜け出して間合いを取り直す）。

### 見た目の調整

- 下の操作の案内が、文字の途中で折り返していたのを直した。
- 大太刀の軌跡が、光の柱のような大きな三角形に見えていた。刃先の3分の1だけで軌跡を描くようにした。
