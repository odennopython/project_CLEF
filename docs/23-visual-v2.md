# 見た目の作り直し：アニメ調で作り込む（試作 2.0、2026-10-30）

## オーナーの評価（試作 1.2）

- めっちゃダサい。顔がモチョモチョ。顔も動きもダサく、人が不自然で気持ち悪い
- 変にリアル寄りにするより、アニメ調で細部まで作り込む方がいい。ゼルダの伝説くらいの見た目に
- 主人公：笠をかぶる。服はナルトのサスケのような衣装を黒に。黒い羽織。刀の鞘は背中に
- 敵：SEKIROの葦名弦一郎のように、格好よさを徹底的に考えて作り直す
- 剣戟のエフェクトが角張っている。斬撃は滑らかに、大袈裟に
- ゲームの名は「風の伝説」

## 「気持ち悪さ」の原因（分析）

| 原因 | 説明 |
|---|---|
| 粗い面 | 人物全体を 1.35cm の格子で焼き出していた。顔は縦に約10個の頂点しかなく、顔の形も髪もつぶれていた（モチョモチョ） |
| 硬い物まで粘土で作っていた | 板や縄のように縁のくっきりした物を、溶け合う粘土の形で作ると、ぼやけて安っぽい |
| 揺れ戻りの大きいばね | 動きのばねの減衰が弱く（0.42〜0.6）、行き過ぎて戻る。これがゼリーのような、生き物らしくない動きに見えた |
| 中途半端な写実 | 顔を写実寄りに彫ると、不気味の谷に落ちる |

## 作り方の変更

1. **頭は 5mm の格子で別に焼き出す**（体の約3倍の細かさ）。同じ骨で動かし、首の重なりでは頭の面が前に出る
2. **顔はアニメ調に**：丸い頭、丸い頬、小さく尖った顎、ごく小さな鼻。目と眉と口は、頭の皮膚そのものに絵を貼る（顔の部分の三角形を取り出し、正面から投影する）。顔の影は浅くする
3. **硬い物は形として作る**：笠、縄の帯と結び目、鞘、鎧の板、弓。縁がくっきりし、細かい模様（笠の編み目、縄の撚り、縅の糸）を絵で付ける
4. **ばねの減衰を強く**（0.78〜0.95）、行き過ぎをほぼなくした

## 斬撃のエフェクト

- **刃の軌跡**：前のフレームと今のフレームの間を、刀の向きの回転として細かく補う（0.05ラジアンごと）。直線でつなぐと、速い振りほど角張っていた
- **三日月**：両端が細く尖り、中ほどが太い形。刃の進む向きに 80ms で一気に描かれ、白い芯が色へ冷えながら外へ広がって消える。前より太く（1.4〜1.6倍）、長く残り（380〜560ms）、刃の通り道の先まで伸ばす

## 斬りの結果ごとのエフェクト（試作 2.1、2026-10-30）

オーナーの要望：「斬撃は、相手への攻撃が成功するか否かで分かりやすくエフェクトを変えよう」。

振っている間の軌跡は控えめな色にしておき、**結果が出た瞬間に、残っている軌跡ごと塗り替える**。結果は形・色・残り方の三つで分ける。

| 結果 | 軌跡 | 三日月 | ほか |
|---|---|---|---|
| 斬れた | 白く灼ける | 太く、両端が尖り、相手の体を通り抜けて外へ広がる（380〜560ms） | 刃の通った向きに、体を横切る細く鋭い「斬り線」が一瞬残る（330ms）。体が白く光る |
| 浅い（振りかぶった相手を斬った） | 鈍い赤 | 細く暗い。残像なし（260ms） | 斬り線なし |
| 弾かれた | 当たった所で途切れ、冷たい鋼の青に | 短く細く、当たった所で折れて跳ね返る（220ms） | 火花 |
| 空振り | 灰色の薄い軌跡 | なし | — |

白＝斬れた、青＝弾かれた、灰＝届かない。[14-feedback-language.md](14-feedback-language.md) の「火花＝刃と刃、白い線＝斬れた」を、斬撃の形まで広げた。

## 大きな弧の斬撃と、ダイナミックな動き（試作 2.2、2026-10-30）

オーナーの要望：「斬撃がまだカクカク。もっと滑らかな線に。弧を描くような大きな斬撃（刀が通っていない部分も大袈裟に大きく）。人の動きもダイナミックに」。

### 斬撃：点をなぞらず、数式の円弧を描く

カクカクの原因は二つあった。

1. 三日月を、刀の通った点をなぞって作っていた。点の並びの乱れがそのまま線に出る
2. 刀の軌跡の帯に、振りかぶりで刀を引く動きまで入っていた。さらに帯の内側の端を柄の側まで伸ばしていたため、手首を中心に回ると内側が逆に振れて、帯が「く」の字にねじれた

直し方。

- 斬れたときの三日月は、刀の通った点から**振りの面と回転の向きだけを求め**、その面に数式で円弧を描く。半径は刀先の1.35倍（重い斬りは1.55倍）。弧の長さは、実際に振った角度より前へ0.7、後ろへ0.4ラジアン伸ばし、最低でも約165°（重い斬りは約205°）。外へ少しずつ広がる渦の形にする
- 振りの面は**カメラの方へ傾ける**。面が視線と平行だと、大きな円弧は細い楕円につぶれて折れて見える（アニメの斬撃が画面に向けて描かれるのと同じ考え）
- 面がこちらを向いているときは、幅を面の中の外向きに取り、平たい三日月にする
- 刀の軌跡の帯は、振り下ろしの間だけ描く。帯は刀身の外側だけにし、点を両隣と2回均す

### 動き

- 打ったあとに**振り抜き**の姿勢を足した。刀の勢いで体が回り切り、刀先は背の側まで流れる（袈裟・逆袈裟・振り下ろし・反撃）
- 振りかぶりと振り抜きのひねりを1.35倍、沈みを深く、跳ぶ技を高く、手を支点から遠くへ（大きな弧）
- 踏み込みを大きく（斬り 1.0→1.4、重い斬り 1.2→1.6、反撃 2.4→3.0。相手の技も1.4倍。相手に重ならないよう間合いで止める）
- 相手の構えと振りのひねりも1.3倍に
- ばねを少し速くした（揺れ戻りはないまま）

## 細かい面、袴、長い刀、大袈裟な弾き（試作 2.3、2026-10-30）

オーナーの評価：「相手の足が袴ではなくスカートみたいでダサすぎる。主人公も敵も、もう少しポリゴンを細かく作り込んでほしい。刀はもう少し長く、鞘は背負って。弾きとその構えも、もっと大袈裟に」。

- **相手の袴**：地面まで一枚の釣鐘形だったため、スカートに見えた。腰の上だけを覆い、その下は左右の脚に分かれる形にした。脚は裾へ広がり、折り目の立ったひだが通る
- **面の細かさ**：体の格子を 1.35cm → 1.05cm、頭を 5mm → 4.2mm にした（主人公の体 約2.4万 → 4.1万頂点、相手の体 約3.1万 → 4.3万頂点）。そのぶんページは重くなった（埋め込みの人物データ 約3.6MB → 5.3MB）
- **刀**：主人公の刃 1.5 → 1.85、相手 1.3 → 1.65（柄も長く）
- **鞘**：刃に合わせて長くし、右肩の上から左の腰の後ろへ、縦に近く斜めに背負う。負い紐も試したが、体から浮いてホースのように見えたので外した
- **構え**：低く広く腰を落とし、体を半身に開いて、長い刀を斜め上へ立てる
- **弾き**：前へ大きく踏み込み、刀を横一文字に高く突き出して受け、大きく跳ね上げる

## 安っぽさの原因と作り直し（試作 2.4、2026-10-30）

オーナーの評価：「相手の袴が固まったスカートに見えるのが解消されていない。相手と自分のポリゴンの作り込みが甘く、ゼルダの伝説のテイストを目指しているのに安っぽすぎる」。

### 安っぽさの原因（分析）

人物の面の細かさだけではなかった。

| 原因 | 説明 |
|---|---|
| 硬い3段の陰と、太い真っ黒の輪郭線 | ゼルダの伝説（ブレス オブ ザ ワイルド）は、柔らかい2段の陰と、ごく控えめな縁取りで描いている |
| 背景 | ピラミッドの山、平らな雪原、棒の木。画面の大部分を占める背景が安っぽさの大きな元だった |
| 色が均一 | 布も肌も一色で塗りつぶされ、手で描いたような揺らぎがない |
| 布が固まっている | 袴が骨にくっついて動くだけで、揺れない。股の割れもなく、脚を閉じると一枚のスカートに見えた |

### 直したこと

- **陰**：柔らかい2段にした。陰と明るい面の境目を細いぼかしでつなぐ（体：陰の明るさ 132/255、境目の幅 0.08。顔：186/255、0.14）
- **輪郭線**：真っ黒ではなく夜の藍を帯びた暗い色にし、細くした（体 0.0065〜0.011 → 0.0045〜0.006、頭 0.0045 → 0.0032）
- **色のむら**：焼き出すときに、ゆるい明るさと色味の揺らぎを入れた（±5% ほど）
- **袴の股の割れ**：左右の脚の間を、股の下から裾まで細く割った。脚を開くと割れが開き、ズボンとして読める
- **布の揺れ**：袴と羽織の裾、羽織の袖に「揺れの重み」を焼き込み、描くときに裾ほど大きく、体の動きに遅れてなびき、細かく波打つようにした
- **細部**：主人公の袴の前で交差する紐と結び目。相手の肩上（肩の上から胴を吊る帯）と深紅の紐の結び目
- **背景**：天頂の深い藍から地平の青紫へのグラデーションの空、月と光の暈、星。雪の頂を持つ山並みを三重（遠いほど霞む）。闘う場所の外へゆるく起伏する雪原と、細かくきらめく雪。雪の積もった三段の杉（70本）、雪をかぶった岩、作り直した石灯籠（反った笠に雪）。夜の雪は白ではなく、月明かりの青い灰で塗る

## 残る弱点（率直に）

- 羽織や袖は骨にくっついて動く硬い形で、布として揺れない
- 顔は正面からの投影で描いているので、真横から見ると目が引き伸ばされる
- 動きは姿勢の誇張と振り抜きで大きくしたが、足運び（踏み込む足、残す足）はまだ作り込んでいない
- この開発環境では、頭の面を増やしたぶん描画が重くなった（ソフトウェア描画で 4.7 → 3.3 コマ/秒）。iPhone の実機では確かめていない
