# 北極星と戦略（オーナーの確認待ち）

## オーナーの要望（2026-10-29）

> 壮大にいこう。本質的には世界シミュレーションが理想だ。この世界すべての現象を扱いたい。すべての法則が対象だし、この取り組みを通して新しい法則も発見したい。

## そのままの形では失敗する理由

| 問題 | 内容 |
|---|---|
| 計算できない | 素粒子から宇宙までを同時にシミュレーションすることは不可能。万物を統一する理論も人類はまだ持っていない |
| ゲームにならない | 何でもできる箱庭は目標がはっきりせず、②集中が起きない（Universe Sandboxのような宇宙シミュレーターは「眺めて遊ぶおもちゃ」で止まっている） |
| 柱とぶつかる | 柱2（少数の法則）、柱5（1回数分）と衝突する |

## 壮大さを実現する方法：物理学と同じやり方

物理学は、すべての現象を1つずつ扱ったのではなく、少数の原理に圧縮することで、すべての現象を射程に入れてきた（[04-laws-and-understanding.md](04-laws-and-understanding.md) の「理解の層」）。

**すべてを同時にシミュレーションするのではなく、少数の規則から世界を組み立て、プレイヤーが層を降りるほど扱える現象が広がる構造にする。**

## 提案

| 段階 | 内容 |
|---|---|
| 北極星 | 世界のすべての法則を対象にする。新しい法則の発見も目指す |
| 戦略 | 少数のミクロな規則から世界を組み立てる。層を降りるほど扱える現象が広がる |
| 最初の一片 | 1つの規則から豊かな現象が出てくる領域（候補：波） |
| 発見の仕組み | 創発する世界の中で、作者も知らない法則をプレイヤーが見つける |
| 将来 | 研究機関と組んだ市民科学への接続 |

### 最初の一片の候補：波

方程式は1つ（波動方程式）で、干渉、回折、屈折、共鳴、音、光が出てくる。量子力学のシュレーディンガー方程式も波の方程式なので、「別々の現象が1つにまとまる瞬間」を最初から仕込める。静かな見た目にも向いている。

## 新しい法則を発見する道

1. **創発する世界（主軸の候補）**：少数のミクロな規則から世界を作ると、マクロな法則が生まれる（分子の規則から熱力学が出てくるように）。ライフゲームは4つの規則から、作者のコンウェイも知らなかった構造が50年以上見つかり続けている。作った側も知らない法則を、プレイヤーが本当に発見できる。
2. **市民科学**：Foldit（プレイヤーがウイルス酵素の構造を解き、論文になった）、Galaxy Zoo（参加者が新しい種類の天体を発見した）の前例がある。ただし研究機関との協力が必要で、見つかるのは既存理論の中の新しい答えであり、新しい基本法則ではない。

現実の物理で、ゲームを通して新しい基本法則を見つけるのは非現実的。
