# 音のリアリティ（試作 2.0、2026-10-30）

## オーナーの評価（試作 1.2）

> 音は非常にクオリティが低く、間抜けで、リアリティがない。音はリアリティに徹底的にこだわってほしい。

## 原因

- 現実に存在しない音を混ぜていた：太鼓、ご褒美の和音（五音音階で上がる）、見切りのガラスの音、ノコギリ波の合成の声（うなり、息をのむ音）。これらが間抜けさの元だった
- 金属の音を、正弦波を6本ほど重ねただけで作っていた。本物の刀の響きは、高い音域に数十の振動がひしめき、それぞれがうなる
- 風切りの音が、刀の動きと無関係な決まった音だった
- 歪み（tanh）で潰していて、作り物らしく聞こえた

## 録音素材について（調べた事実）

この開発環境から外へつながるのは GitHub と npm だけで、CC0 の効果音を配るサイト（kenney.nl、opengameart.org、freesound.org、pixabay.com、archive.org など）には接続を拒否される（2026-10-30 に確認）。npm にある効果音のパッケージ（react-sounds、@remotion/sfx）は、音そのものを含まず、外部の URL を指すだけだった。そのため今回は、物理に基づく合成で作った。

**本当に最高の音にするには、本物の録音（フォーリー）が必要。** 刀の衝突、布、雪を、購入した素材か自分の録音で差し替えるのが本番の道（[18-character-pipeline.md](18-character-pipeline.md) の予算の判断と同じ）。

## 作り方

| 音 | 物理の考え方 | 作り方 |
|---|---|---|
| 刃と刃 | 二本の刀身が、それぞれ固有の振動で鳴る。低い曲げの振動は、両端が自由な棒の比（1、2.757、5.404、8.933…）に並ぶ。刃の高い振動は 2〜11kHz に密に並ぶ。振動は高いほど早く消え、ほぼ同じ高さの二つ組がうなる | 減衰する共振器を、一本の刀につき約60個並べ、接触の衝撃で鳴らす。硬く鋭い接触ほど高い振動まで鳴る |
| 弾き | 刃筋で当たり、手が振動を吸わない | 長く澄んで響く（0.5秒で −39dB、1秒で −46dB） |
| 受け | 握った手が振動を吸い、刃が擦れ合う | 響きを短くし、ひっかかっては滑る細かい衝撃の連なり（擦れ）を足す |
| 風切り | 空気の渦の音は、速さで高さが決まり、速いほど急に大きくなる | 刀先の実際の速さから毎フレーム作る。速さに比例して高く、速さの約2.4乗で大きく。刃鳴りの狭い帯域を少し足す |
| 斬り | 布が裂け、体を打つ | 布：細かい破裂が速く連なる音。体：低く沈む胴の響きと、こもった雑音 |
| 雪 | 小さな氷の粒が潰れる音の集まりと、押し込まれる低い音 | 粒の音を70〜260個重ねる。踏む、着地、滑るで粒の数と長さを変える |
| 空間 | 雪原は高い音を吸うので、残響は短く暗い。遠い山から反射が一つ返る | 早い反射4つと、0.13秒で消える暗い残響、0.42秒後の遠い反射 |
| 風 | 低いうなり、木々を抜ける中域、ときどき鳴る細い笛のような音 | 三つの帯域の雑音の強さと高さを、ゆっくり不規則に変える |
| 衣擦れ | 体が速く動くと布が鳴る | 主人公の腰の速さで、こもった布の音の大きさを変える |

楽器の音は一つも使わない。結果の違い（弾きか受けか、など）は、現実の音の違い（響きの長さ、擦れの有無）だけで伝える。

## 演出の音

- 危険な技の予兆：鞘から刀を引くような、刃が擦れて鳴る音（以前は低い唸り）
- 相手の構えが変わる：強い風と、刀を抜き直す音（以前は太鼓）
- 一閃：風が止み、静寂のあとに一つだけ長く澄んだ響き。布が裂け、雪に倒れる
- 鎧の板が落ちる：雪の上のこもった金属
