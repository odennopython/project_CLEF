# プレイヤーの操作

操作はゲームの面白さを最も直接に決める。上位方針①②③と洗練から、丁寧に導く。

## 1. 前提：参考ゲームでプレイヤーは何をしているか

| ゲーム | プレイヤーの決定 | その決定は何か |
|---|---|---|
| 将棋 | 一手を指す | 世界に働きかける行動。その中に予測が含まれている |
| SEKIRO | 攻撃を弾く、避ける | 行動 |
| ELDEN RING | どこへ進むか、どう戦うか | 行動 |
| 株 | 売買する | 行動（予測にお金を賭ける） |
| Kaggle | モデルを作って提出する | 作ったものを世界に評価させる |

予測を外から宣言するだけのゲームは1本もない。予測は常に行動の中に埋め込まれている。

### 撤回：「予測を確定する」を核の操作にする案

| 問題 | 内容 |
|---|---|
| クイズになる | 世界との関わりが薄くなる |
| 当てても世界が変わらない | 結果に重みがない |
| 原因になる喜びがない | 自分が原因になって世界に変化を起こすこと自体が喜びである（ホワイトの「エフェクタンス動機づけ」、グロースの「原因であることの喜び」）。③有能感の根っこにあたる |

予測は核の操作にせず、行動の中に埋め込む。

## 2. 本質：理解の証明は「起こせること」

法則を理解した証明は、予言できること、さらに意図した結果を起こせること（工学）。

> **法則を理解するほど、少ない介入で、意図した結果を世界に起こせるようになる。**

最も洗練された解は、最小の一触れで最大の結果を起こすもの（詰将棋の最短手順、柔道、単純な装置で本質を示す物理実験）。介入が少ないことが、上達の証（①③）であり、洗練の表現でもある。上位方針と表現の方向性が1つの操作にまとまる。

## 3. 操作を構成する要素

### A. 触れると何が起きるか

| 候補 | 内容 |
|---|---|
| かき乱す | 小石を落とすように、その場所にエネルギーを与える |
| 置く・取り除く | 物質や構造を置く、消す |
| 境界を作る | 壁や仕切りを置く |
| 規則を変える | 世界の法則そのものを書き換える |

提案：動詞はできる限り1つ（柱2）。「規則を変える」は柱1を壊すので核にしない。上級者向けの「別の宇宙を作る」機能として将来の候補に残す（新しい法則の発見とも関係する）。具体的な動詞は世界の規則が決まってから決める。

### B. 時間との関係

提案：止まった世界に触れる → 確定 → 世界が自分の法則で動く（柱5）。将棋の「指す → 相手が応じる」と同じ形。

- 見返す（巻き戻して観察する、感想戦）：自由
- やり直す（結果を変える）：できない。ただし新しい挑戦はすぐ始められる（柱4）

### C. 実験と本番の2段階

| ゲーム | 自由に試せる場 | 結果が確定する場 |
|---|---|---|
| 将棋 | 研究 | 対局 |
| Kaggle | 手元での検証 | 提出（1日の回数に制限） |
| SEKIRO | 道中で試す | ボス戦 |

提案：自由に触って試せる「実験」と、介入の回数が数えられ結果が確定する「本番」に分ける。実験は①学習と③自律、本番は柱4と②集中のため。

未決の論点：本番と同じ状況を事前に実験で試せてよいか。案：似ているが同じではない状況で実験できる（将棋の研究も本番と全く同じ局面にはならない）。

### D. 目標の与え方

| 種類 | 内容 | 満たすもの |
|---|---|---|
| 問題 | 「この構造をあそこへ届ける」など。目標は見えていて、方法が隠れている | ②集中 |
| 探索 | 目標なし。未知の現象を探す | ③自律、新しい法則の発見 |

問題で法則を学び、探索で誰も知らない法則を見つける（ELDEN RINGのボス戦とオープンワールドの関係）。

### E. 観察の道具

ピンチで拡大、時間の速さを変える、巻き戻して見返す。

### F. 記録

見つけたものを、その瞬間ごと保存して名前を付ける。手帳になり、発見を共有する単位にもなる（③つながり）。文章で法則を書かせることはしない。

## 4. 人間工学

| 制約 | 対策 |
|---|---|
| 指で触る場所が隠れる | 意味のある構造は指先（約1cm）より大きくする。介入は範囲に影響するものにし、精密さではなく「どこに、どれくらい」で勝負する |
| 画面のボタンに押した感触がない | 小さなボタンを置かない。画面全体＝世界＝触れる対象 |
| 隠れた操作は見つけられない | タップ、ドラッグ、ピンチだけにする |
| 片手・縦向き | 親指が届く下の方に、数少ない操作をまとめる |
| 確定の手応え | 確定の瞬間に振動と音を1つだけ返す |
| 最初の数秒（柱1） | 説明なしで、触れた瞬間に世界が反応する |

## 5. 操作の案

> **止まった世界を観察し、どこに、どれだけ触れるかを決めて確定する。世界は自分の法則で動き出す。法則を理解するほど、少ない一触れで、意図した結果を起こせるようになる。**

| 観点 | どう満たすか |
|---|---|
| ①学習 | 触れるたびに実験になる。予想と結果のズレから学ぶ |
| ②集中 | 目標が見えている。結果は数秒で返る。挑む問題は自分で選べる |
| ③自律 | どこに触れるか、どの問題に挑むか、何を探索するかを自分で決める |
| ③有能感 | 自分が原因になって世界が変わる。触れる回数が減っていくことが上達として見える |
| ③つながり | 発見に名前を付けて残せる |
| 洗練 | 動詞は1つ、画面には世界だけ。最小の一触れが最も美しい |

## 決定事項（2026-10-29）

| 項目 | 決定 |
|---|---|
| **操作の核** | **最も洗練された解は、最小の一触れで最大の結果を起こすもの。** 法則を理解するほど、少ない介入で意図した結果を起こせるようになる |
| 実験と本番 | **モードとして分けない。** ELDEN RINGのように、1つの世界の中に気軽に試せる場所と重みのある場面が自然に混ざり、どこに挑むかをプレイヤーが選ぶ。ゲームデザインの中で自然に生まれるようにする |
| 問題と探索 | 同じ理由で、別々のモードにせず1つの世界の中に溶け込ませる方向（ボスがオープンワールドの中にいるのと同じ形） |
| 触れる動作 | まだ抽象的なので決めない。世界の規則が決まってから決める |

上の「3-C 実験と本番の2段階」「3-D 目標の与え方」の、モードとして分ける案は採用しない。

## 核から導かれる、世界の規則への条件

「最小の一触れで最大の結果」には、世界が小さな介入を大きな結果に増幅する性質が必要。

| 増幅の仕方 | 例 | 核との相性 |
|---|---|---|
| 読めない増幅 | バタフライ効果（カオス） | ✕ 一触れの結果が運任せになり、法則として学べない |
| **読める増幅** | てこ、ドミノ、雪崩、将棋の急所の一手 | ◎ 理解するほど、どこに触れれば大きく動くかがわかる |

世界の規則には**読める増幅**が必要（[06-emergent-world.md](06-emergent-world.md) の選定基準⑤）。
