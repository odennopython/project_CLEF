# 42. 世界と登場人物：上位方針と設定（試作 4.8）

## オーナーの依頼（2026-10-31）

> 登場人物の（見た目の）多様さなど、本質的な面白さを、背景を練りながら、上位方針・設定を作り込んでください。

## 1. 上位方針：設定は何のためにあるか

設定は飾りではない。このゲームの上位方針（①学習・上達 ②集中 ③内から湧く動機、[05-vision.md](05-vision.md)）に仕えるときだけ、置く価値がある。そこから四つの約束を決める。

| 約束 | 内容 | どの方針に仕えるか |
|---|---|---|
| **見た目は法則の手がかり** | 相手の色・形・印を見れば、どこの者で、どう戦い、どんな癖があるかが分かる。見た目を覚えることが、そのまま読みの上達になる | ①学習（柱1：法則は観察で見つけられる）、③有能感（見た瞬間に読める） |
| **言葉で語らない** | 物語は、置かれた物と、出会う相手の姿で見せる。会話、説明文、名前の表示はしない | ②集中（柱6：中断させない）、[14](14-feedback-language.md) の文字を出さない方針 |
| **繰り返しに意味がある** | 同じ山を何度も登る理由を、世界の側に持たせる（ローグライクの「もう一度」を、物語として自然にする） | ③内から湧く動機 |
| **上達が、その人の物語になる** | 頂の手前で待つ白狐の剣士は、その人自身の戦い方の癖を映す。山の最後の壁は自分 | ①③（柱3：上達はプレイヤーの頭の中に残る） |

判定テスト：

- 相手を遠目の影だけで見て、どこの者か分かるか（頭と背の形）。
- 色と印を見て、戦い方の予測を立てられるか。立てた予測は当たるか。
- 説明文を一つも読まずに、「この山で何が起きているか」をなんとなく感じられるか。

## 2. 世界の芯

ここに書くのは作り手のための設定。遊ぶ人には言葉で伝えず、景色と相手の姿でにじませる。

### 白峰と「風の伝説」

- **白峰**は、一年じゅう雪の消えない霊峰。頂の社には「風」が祀られている。
- 麓にはこう伝わる：**夜明けに頂に立った者は、風になる。** 風になった者は白狐の面をつけ、九合目の岩稜で、次に登ってくる者を待つ。
- 登るのは**一夜**。宵に麓を発ち、夜明けに頂へ。合目ごとに夜が進むのはそのため（[41](41-terrain-craft.md)）。

### 山の掟：名を捨てる

- 白峰に入る者は、名を捨てる。だから山にいる者は、皆、狐の面をつけている。山の上で物を言うのは、名ではなく腕だけ（このゲームが、強化も肩書きもなく、理解だけを問うことと同じ）。
- 面の色は、山での身の上を表す。

| 面 | 誰か |
|---|---|
| 灰 | 名を捨てたまま山に住みついた者（野伏り、修験の下の者） |
| 鉄 | 藩の番所の兵（掟に従うふりをした役人） |
| 赤 | 腕を試しに来た剣客 |
| 影（黒地に白の筋） | 忍び。素顔も名も、二重に隠す |
| 天狗 | 掟を破った者。狐の面を捨て、天狗を名乗る |
| 黒 | 五合目で止まった者。頂を諦め、門番になった（白峰の浪人） |
| 白 | 頂に至った者（白狐の剣士）と、それに仕える守り手 |

### 主人公

- 白狐の面をつけた、名のない剣士。黒の装い、背に鞘、編み笠。
- なぜ最初から白い面なのかは語らない。作り手の答え：**先代の白狐が、麓の社に置いていった面**。それを被って登り始めた者。山の者たちは、その白い面を見て、ある者は恐れ、ある者は挑み、ある者は道を塞ぐ。

### 道の脇の刀

白狐に敗れた者は、刀をその場に置いて山を下りるのが掟。だから登るほど、道の脇に刀と笠が増え、九合目の岩稜は刀の墓場になる（[41](41-terrain-craft.md)）。

### 繰り返す理由

頂で白狐を越えた者が、次の白狐になる。次に登るとき、山はひとつ厳しくなっている（[36](36-mountain-design.md) の「段」）。何度でも登るのは、強くなるためではなく、**風を継ぐため**。

## 3. 山の勢力

合目ごとに出会う勢力を、地形と合わせて決めた。勢力は「色」で見分ける。

| 勢力 | なぜ山にいるか | 装い（色・頭・背） | 武器 | 出る合目 |
|---|---|---|---|---|
| **野伏り** | 麓に巣くう食い詰め者。登る者から奪う | 継ぎの当たった土色の布。編み笠か鉢巻。雨よけの蓑 | 刀、小太刀、二刀、棒、金砕棒、鎖鎌、大太刀 | 一・二・五 |
| **番所の兵** | 藩が「風」を恐れ、山の関を閉ざしている | 藍の揃いの装いと白い襟。陣笠。背に白地に黒丸の旗（頭は赤地） | 槍、弓、刀、薙刀、大太刀、金砕棒 | 二・四 |
| **修験** | 山を清く保つため、名を捨てきれない者を退ける | 白の装束、黄土か紫の袴。額の頭襟。胸の結袈裟の房（格で色が変わる：白→金→紫） | 薙刀、棒、大太刀、刀 | 三・六 |
| **忍び** | 藩に雇われ、登る者を消す | 闇の藍と黒。頭巾。影の面。髪を見せない | 忍者刀、クナイ、鎖鎌、小太刀、二刀 | 三・七 |
| **剣客** | 白峰の浪人の噂を聞いて、腕を試しに集まった者 | 一人ひとり違う色の着物（深紅、青緑、からし、葡萄）と白い襟。編み笠か素頭 | 刀、大太刀、二刀、槍、小太刀 | 五・六・七・九 |
| **天狗党** | 修験崩れ。風を独り占めしようと、吹雪の尾根に居座る | 黒の装束に、赤い襟と金の帯。天狗の面、頭襟、黒い羽の蓑 | 薙刀、刀、二刀、棒、忍者刀 | 八 |
| **白峰の守り手** | 頂に至れなかった者のうち、白狐に仕えると決めた者 | 白と銀の装い、深紅の襟。白い面、白い襟巻 | すべて | 九 |

同じ合目で同じ相手が出ても、色の組み合わせは登るたびに少し変わる（勢力の中の配色から選ぶ）。

## 4. 見た目の文法

色は勢力、頭と背の形は勢力と格、なびく布や兜の飾りは**固有の法則**を表す。一度覚えれば、どの勢力の誰にでも通じる。

### 格

| 格 | 見た目 |
|---|---|
| 雑兵 | 鎧なし。勢力の装いそのまま |
| 足軽 | 勢力の揃いの装い（番所なら陣笠と背旗） |
| 手練・流派の者 | 袖と草摺の鎧の板 |
| 頭 | 兜に金の鍬形。体が一回り大きい。番所の頭は赤い背旗、修験の頭は紫の房 |

### 固有の法則の印

| 法則 | 印 | 読み |
|---|---|---|
| 疾い | **赤い襟巻**がなびく | 技が速い。起こりを早めに読む |
| 身軽 | **灰の襟巻**がなびき、鎧がない | よくかわす。無理に斬りかからない |
| 返しが鋭い | **赤い襷** | 弾き返しがよく来る。斬った後の構えを崩さない |
| 怯まない | **金の鍬形の兜** | 軽い斬りではのけぞらない。崩しを溜めてから |
| 堅い | **鎧の板と兜** | 崩れにくい |
| 重い | **蓑** | 与える崩しが大きい。受けずに弾く |
| 虚が多い | **影の面** | 連撃の中に虚が混じる。腰を見る |

## 6. 今回入れたもの（試作 4.8）

- **装束の塗り分け**：体の布の部位（着物、襟、袴、帯、鎧、籠手、頭巾）ごとに、勢力の配色で塗り分ける。元の色の明暗（陰や縫い目）は残す。斬り分けた破片も同じ色になる。
- **形の部品**：兜と鍬形、頭襟、鉢巻、蓑（藁と黒い羽）、背旗、結袈裟、襷、なびく襟巻、天狗の面、影の面。
- **勢力と道**：合目ごとの勢力から相手を選ぶ（その勢力が使う武器の者だけ）。主（名のある者）も、その合目の勢力の装いになる。白峰の浪人（黒い面）と白狐の剣士（白と銀）は固有の装い。
- 開発者モードで一人の相手を選んだときは、武器と格から決めた勢力の装いになる。

## 7. あわせて直したこと

- **走って移動する**：倒した後に次の開けへ、合目の主の後に次の合目へは、走って向かう（毎秒4.4m、合目の境の長い道は5.2m。石段と上り坂では少し遅くなる）。走りは、歩幅を広げ、両足が地面を離れる瞬間を作り、体を前に傾け、一歩ごとに弾ませる。足は体の中心線へ寄せる（構えの足幅のまま走ると、がに股に見えた）。主を倒した後の間も、4.2秒から3.2秒に縮めた。
- **赤い斬撃の帯のカクつき**：刃の軌跡の帯は、コマごとの刀の位置を直線でつないでいたので、速い振り（一振りが3〜4コマ）ではつなぎ目が角になっていた。コマごとの手元の位置と刀の向きを、滑らかな曲線（Catmull-Rom）でつなぎ直した。毎秒30コマで撮り比べ、前の版の角が消えたことを確かめた。

## 8. 試験

| 試験 | 結果 |
|---|---|
| 勢力・格・法則を変えた相手を一人ずつ撮った一覧 | 野伏り（土色と蓑）、番所の兵（藍と陣笠と背旗）、修験（白と頭襟と結袈裟）、忍び（闇色と影の面）、剣客（色違いの着物と襷）、天狗党（天狗の面と黒い羽の蓑）、守り手（白と銀）を見分けられる |
| 三合目・八合目の戦いの場を縦長の画面で撮った | 三合目に忍びと修験、八合目に天狗党が出る。**主人公まで敵の色に染まる不具合を見つけて直した**（同じ作りの描き方を共有したため、敵の色の設定が主人公に流れ込んでいた） |
| 合目の境（一→二、四→五、八→九）、戦いの決まり、負けてやり直す、iPhone 表示 | 前の版と同じ結果。例外なし |

## 9. 率直な限界

- 体の形（骨格と体つき）は、まだ全員が同じ人体の使い回し。違いは色、頭と背と胸の部品、大きさで出している。遠目の影の違いは、主に頭と背の形による。
- 女性の剣士（くノ一、巴の薙刀使いなど）も同じ体。体つきを変えるには、人物の型を作り直す必要がある（次の候補）。
- 設定は、まだ景色と装いでしか見せていない。山小屋や社に置く小物で、もう一段にじませる余地がある。
