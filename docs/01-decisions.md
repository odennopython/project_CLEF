## 決まったこと

| 項目 | 決定 | 理由 |
|---|---|---|
| 配信先 | iOSを最初に出す。あとでAndroidとWebにも出せるようにする | 課金で収益を得るならiOSが有利。日本ではiPhoneのシェアも大きい |
| ゲームの中心 | **世界の法則を読む** | 下の「方向性の決定」を参照 |
| 世界の作り方 | **少数のミクロな規則から法則が創発する世界** | [05-vision.md](05-vision.md) |
| 方針の上下関係 | 上位方針は①②③、表現の方向性は洗練 | [05-vision.md](05-vision.md) |
| **操作の核** | **最小の一触れで最大の結果を起こす** | [07-interaction.md](07-interaction.md) |
| 実験と本番、問題と探索 | モードとして分けず、1つの世界の作りの中で自然に生まれるようにする | オープンワールドと同じ。画面の切り替えが減り、洗練にも合う |
| 時間の作り | 1回の遊びは数分。上達は長く積み重なる | オーナーの要望「手軽に」。詰将棋やボス戦1回と同じ形 |

| 開発の仕方 | Web技術（JavaScript）でゲームを作り、Capacitorでアプリにする | 時間の主導権がプレイヤーにあるので、WebViewの制約（下記）が問題にならない。この開発環境のブラウザで確認しながら作れる |
| ビルドと提出 | Codemagic（クラウドのMac）で行う | オーナーはMacを持っていない |
| テスト | 普段はブラウザで確認し、実機確認はTestFlightでiPhoneに配信 | オーナーはiPhoneを持っている |
| リポジトリ | 非公開にする | 販売するゲームのため |
| 面白さの中心 | ①学習・上達 ②集中 ③内から湧く動機 | [02-fun-analysis.md](02-fun-analysis.md) |
| 表現の方向性 | 洗練。静けさ、余白、少ない要素を丁寧に作り込む | [03-pillars.md](03-pillars.md) |
| **達成感** | **必須**。人との勝負は必須ではない（2026-10-29） | 達成感の5要素：高い壁、自分の力で越えた、前はできなかった、はっきりした証拠、費やした努力。壁は人でなくてよいが、こちらの弱点を突くように設計された壁であること（物理現象のような無関心な壁は壁にならない） |
| 外から与える報酬 | ガチャ、ログインボーナス、期間限定で引き止める仕組みは使わない | 本質的な面白さではないため |

## 方向性の決定

6本の参考ゲームに共通する「隠れた構造を読む」ループのうち、読む対象を3つの候補から選んだ。

| 読む対象 | 参考ゲーム | 判断 |
|---|---|---|
| 他者の意図 | 将棋、ポケモン対戦 | オーナーはこれにも強く惹かれる。ただし向かい合う相手が緊張を生み、デザインの方向性（一人の静けさ）と合いにくい |
| **世界の法則** | SEKIRO、ELDEN RING、Kaggle | **採用**。一人で世界と向き合う形が、デザインの方向性と一致する |
| 確率と不確実性 | 株、ポケモン対戦 | 運と実力の区別が難しく、「納得して負ける」が弱くなりやすい |

## 技術選定の根拠と注意点（2026年10月時点の調査）

- **Codemagic**：個人アカウントの無料枠はMac（M2）のビルドが月500分、同時に1つまで。チームでは無料枠なし。料金は変わるので使い始めるときに公式で確認する。
  - [Codemagic pricing docs](https://docs.codemagic.io/billing/pricing/)
- **WKWebView（Capacitorの土台）の制約**：アプリの中のWebViewでは、画面の更新が1秒に60回に抑えられる（iPhone Proの120Hzが使えない）。2025年時点で未解決。2026年の状況は実機で確認する必要がある。
  - [Apple Developer Forums: WKWebView 120hz Support](https://developer.apple.com/forums/thread/773222)
  - [WebKit Bug 294338](https://bugs.webkit.org/show_bug.cgi?id=294338)
- **Appleの審査（ガイドライン4.2）**：Webサイトを包んだだけのアプリは落とされる。ゲームのデータはすべてアプリ内に入れる。
- **リアルタイムで精密なタイミングが必要になった場合**は、Godotへの切り替えを検討する（Godotでも Mac は不要で、Codemagicでビルドできる）。
