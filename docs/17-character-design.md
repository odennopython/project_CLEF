# 人物の作り直し：視覚の原則から格好よく見せる（試作 0.8、2026-10-29）

## オーナーの評価

> 敵と主人公の大幅なアップデートをしてほしい。まだクオリティの低い人形みたい。人間工学に基づいて、視覚的にどうすればかっこいいのかをきちんと作ってほしい。

## 人形に見えていた原因と、視覚の原則

| 視覚の原則 | 問題 | 直し方 |
|---|---|---|
| シルエットが最初に読まれる（人は細部より先に輪郭で形を判断する） | 二人の輪郭が似ていて、特徴がない | 対照的なシルエット。**自分**：縦に細く鋭く、赤い襟巻きと髷が流れる（俊敏）。**相手**：肩から横に張り出した肩衣と大きな笠、裾の広い袴で、横に広い三角（重さと脅威） |
| 連続した面が生き物に見える | 円柱を関節で繋いでいて、継ぎ目と段差が見え、機械に見える | 体を一続きの皮膚にする。腕と脚は関節で滑らかに曲がる一本の管にし、筋肉の膨らみ（肩、二の腕、前腕、腿、ふくらはぎ）を太さの変化で付ける |
| 英雄的な比率 | 頭が大きく、脚が短く、寸胴 | 脚を長く、肩を広く、腰を細く、頭を小さく |
| 形の言語（尖った形は素早さ、塊と三角は重さと脅威） | 全身が丸い | 自分は鋭い線、相手は重い塊とぎざぎざの布 |
| 明暗の分離（人物が背景から浮き上がること） | 夜の雪で輪郭が溶ける | 縁取りの光（リムライト）。視線に対して横を向いた面ほど、月の色で縁が光る |
| 細部の密度の偏り | どこも同じ粗さ | 細部を頭・手・刀・腰に集める |
| 二次的な動きが動きを大きく見せる | 布が少ない | 相手の外套の裾と肩衣と広い袖、自分の襟巻きと髷とたすきの結び目 |

## 実装

- **一続きの皮膚**：関節の位置に沿って、楕円の輪を連ねた管を毎フレーム作り直す。肘と膝は曲線で丸め、継ぎ目を出さない。輪ごとに太さと色を変え、袖口や脚絆の切り替えも同じ管の色で表す。墨の輪郭線も、同じ管を法線の向きに少し膨らませて描く。
- **胴**：骨盤から首の付け根まで9つの楕円の輪。腰は細く、胸と肩は広い。胸は呼吸でわずかに膨らむ。
- **頭**：頭蓋、顎、鼻、耳。自分は髷と結い紐、相手は面頬と鼻の稜線。
- **縁取りの光**：影の素材に、視線と面の角度から縁を光らせる処理を加えた。
- 処理の重さ：人物の形を作り直す計算は1フレームあたり約1ミリ秒（ソフトウェア描画の環境で測定）。

## 確かめたこと

- 横からの一閃の画で、二人の体が継ぎ目のない一続きの形になっていることを確かめた。
- これまでの試験はすべて通った（操作の規則、完璧に遊ぶ試験4回とも勝利、負けとやり直し、iPhoneを模した表示）。

## 限界

手続き的に作る人体としては大きく良くなったが、本物の人体モデル（彫刻された形、質感、手の指）には及ばない。本番の美術の作り方は、[15-road-to-sekiro.md](15-road-to-sekiro.md) の判断待ち。
