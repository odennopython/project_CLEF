# 51. 商業作品（Sekiro 等）との差を数字で測る（試作 7.5、2026-11-16）

オーナーの指摘：「パーツが少なく、手抜き感がある。Sekiro を調べて、差を定量的に」。

## 先に：調べて分かったこと／分からなかったこと
- **Sekiro の人物の三角形数・骨の数・テクスチャの大きさの公式な数値は、見つからなかった。** FromSoftware は公開していないらしい（検索で、開発者の発表も出てこなかった）。
- 出てきたのは、ファンが作った Sekiro 風モデルの数（例：[低ポリのリグ付き 約6千三角形](https://sketchfab.com/3d-models/lowpolysekirorigged-e0a0edf643b5400789b82b8bd0294e7d)、[Kusabimaru の習作 約7.3万](https://sketchfab.com/3d-models/kusabimaru-sekiro-study-4791539534e44dc7bb1b386a15974e55)）で、**ゲーム内の資産ではないので基準にしない**。
- 技術面は、[Dark Souls 3 のエンジンの発展版を使う](https://implacableness.netlify.app/sekiro-shadows-die-twice-analysis-the-dark-souls-engine-evolved)（二次情報、質の低いミラーサイト）、骨の作りは 3ds Max の Biped が使われた（[80.lv](https://80.lv/articles/characters-in-dark-souls-iii-armored-core-vi-were-rigged-with-the-same-tool)）程度。
- そこで**代わりの物差し**として、CryEngine（HUNT: Showdown 向け）の文書の「人物の予算」を使う。[Character Budgets](https://www.cryengine.com/docs/static/engines/cryengine-5/categories/23756816/pages/23307976)。**この環境からはそのページを開けず**、検索結果の引用で見た数字：主人公級 LOD0 が約 3.5万〜7万三角形、雑兵 約 2.5万〜3.5万、主人公級のテクスチャは 2048×2048 を一組（PC）。別のゲームの文書で、Sekiro の数字ではない。

## 読み取れること（率直な診断）
1. **三角形の数は、足りないどころか多すぎる**（物差しの約3〜10倍）。「パーツが少ない」の正体は数ではない。
2. 差は **「数が何を表しているか」**。こちらの三角形は、箱や筒を2回細分した結果で、**同じ数でも、形の情報（皺、縫い目、傷、肉付き、金具）がほとんど無い**。商業作品は、彫り込んだ高精細模型から**画像（法線・陰影・色）に焼いて**、少ない三角形に細部を載せる。こちらは、その画像が**ゼロ**。
3. **骨が18本**：指が無く、握った拳の箱。衣のひねり・肩の自然な盛り上がりも作れない。
4. **画像の細部が無い＝近づくと「つるっとした」塊**。式で作る凹凸は細かい織り目程度で、傷・汚れ・摩耗・色の染みを作る手段にならない。
5. **一人ずつの個体差がない**（同じ型に色を替える作り）。

## したがって、「全部手作業で彫る」代わりにできること（案）
- 画像テクスチャを、**コードで描く**（キャンバスで、汚れ・染み・縫い目・擦れを重ねる）。人物ごとに 1024〜2048 の色・粗さ・法線の画像を作り、体に貼る。ただし、体に **UV（貼る座標）が要る**ので、造形コードに UV の出力を足す必要がある。
- **指を作る**：手の骨（各指3関節）と、指の形を足す。握りの姿勢を、指ごとに作る。
- 三角形は**減らす**（細分を1回に、頭の格子を粗く）。浮いた予算を、画像と骨に振る。
- 雑兵の**個体差**（笠・面・衣の柄・傷・持ち物）を、決まった部品の組み合わせ＋汚しの画像で出す。
- これらでも、**人の手で彫った商業品の水準には届かない**。届く見込みを数字で言うなら：画像の細部と骨の数は、物差しの**半分〜同等**まで近づけられるが、造形の巧みさは別の話。

（注）物差しは、別ゲームの文書の検索引用。Sekiro 本体の数字ではない。実機（iPhone）での負荷は未確認。

## 実施記録（試作 7.6）
- **画像テクスチャ**：1024²の摩耗画像（汚れ・擦り傷・高さ・くぼみ）をコードで生成し、体と頭に物の座標から三方向に貼る（UVなしで貼れる方式）。低い所ほど汚れが積もり、漆には擦り傷、相手は一人ごとに汚れ方がずれる。効きは控えめ（`?wear=5` で強めて確認できる）。**目視では、暗い夜の画面で違いは小さい**。
- **蓑**：平らな筒を、六段・各40束の先細りの藁束に作り直した（以前は平らなオリーブ色の布に見えていた）。
- **手**：握った拳に、四本の指（付け根・中節・指先）を足した。骨は足していない（指ごとの動きは無い）。
- **袖**：相手の袖を細くし、袖口の内側が勢力の白に染まって「牙」のように見えていたのを直した。
- **頭の格子**：焼き出しの細かさを一段粗く（三角形 約7万→約4.6万）。
- 未達：骨は18本のまま、体のUVとテクスチャの焼き出し（彫り込み模型→法線）は未着手。三角形は物差しの約3〜7倍のまま（細分の回数を減らす作業が残る）。
