# 高品質の定義と、低品質な部分の洗い出し（試作 1.1、2026-10-29）

## オーナーの評価（試作 1.0）

> 面白くなっている。主人公が少しダサいので、和装でも現代的でかっこいいものにしてほしい。エフェクトや振りは、もっと大げさにわかりやすく。音はダサいので、もっと激しく。今のエフェクトはとても安っぽい。高クオリティを定義して、低クオリティな部分をすべて補修してほしい。

## 1. 高品質の定義

### エフェクト

| 基準 | 内容 |
|---|---|
| 層を重ねる | 1つの出来事を、芯（白熱の一瞬）・主（火花や斬撃の形）・残り（燃えさし、煙、光の名残）・周り（地面の雪、周囲を照らす光、画面の揺らぎ）の層で作る。1種類の粒だけで済ませない |
| 時間の三幕 | 0〜60ms：閃光（最も明るく、最も小さい）。60〜250ms：主の形が広がる。250〜1000ms：散り、冷え、消えていく |
| 温度の変化 | 白熱 → 橙 → 赤 → 暗い煙、と時間とともに冷える。一色のまま消えない |
| 形の言語 | 鋭く、先細りで、動きの向きにそろう。丸い点や均一な線を使わない |
| 大きさの差 | 小・中・大の粒を混ぜる。同じ大きさの粒を並べない |
| 揺らぎ | 数、速さ、寿命、大きさに必ずばらつきを入れる。毎回同じ形にしない |
| 世界への作用 | 光が周りの人物と雪を照らし、雪が舞い、画面が揺れる |
| 画風との一致 | 墨の輪郭と三段階の影の世界に合わせ、筆の形を取り入れる |
| 序列 | 一閃 ＞ 反撃 ＞ 弾き ＞ 斬り ＞ 受け。大きい出来事ほど、層も時間も大きい |

### 振り（動き）

| 基準 | 内容 |
|---|---|
| 誇張 | 振りかぶりは実際より大きく、深く溜める。振り抜きは体ごと回り切る |
| 緩急 | 溜めは長く、振りは一瞬。その差が速さに見える |
| 残像 | 刃の軌跡は長く、太く、刃の側が明るく外側へ透けていく |
| 当たりの止め | 当たった瞬間に時間を止め、カメラを当たった向きに揺らす |

### 音

| 基準 | 内容 |
|---|---|
| 層 | 立ち上がり（高い破裂）、胴（中域の音色）、重さ（低域の衝撃）、尾（残響） |
| 帯域 | 超低域（40Hz）から高域（8kHz以上）まで埋める |
| 歪み | 衝撃音は少し歪ませて、荒々しさと太さを出す |
| 序列 | 大きい出来事ほど大きく、低く、長い |
| 揺らぎ | 毎回わずかに音の高さを変え、同じ音の繰り返しに聞こえないようにする |
| 太鼓 | 大きな出来事には和太鼓の一打を重ねる |

### 人物の意匠

| 基準 | 内容 |
|---|---|
| 和と現代 | 和の要素（襟、帯、袴、足袋）を、現代的な裁ち方（細身、非対称、高い襟、重ね着）で着る |
| 色の絞り込み | 黒と墨色を主に、差し色は深紅だけ。金属の小さな部品で質感の差を出す |
| 動きで映える布 | 長い羽織の裾と襟巻きが、動きを大きく見せる |

## 2. 低品質な部分の洗い出し

| 部分 | 何が低品質か | 直し方 |
|---|---|---|
| 主人公の意匠 | 古い農民のような装い。月代の髪型が地味 | 高い立ち襟の細身の上衣、肩に羽織る長い外套、籠手、細身の袴と脚絆、地下足袋。髪は側頭を刈り上げた高い髷 |
| 火花 | 一色の線が飛ぶだけ。冷えない、燃えさしがない、煙がない | 白熱の芯、冷えていく火花の線、漂う燃えさし、立ちのぼる煙、横に伸びる光の筋 |
| 斬撃の線 | 単純な白い帯 | 筆で描いたような三日月。白い芯と色の縁、かすれ、少し遅れて追う残像 |
| 刃の軌跡 | 短く、細く、色が単調 | 長く太く、刃の側が明るく外へ透ける。自分は深紅と白、相手は冷たい青、危険な技は赤 |
| 一閃の線 | 画面に引いた白い直線（CSS） | 画面いっぱいの墨の筆の一閃（かすれた筆跡）と、世界の中の大きな斬撃 |
| 地面の衝撃 | 輪の画像が広がるだけ | 雪が輪になって外へ吹き飛ぶ |
| カメラ | 揺れが一様 | 当たった向きへの揺れ、傾き、一瞬の寄り |
| 音 | 合成音が素直すぎて弱い | 歪みと超低域、和太鼓、大太刀の重い風切り音 |
| 振り | まだ小さい | 振りかぶりと振り抜きをさらに大きく、溜めを深く、振りを速く |

## 3. 補修の結果（試作 1.1）

| 部分 | 補修 |
|---|---|
| 主人公の意匠 | 細身の黒い上衣と高い立ち襟、左肩だけに羽織る長い外套（右肩は脱ぐ）と、動きになびく外套の裾5枚。鋼の籠手と黒い手袋、深紅の帯と胸の帯紐、細身の袴、黒い脚絆と地下足袋。髪は側頭を刈り上げ、頭頂の髪を高い髷に結う |
| 火花 | 白熱から橙、赤へ冷える光の線。太さに差（1割は太い塊）。雪で跳ね返る。燃えさしが漂い、ちらつきながら消える |
| 打ち合いの層 | 白熱の芯の閃光、横に伸びる光の筋、星形の光、立ちのぼる煙、雪の輪、カメラの当たりの揺れ |
| 斬撃 | 筆の形の三日月（白い芯から色へ冷える、かすれた縁）と、45ms遅れて追う残像 |
| 刃の軌跡 | 長く太く、刃の側が明るく外へ透ける。通り道を曲線で滑らかにつなぐ。自分は深紅、反撃は金、相手は冷たい青、危険な技は赤 |
| 一閃 | 画面いっぱいを走る、かすれた白い墨の一画。毛ごとに濃さと切れ目が違う |
| カメラ | 当たった向きへの跳ねと、大きな出来事での傾き（ばねで戻る） |
| 音 | 衝撃音を少し歪ませる経路、超低域の沈み込み、和太鼓（3連以上の弾き、大きな斬り、後半の入り、一閃）、大太刀の重い風切り音、毎回わずかに高さを変える |
| 振り | 自分の振りかぶりと振り抜きのひねりを1.25倍、沈みを深く、跳ぶ技を高く。相手の振りかぶりも1.15倍。溜めを長く、振りを短く。当たりの止めを長く（弾き135ms、斬り80ms、大きな斬り150ms） |

### 途中で直したこと

- 一閃の筆のかすれが規則的な縞になり、走査線のように見えた。毛ごとの濃さを乱数で決め、筆の終わりのかすれも毛ごとに変えた。
- 斬撃の三日月が細く弱かった。太さと明るさを上げた。
- 雪の輪の粒が大きく明るすぎて、綿のかたまりのように見えた。小さく、速く、数を多くした。
