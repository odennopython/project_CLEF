## 2. このゲームの仕組みの模型

### 遊びの芯は「読みの原子」

このゲームのスキルの原子は、すべて同じ形をしている：**相手の起こりを見る → いつ・どの向きに来るかを予想する → 一瞬に応える（弾く・避ける・斬る） → 手応え（火花・音・崩れ） → 予想の精度が上がる**。

今ある読みの原子：

| 原子 | 何を読むか |
|---|---|
| 弾き | 刃が届く瞬間 |
| 避け | 弾けない危険な技（赤い閃き） |
| 見切り踏み | 危険な突き |
| 出鼻 | 起こりの始まり |
| 虚を見抜く | 腕だけ動いて腰が動かない |
| 溜め遅らせ | 溜めの長さ |
| 避けの読み | 相手が避けを読んでいる眼光 |
| 二人の番 | 次に誰が来るか |

### 飽きる仕組み（なぜ燃え尽きるか）

読みの原子は、**手がかり（何を見るか）× 拍子（いつ来るか）× 応え（どう返すか）**でできている。この三つがいつも同じなら、数戦で模型が完成し、燃え尽きる。試作 4.9 では：

- **手がかり**：起こりは、いつもよく見える（明るい、近い、正面）
- **拍子**：技の時間表は、型ごとにほぼ一定
- **応え**：弾けば勝てる

→ 合目が変わっても、三つのどれも変わらない場面が多い。これが「戦闘の単調さ」と「敵の動きの単調さ」の正体。

### 注意が続く条件（模型から導く）

1. **燃え尽きる前に、原子を一段上に組み替える**（クックのスキルの鎖）。新しい原子は、知っている原子の**手がかり・拍子・応えのどれか一つだけ**を変えて作る（一度に二つ以上変えると、模型が作れず不安になる：フローの上側）。
2. **一つの戦いの中でも、模型を一度だけ裏切る**（起承転結の「転」）。読みが固まった頃に、相手が一度だけ戦い方を変える。
3. **新しい原子は、補充の速さを決めて出す**。覚える速さより遅いと退屈、速いと混乱。目安：数分に一つの新しい原子、または新しい組み合わせ。
4. **難しさは、遊ぶ人が選ぶ**（チェン）。入るかどうか、どの流儀を背負うかを選べるようにする（自律性）。
5. **輪（戦い）の間に弧（物語）を通す**。弧は、中くらいの知識の空白を開いてから閉じる（ローウェンスタイン）。閉じると同時に、次の空白を開く。
6. **人との関係を置く**（関係性）。先を行く者、白狐、記憶の持ち主。

## 3. 設計の規則

| 規則 | 内容 | 導いた元 |
|---|---|---|
| 規則1：一変化の原則 | 新しい相手・場所・仕掛けは、読みの三要素（手がかり・拍子・応え）のうち一つだけを変える | 条件1（スキルの鎖、フロー） |
| 規則2：戦いの「転」 | 手練以上の相手は、崩しが半分を越えた頃に一度だけ「奥の手」に切り替わる。切り替わる瞬間は、見て分かる印で知らせる | 条件2（起承転結） |
| 規則3：主は「問い」 | 主は強さの数字でなく、その者にしかない読み方を一つ持つ | 条件1、規則1 |
| 規則4：場所は読み方を変える | 新しい場所は見た目でなく、読みの三要素のどれかを変える | 条件1、規則1 |
| 規則5：入るかは自分で選ぶ | 新しい場所（刀の記憶）には、自分の意思で入る。入らずに先へ進んでもよい | 条件4（自律性） |
| 規則6：報酬は遊び方を変える | 報酬は強くならず、遊び方が変わる引き換え（流儀）。背負えるのは一つ | 柱3、条件1（新しい読みの組み合わせを自分で作る） |
| 規則7：空白を開いて閉じる | 物語は、見当のつく謎（赤い襟巻の背中、白い面の影、光る刀）を先に見せ、遊びの中で答える | 条件5 |

## 4. 規則から作ったもの（試作 5.0）

### 規則2：戦いの「転」（奥の手）

手練・流派の者・頭は、崩しが半分を越えると、一度だけ奥の手に切り替わる。

- 印：刀を大きく振り払い、足元の雪が輪になって爆ぜ、面の目が一瞬白く光る（文字は出さない）。
- 中身：勢力ごとに、それまでと**一つだけ**違う戦い方へ（規則1）。

| 勢力 | 奥の手（変わる要素） |
|---|---|
| 蓑虫党 | 拍子：連撃の間が詰まり、休まず押し続ける |
| 関守 | 応え：危険な技（弾けない）が増える。避けを使わせる |
| 霧谷修験 | 拍子：待ちの構えから、居合を連ねる |
| 影縫い | 手がかり：虚が増え、腰でしか見分けられない |
| 浪人連 | 拍子：溜め遅らせが増える |
| 鴉天狗党 | 手がかり：大跳躍から、上から来る |
| 白狐衆 | 応え：弾き返しが鋭くなる |

### 規則3：主の問い（最初の一つ：霧縫い）

三合目の主「霧縫い」は、霧の中に消える。姿は見えず、**雪に刻まれる足跡と、雪を蹴る音**だけが近づいてくる（手がかりだけを変える）。打ちかかる直前に、霧から姿を現す。

### 規則4・5・6・7：刀の記憶（最初の一つ：雷雨の河原）

- **入口**：二合目の茶屋の脇に、柄に赤い下げ緒を結んだ刀が一本だけ立ち、かすかに光っている（規則7：見当のつく謎）。走って横を通るとき、刀が鳴り、カメラが刀を向く。そこで画面に触れると記憶に入る。触れなければ、そのまま先へ（規則5）。
- **場所**：夏の夜の、雷雨の河原。石の河原、黒い川、葦、折れた橋、降りしきる雨。
- **読み方の変化（規則4、規則1）**：**手がかり**だけが変わる。闇の中で、相手は稲光の一瞬にしか見えない。稲光は一定の拍子で走り、雷鳴は少し遅れて届く。相手の刃は、闇の中でも刃先だけがかすかに光る。
- **記憶の主の相手「雷切」**：稲光と同時に斬りかかる。稲光の拍子を数えれば、いつ来るかが読める（問い）。
- **報酬（規則6）**：雷切を越えると、刀を抜ける。その人の流儀「**稲妻**」を背負う：弾きの間が狭くなる代わりに、弾いた後の反撃が深く入る。背負った流儀は、主人公の鞘の下げ緒の色で分かる。
- **戻る**：記憶から出ると、もとの河原ではなく、刀の前に立っている。

## 5. 確かめ方

| 確かめること | 方法 |
|---|---|
| 新しい模様の補充の速さ | 遊んだ記録に「初めて出会った技・戦術・法則」の時刻を残し、一分あたりの新しい模様の数を出す（開発者向けの記録の要約に出す） |
| 転が読みを裏切っているか | 奥の手の後の被弾率が、前より一時的に上がり、また下がるか（模型の更新が起きている） |
| 雷雨の河原が「読める」か | 稲光の拍子を覚えた後に、弾きの成功率が上がるか。上がらなければ、手がかりが足りない（不安側） |

## 6. 確かめた結果（試作 5.0）

| 試験 | 結果 |
|---|---|
| 新しい模様の補充の速さ | 一合目を自動で遊ばせると、始めの約2分で新しい模様が19個（1分あたり約9個）。新しい模様が来なかった最長の間は42秒（走って移動する時間を含む）。一合目の始めは「覚える段」なので、この速さは高すぎない。合目が進むと補充が減るはずなので、そこで転・主の問い・刀の記憶が効くかを、合目ごとに測っていく |
| 戦いの転（奥の手） | 大太刀の頭の崩しを半分越えにすると、奥の手を見せて跳び退き、それ以降は奥の手の戦い方に変わる |
| 主の問い（霧縫い） | 構えの間は姿が消え（足跡と雪を蹴る音だけ）、打ちかかる時に現れる |
| 刀の記憶（雷雨の河原） | 二合目で刀が鳴り、足が緩み、カメラが刀を向く → 触れると記憶へ → 闇の河原で三戦（最後は雷切） → 越えると流儀「稲妻」を背負い、刀の前に戻って先へ走る。刀は抜かれて消え、腰に黄色い下げ緒が付く |
| 戦いの決まり、負けてやり直す、合目の境、iPhone 表示 | 前の版と同じ結果 |

### 調べる途中で見つけて直した不具合

| 不具合 | 原因 | 直し方 |
|---|---|---|
| 相手が延々と回り込むだけで仕掛けてこないことがある | 構えの間、「回り込みの一歩」と「次の一手を考える」が取り合い、一歩が終わるとすぐ次の一歩が始まって考える番が回らなかった。コマが落ちる重い端末ほど起きやすい。蓑虫党の「止まる時間が短い」癖で表に出た | 考える番を、回り込みの一歩より先にした |
| 鎖鎌の分銅が飛ぶと、画面が固まるおそれ | 分銅に無い残像の部品を探して例外になり、そのコマの残り（カメラと描画）が止まっていた | 残像の無い飛び道具を正しく扱う。さらに、一つの処理が例外を出しても残りの処理と描画は進むようにした |
| 刀の記憶の河原が灰色に明るい | 雪山の明るい空の映り込みが、夜の濡れた石と川に映っていた。空は仕上げの処理で明るさの補正が二度かかっていた | 記憶の中では暗い夜空の映り込みに入れ替え、空の値を補正分まで下げた |

## 7. 次に作るもの（規則から）

1. 主の問いを、残りの主にも一つずつ（双弓の兄弟、垂氷の行者、雪坊主、鴉天狗）。
2. 刀の記憶を増やす（夜桜の里：手がかり＝刃の筋に花びらが渦を巻く、紅葉の山寺：拍子＝鐘の数で構えが替わる）。
3. 合目ごとに補充の速さを測り、燃え尽きの兆し（来なかった最長の間が長い合目）を直す。
