# 取り残し、相手の成功の間、危険の閃き、景色、斬撃の洗練（試作 3.9、2026-10-30）

## オーナーの評価（試作 3.8）

> 主人公の笠と鞘が取り残されている。相手が見切りや弾きに成功したときもスローモーションにして、カウンターされたことをわかりやすく。こちらの弾き成功時もスローに。風景のオブジェが手抜きなので細部まで綺麗に。危険技の赤い球体が謎でダサい。モーションはもっとダイナミックに大袈裟でいい。飛ぶ斬撃の形がダサい。剣戟エフェクトはもっと洗練して美しくできる。正直クオリティが上がっている。

| 依頼 | 原因・やったこと |
|---|---|
| 笠と鞘の取り残し | 負けて飛び散ったとき、主人公の飛び散った物（笠、鞘、縄の帯）を動かす処理を呼んでいなかった（相手の分だけ動かしていた）。主人公の分も動かすようにした |
| 相手の成功の間 | 相手に**弾かれた**とき：一瞬止まり、ゆっくりから戻る（0.11秒止まり、約0.5秒ゆっくり）。相手に**かわされた**とき：見切りと同じく時間がゆっくりになり、画面の色が抜ける（約0.65秒）。どちらも、そのあと斬り返しが来る |
| こちらの弾き | 以前は一瞬止まるだけだった。止まったあと、約0.4秒ゆっくりから戻るようにした |
| 危険の赤い球 | 丸い赤い光の玉をやめた。刃の根元から刃先へ、細く鋭い赤い十字の閃きが繰り返し走る |
| 動きの大袈裟さ | こちらの振り：ひねり 1.35 → 1.55倍、沈み・跳び・前屈みを深く、手の弧を大きく、ひねりに合わせて体を傾ける。踏み込み 1.4 → 1.7（重い斬り 1.6 → 1.9）。相手の振り：ひねり 1.3 → 1.5倍、沈みと傾きを深く |
| 飛ぶ斬撃 | 太い板のような三日月をやめた。鋭く反った細い三日月の帯で、外側の縁に白い芯、内側へ青く溶ける。後ろに二枚の残像が続く |
| 斬撃の洗練 | 筆の絵の質感をやめ、外側の縁に刃のように細く鋭い白い芯、内側へ柔らかく色を帯びて消える光にした。尾は細く淡く、先ほど強い。空気を裂いた細い筋を薄く重ねる |
