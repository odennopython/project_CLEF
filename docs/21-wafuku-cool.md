# 和装の自然な格好よさの定義（試作 1.2、2026-10-30）

## オーナーの評価（試作 1.1）

> 全体的にビジュアルはカッコ悪い。現代的でも、和装の自然なかっこよさとは何かをきちんと定義してほしい。今のは、なんか臭そうなおっさん。

## 原因

和装を部品の寄せ集めとして作り、和装が格好よく見える理由を定義していなかった。

## 定義

| 原則 | 内容 | 試作 1.1 の失敗 |
|---|---|---|
| 1. 布の面と線で見せる | 和服は直線に裁った布でできている。格好よさは体の凹凸ではなく、大きく平らな布の面がまっすぐ落ちる線から生まれる。そこに襟の合わせ、袴のひだ、袖の四角い面が重なる | 筋肉の凹凸と、ごつごつした装備で見せようとした |
| 2. 立ち姿 | 背筋が伸び、肩は下がり（なで肩）、首は長く、顎を引く。腰は据わり、膝はゆるむ | 首が太く短く、肩が盛り上がっていた |
| 3. 抑制と清潔感 | 色は2〜3色に絞る。飾りは最小限。布はきれいで、汚れやざらつきがない | 布のむらと強い陰の焼き込みが汚れに見えた。部品が多すぎた |
| 4. 比率 | 小さな顔、長い首と脚。帯の位置を高くして（腰高）、袴で脚を長く見せる | 頭が大きく、帯が低かった |
| 5. 顔 | 若く、整って、余計な彫りがない。通った鼻筋と、すっきりした顎。皺や深いくぼみは老けて見える | 目のくぼみや口を深く彫り、老けた汚れた顔になった |
| 6. 髪 | 清潔な黒髪を、きれいに束ねる。前髪が顔を縁取る | 刈り上げと小さな髷が、禿げて見えた |
| 7. 動きで映える布 | 袖、袴、羽織、鉢巻の尾が、体の動きに遅れてなびく | — |

**現代的とは、裁ち方と配色で出すもの。** 装備を足しても現代的にはならない。

## 新しい主人公

| 項目 | 内容 |
|---|---|
| 配色 | 黒に近い藍の着物、白い内襟、灰色の袴、白い羽織（裏地は深紅）、深紅の鉢巻。夜の雪の中で、白い羽織が相手の暗い姿と分かれる |
| 形 | V字に合わせた襟元、高い位置の帯、裾まで落ちるひだのはっきりした袴、肩に羽織る長い羽織、腕の動きに遅れて揺れる四角い袖 |
| 顔 | 若く整った顔。彫らずに、眉と目元を色で描く |
| 髪 | 長い黒髪を高く束ね、前髪で顔を縁取る。束ねた髪と鉢巻の尾がなびく |
| 描き方 | 布のざらつきをなくし、陰の焼き込みを弱める。影の段階を明るくし、輪郭線を細くする |

## 実装（試作 1.2）

| 原則 | やったこと |
|---|---|
| 1. 布の面と線 | 羽織の身頃を、肩から腰へわずかにすぼまる平らな面にした。裾は袴の上で少し広がる。袖は腕から垂れる平らな四角い布にした（肘をまたいで二の腕と前腕に分ける）。袴のひだは、丸い膨らみから折り目の立った鋭いひだに変えた |
| 2. 立ち姿 | 肩の線を低く細くした（なで肩）。首を細く長くした |
| 3. 抑制と清潔感 | 色を、藍に近い黒・白・灰の3色と、差し色の深紅だけにした。装備（籠手、鋼板、帯紐、外套、襟巻き、刈り上げ）をすべて外した。陰の焼き込みを弱め（肌はさらに弱く）、布のむらをなくした。影の段階を明るくし（70/150/255 → 105/178/255）、輪郭線を細くした（0.009 → 0.0065） |
| 4. 比率 | 頭を小さくした。帯を高い位置へ上げた（1.17 → 1.235）。袴を足首まで落とした |
| 5. 顔 | 頬骨、眉の稜線、目のくぼみ、口の彫りをやめた。顎を細くし（V字）、鼻を小さくした。目と眉は、顔の前に沿う薄い殻に絵として描いた（焼き出す頂点は1.35cm間隔なので、目のような細かい形は描けない） |
| 6. 髪 | 頭全体を包む黒髪にした。中央で分けた前髪と、顔の両脇に落ちる髪で顔を縁取る。高く結った髪は、動きでなびく |
| 7. 動く布 | 高く結った髪と、深紅の鉢巻の2本の尾が、動きに遅れてなびく |
| 背中 | 後ろから見る時間が一番長いので、羽織の背の中心に紋を一つだけ置いた（丸の中に一筋の太刀筋＝一閃） |

技術的な直しも入れた。

- 内側の部品が布を突き抜けると、黒い染みが出ていた。羽織を広げ、内側の部品を小さくして直した
- 輪郭線（裏返した膨らみ）が、くぼみから透けて見えていた。輪郭線を奥へ少しずらし、外形の縁にだけ出るようにした

## 残る弱点（率直に）

- 羽織と袖は骨にくっついて動く硬い形で、布として揺れない。袖が腕の動きに遅れて垂れる動きは、布の計算（ベルレ積分の面）を入れないと出ない
- 深く腰を落とす構えでは、袴の脚がつぶれて見える
- 白い羽織は光の滲み（ブルーム）で少し光って見える
- 顔の造形はまだ単純。近くで見る演出（一閃の寄り）を増やすなら、顔の形を作り込む必要がある
- コードで彫る方式の限界は変わらない（[18-character-pipeline.md](18-character-pipeline.md)）
