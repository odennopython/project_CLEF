# 世界の法則を読むとは何か

## 1. 核となるループは科学の方法そのもの

[02-fun-analysis.md](02-fun-analysis.md) で見つけた「隠れた構造を読む」ループは、科学の方法と同じ形をしている。

| ゲームのループ | 科学の方法 | 物理学の歴史での例 |
|---|---|---|
| 観察する | 観測 | ティコ・ブラーエが惑星の位置を記録した |
| 仮説を立てる | 仮説 | ケプラーが惑星の軌道は楕円だと考えた |
| 取り消せない形で決める | 予測を公表する | ニュートンの理論でハレー彗星の回帰を予言した |
| 結果が返る | 実験・観測 | 1758年に彗星が戻ってきた |
| モデルを直す | 理論の修正 | 水星の軌道のずれから、一般相対性理論が生まれた |

オーナーの指摘：「これは物理という過去の世界そのもの」。人類が物理法則を見つけてきた道のりは、このゲームが目指す体験の原型である。

## 2. F=ma はなぜ成り立つのか（オーナーの問い）

**結論：物理学は「なぜ」を完全には説明できない。** できるのは、より深い原理から導くことだけで、一番底の原理は説明されないまま残る。

### 説明の層

| 層 | 内容 | この層で説明できること |
|---|---|---|
| 現象 | 物を押すと動く、落ちる | — |
| 経験則 | ガリレオの落体の法則、ケプラーの法則 | 現象の規則性を短く書ける |
| 法則 | ニュートンの運動の法則（F=ma） | 地上の落下と天体の運動を1つの法則で説明できる |
| 原理 | **最小作用の原理**（物体は「作用」という量が停留する経路を通る） | F=maがここから導ける。マクスウェル方程式や相対性理論も同じ形で書ける |
| 対称性 | **ネーターの定理**：空間がどこでも同じなら運動量が保存され、時間がいつでも同じならエネルギーが保存される | 保存則がなぜ成り立つのかを、世界の対称性から説明できる |
| 量子論 | 量子力学の経路積分では、あらゆる経路の寄与が打ち消し合い、最小作用の経路だけが残る | なぜ最小作用の原理が成り立つのかを説明できる |
| 底 | なぜ世界がこの対称性を持つのか。なぜ量子力学なのか | **説明されていない** |

### 補足

- **F=maには定義の側面もある**：「力」と「質量」は、F=maを通して定義されている面がある（マッハやポアンカレの議論）。純粋な発見ではなく、世界を記述するための約束事も含んでいる。
- **F=maは近似である**：光の速さに近いと相対性理論、原子の大きさになると量子力学が必要になる。法則には**通用する範囲**がある。
- **マクスウェル方程式**は、電気、磁気、光という別々に見えた現象を4つの式にまとめた。現代では、これも対称性（ゲージ対称性）から導かれる。

### LLMとの比較

LLMのスケーリング則（モデルの大きさ、データ量、計算量を増やすと、性能がべき乗則に従って上がる）は、今のところ**経験則**の層にある。規則性は見つかっているが、なぜそうなるかを完全に説明する理論はまだない。

これは、ケプラーの法則（経験則）が見つかってからニュートンの法則（その理由）が見つかるまでの、**間の時代**に似ている。

## 3. ゲーム設計への示唆

### 示唆1：面白さとは「圧縮」の進歩である

F=maやマクスウェル方程式が美しいのは、**膨大な現象を、少ない記号に圧縮している**から。

- コスターの「面白さとはパターンを学ぶこと」は、言い換えれば、観察を短いルールに圧縮すること。
- ユルゲン・シュミットフーバーは「面白さとは、観察をより短く圧縮できるようになった、その進歩の量である」という理論を出している。
- **洗練も圧縮である。** 少ない要素で多くを表す。表面は単純、中身は深い。

**面白さ（①学習）と洗練（デザインの方向性）は、同じ「圧縮」という原理でつながっている。**

### 示唆2：理解には層がある

物理学の歴史では、現象 → 経験則 → 法則 → 原理と、理解が層になって深まってきた。深い法則が見つかると、それまでの法則が**その特殊な場合**としてまとめられる。

ゲームに当てはめると、次のような体験を作れる可能性がある。
- 最初は「こうするとこうなる」という経験則を見つける。
- やがて、いくつかの経験則が、実は1つのより深い法則から出ていることに気づく。
- この「まとまる瞬間」が、一番大きな「わかった！」になる（電気と磁気と光が1つにまとまったように）。

### 示唆3：法則には通用する範囲がある

F=maが極端な条件で崩れるように、「今まで正しかった法則が通用しない場面」は、次の層への入り口になる。プレイヤーの頭の中のモデルが**裏切られ、作り直される**体験を設計できる。ただし柱1（法則は一貫している）を守るため、崩れ方にも法則がなければいけない。

### 示唆4：世界を理解する道具

オーナーの指摘：「この世界を理解する道具には面白いものがたくさんある」。数式、グラフ、地図、記号、モデルは、人類が法則を捉えるために作った道具である。

プレイヤーに道具を与える、あるいはプレイヤー自身が道具を作ることで、理解を外に書き出して確かめられるようにする方向も考えられる。ただし、道具が増えると画面が複雑になり、洗練とぶつかる可能性がある。

## 4. 未決の問い

- 法則は現実の物理法則をそのまま使うか、架空の世界の法則にするか。
  - 現実の法則：学んだことが現実の世界の見え方を変える（③世界とのつながり）。ただし、知識のある人には最初から答えがわかってしまう。
  - 架空の法則：誰にとっても新しい発見になる。ただし、作者の思いつきに見えないよう、物理法則並みの一貫性が必要。
- 層の構造（経験則 → 法則 → 原理）を、1回数分の遊びにどう分けるか。
- 道具を与えるか、道具なしで頭の中だけで理解させるか。
