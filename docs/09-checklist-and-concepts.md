# 面白さのチェック項目と、全項目に合格した案

[08-concepts.md](08-concepts.md) の失敗（型に当てはめた量産）を受けて、先にチェック項目を作り、全項目に合格した案だけを残した。

## 1. チェック項目（22項目）

### A. 面白さの構造（参考の6本に共通するループ）

| # | 項目 | 合格の条件 |
|---|---|---|
| 1 | 隠れた法則 | 世界の振る舞いの裏に、観察から推測できる法則がある。作者の思いつきではない |
| 2 | ループの回転 | 数分の1回の遊びの中で、観察 → 仮説 → 決定 → 結果 → 修正が3周以上回る |
| 3 | 取り消せない決定と即時の結果 | 決定は取り消せず、結果は数秒で、原因が見える形で返る |
| 4 | 世界が応じてくる | 世界はただの的ではない。自分の法則で動き、状況を変えてくる |
| 5 | 失うものがある | 失敗すると何かを失う。ただし致命的ではなく、すぐ再挑戦できる |
| 6 | 公正な失敗 | 失敗の原因を、自分の読み違いとして特定できる。運のせいにならない |

### B. ①学習・上達

| # | 項目 | 合格の条件 |
|---|---|---|
| 7 | 最初の気づき | 説明なしで、最初の1分以内に最初の法則に気づける |
| 8 | 理解の層 | 理解が3段以上の層になっている（経験則 → 組み合わせ → まとめる原理） |
| 9 | 少数の規則 | 深さが少数の規則の組み合わせから生まれる。規則の一覧が1画面に収まる |
| 10 | 知識で進む | 進み方を決めるのは知識だけ。レベル、装備、課金では先へ進めない |

### C. ②集中

| # | 項目 | 合格の条件 |
|---|---|---|
| 11 | 目標の明快さ | 目標は言葉なしで一目でわかり、方法は隠れている |
| 12 | 難しさを選べる | 1つの世界の中で、挑む場所をプレイヤーが選べる。モードの切り替えがない |

### D. ③内から湧く動機

| # | 項目 | 合格の条件 |
|---|---|---|
| 13 | 自律 | 同じ目標に複数の解き方がある。答えが1つのパズルではない |
| 14 | 有能感と核 | 上達すると、少ない介入で同じ結果を出せるようになる。「一度だけ」という制約ではなく、到達点としての最小の一触れ |
| 15 | つながり | 法則がその世界の自然に感じられる。発見に名前を付けて残せる |

### E. 創発と増幅

| # | 項目 | 合格の条件 |
|---|---|---|
| 16 | 読める増幅 | 急所を見抜けば、小さな介入で大きく、狙いどおりに世界が動く |

### F. 洗練・手軽さ・実現性

| # | 項目 | 合格の条件 |
|---|---|---|
| 19 | 時間の主導権 | 世界は止まって待つ。反射神経がいらず、いつでも閉じられる |
| 20 | 洗練 | 画面は世界だけ。外から与える報酬、通知、広告がない。静かだが退屈ではなく、静けさと緊張の対比がある |
| 21 | 人間工学 | 介入は指先より大きい単位。タップ・ドラッグ・ピンチだけで、片手・縦持ちで遊べる |

### 一覧全体の規則

**構造の重複の禁止**：他の案と「題材を入れ替えただけ」の関係にしない。プレイヤーの役割、世界の押し返し、失うもの、進み方のうち、2つ以上が違うこと。

### 判定についての注意

- 判定は紙の上での設計の判定であり、遊んで確かめたものではない。
- 特に16（読める増幅）と6（公正な失敗）は、試作で確かめる必要がある。各案の「試作で確かめる仮説」に書いた。
- 判定したのは提案者自身なので、甘くなっている可能性がある。

## 2. 結果

46案を考え、**20案が全項目に合格**した。目標は30案だったが、30に届かせるには、構造が重複する案（題材を入れ替えただけの案）を入れるしかなかったため、20案で止めた。

### 全案に共通する仕組み

- 世界は止まって待っている。触れて確定すると、数秒だけ世界が動き、また止まる（19）。
- 1つの地図の上に地域があり、どこに挑むかを選べる（12）。
- 見つけた現象には名前を付けて手帳に残せる（15）。

## 3. 合格した20案

### 1. 形の博物誌
- **背景**：誰も知らない法則で動くマス目の世界。夜の標本室のように、形が生まれては消える。
- **操作**：小さな形（最初は1マスだけ）を置く。世界が動き出し、落ち着くまで見守る。発見して記録した形は、次から道具として置ける。
- **1回の遊び**：遠くの灯りまで「動く形」を届ける、流れてくる野生の形の列を止める、眠っている区域を目覚めさせる。数手置いては見守る、を繰り返す。
- **世界の押し返し**：野生の形が行き交い、置いた形を壊していく。
- **失うもの**：置いた構造と、その遠征で持ち出した形。
- **進み方**：手帳に記録した形だけが道具になる。理解が深いほど、少ないマスで目的の形を作れる。
- **理解の層**：止まった形 → 点滅する形 → 動く形 → 形どうしの衝突 → 衝突で新しい形を作る → 形を撃ち出し続ける装置
- **ゾクッとする瞬間**：2つの動く形をぶつけると、まったく別の形が生まれる。「衝突の組み合わせで何でも作れる」とわかる瞬間。
- **試作で確かめる仮説**：独自の規則で、ライフゲームのように豊かな形の世界が作れるか。

### 2. 潮だまりの生き物
- **背景**：早朝の磯の潮だまり。粒が集まって、生き物のような塊が泳いでいる。
- **操作**：指でなぞって、水を少しだけ動かす（粒を押す）。
- **1回の遊び**：塊が水路を渡れるように導く。二種類の塊が共存できる状態にする。押しては数秒見守る、を繰り返す。
- **世界の押し返し**：塊は自分で動き、他の塊を食べ、分裂し、崩れる。
- **失うもの**：種の絶滅。この世界の記録として残り、戻らない。
- **進み方**：潮だまりは水路でつながっている。塊を別の潮だまりへ運べるのは、その塊が何で形を保っているかを理解したときだけ（理解せずに運ぶと崩れる）。
- **理解の層**：粒の引き合いと反発 → 塊ができる条件 → 塊どうしの捕食と共生 → 潮だまりごとの環境の違い
- **ゾクッとする瞬間**：「生き物」に見えていたものが、粒の踊りが安定しているだけだと気づき、自分でも一から組み立てられるとわかる瞬間。
- **試作で確かめる仮説**：塊が、人間が見分けられるほど安定した「種」として振る舞うか。

### 3. 風を読む舟
- **背景**：島々が点在する静かな海。島の陰には、渦が左右交互に流れている。
- **操作**：プレイヤーは小舟。帆の向きを決めて数秒だけ進む、を繰り返す。
- **1回の遊び**：次の島の港まで渡る。渦の列のリズムを読んで、隙間を抜ける。
- **世界の押し返し**：島の配置が作る流れが舟を押し流す。風向きは時刻で変わる。
- **失うもの**：転覆すると積み荷はその海域に沈み、最後の港からやり直す。沈んだ場所に戻れば拾える。
- **進み方**：舟の性能は上がらない。流れの理解だけが、遠くの島へ行く手段になる。
- **理解の層**：流れに乗る → 島の陰の渦の列 → 渦の大きさと流れの速さの関係 → 島の並びが作る流れの共鳴
- **ゾクッとする瞬間**：渦の列のリズムがわかり、帆を一度も動かさずに渦から渦へ乗り継げた瞬間。
- **試作で確かめる仮説**：流れがカオスにならず、読める範囲に収まるか。スマホで流体の計算が軽く動くか。

### 4. 雪嶺の村
- **背景**：雪深い山脈。谷ごとに小屋と峠道がある。
- **操作**：一手ごとに、雪を一粒落とすか、一粒取り除く。そのあと雪が降り、崩れるべき場所が崩れる。
- **1回の遊び**：峠道を開けておく、小屋を守る。溜まった雪を、小さな一粒で安全な方向へ崩す。
- **世界の押し返し**：雪は毎手降り積もり、山全体が崩れる寸前に近づいていく。
- **失うもの**：埋まった小屋と道は埋まったまま残る。
- **進み方**：崩れ方の理解が、新しい谷への峠を開く。
- **理解の層**：隣へ崩れる規則 → 雪崩の大きさの分布 → 崩れる順番に関係なく結果が決まる性質 → 山に隠れている応力の模様（フラクタル）
- **ゾクッとする瞬間**：山全体に目に見えない応力の模様が隠れていて、それが読めるようになった瞬間。
- **試作で確かめる仮説**：地形ごとの違い（岩、森）で、学ぶことが十分に増えるか。

### 5. 灯の町
- **背景**：夜の町。灯りは隣が点くと少し遅れて点き、しばらく休む。
- **操作**：一つの灯りを、好きな瞬間に点ける。
- **1回の遊び**：町のあちこちで、自分で回り続ける光の渦（光の嵐）が勝手に生まれ、油を使い果たしていく。正しい場所とタイミングの一回の点灯で嵐を消す。遠くの灯台まで光を届ける。
- **世界の押し返し**：光の嵐が自然に生まれ、ぶつかり、分裂する。
- **失うもの**：油が尽きた区域は暗くなり、しばらく戻らない。
- **進み方**：灯りが休む時間の理解が、大きな町を任される条件になる。
- **理解の層**：光が伝わる → 灯りには休む時間がある → 波どうしは打ち消し合う → 波の端が巻いて渦になる → 渦の消し方
- **ゾクッとする瞬間**：嵐の中心近くの一点をちょうど良い瞬間に点けると、渦がほどけて消える。それが心臓の除細動と同じ原理だと知る瞬間。
- **試作で確かめる仮説**：嵐が自然に生まれる頻度を、緊張と静けさが釣り合うように調整できるか。

### 6. 朝市の町
- **背景**：川沿いの朝市。何百人もの商人が、それぞれ単純な考え方で売り買いしている。
- **操作**：プレイヤーは商人の一人。一手ごとに、買う・売る・待つのどれか一つを選ぶか、うわさを一つ流す。そのあと市が一日動く。
- **1回の遊び**：値段の動きを読み、少ない取引で蓄えを増やす。バブルが膨らみ、はじけるのを見抜く。
- **世界の押し返し**：商人たちの群れの行動から、値段の波、バブル、暴落が自然に生まれる。自分の取引も市に影響する。
- **失うもの**：蓄え。
- **進み方**：町ごとに商人の性格の混ざり方が違う。市の理解が、大きな町へ行く条件になる。
- **理解の層**：需要と供給 → 他人の真似をする商人が生む波 → バブルの生まれ方 → 自分の取引が引き金になる連鎖
- **ゾクッとする瞬間**：自分の小さな売りが群れの連鎖を起こし、暴落の引き金になる。そしてそれを予見できるようになったとき。
- **試作で確かめる仮説**：運ではなく読みで勝てるように商人の行動のでたらめさを抑えても、市が生き生きと動くか（6：公正な失敗）。

### 7. 夜の観測所
- **背景**：霧に包まれた夜の観測所。見えない世界が、霧の向こうで自分の法則で動いている。
- **操作**：一か所を観測する（その場所だけが一瞬見える）か、一度だけ介入する。観測すると、その場所の世界がわずかに乱れる。
- **1回の遊び**：霧の向こうを通過する何かを、少ない観測で予測し、一度の介入で捕まえる。
- **世界の押し返し**：世界は見えないところで動き続け、観測そのものが世界を乱す。
- **失うもの**：一夜の観測回数。通過する現象は一度きりで、逃すと戻らない。
- **進み方**：法則を理解するほど、少ない観測で見通せる。観測の少なさそのものが上達になり、核の「最小の一触れ」が観測にも働く。
- **理解の層**：見えている部分の動き → 見えない部分の推測 → 観測が世界を乱す法則 → 乱さずに知る方法
- **ゾクッとする瞬間**：一度も見ていない場所の状態を言い当てた瞬間。
- **試作で確かめる仮説**：見えないことが、ストレスではなく緊張になるか。霧の向こうの世界には、他の案の世界を使える。

### 8. 苔の庭師
- **背景**：雨上がりの寺の庭。苔が斑点、縞、迷路の模様を描いている。
- **操作**：指でなぞって、その場所の日当たりと湿り気を変える。法則そのものは変わらず、環境だけが変わる。
- **1回の遊び**：生きている模様を導いて、石と石の間に道を作る。広がりすぎた模様から花を守る。
- **世界の押し返し**：模様は自分で育ち、増え、境界で別の模様とせめぎ合う。
- **失うもの**：飲み込まれた花は戻らない。
- **進み方**：見つけた模様は手帳に記録される。自分を複製する斑点のような模様は、別の庭へ持ち運べる。
- **理解の層**：環境で模様が変わる → 模様どうしの境界のふるまい → 自分を複製する模様 → すべての模様が1つの法則から出ていると気づく
- **ゾクッとする瞬間**：斑点も縞も迷路も同じ1つの法則から生まれていて、違うのは環境だけだと気づく瞬間。
- **試作で確かめる仮説**：環境を変える操作が、精密すぎず、指で扱える大きさで効くか。

### 9. 羊飼いの犬
- **背景**：風の吹く高原。何百頭もの羊の群れと、それを狙う狼の群れ。
- **操作**：プレイヤーは犬。一手ごとに一か所へ動く。そのあと数秒、群れが動く。
- **1回の遊び**：群れを谷の向こうの牧草地へ導く。狼から守る。
- **世界の押し返し**：群れは自分の規則で動き、狼は群れの端を狙う。
- **失うもの**：狼に取られた羊。
- **進み方**：群れの理解が、季節ごとにより遠い牧草地へ、より大きな群れを連れて行く条件になる。
- **理解の層**：犬から逃げる → 隣に揃う → 群れの向きは端から波のように変わる → 群れが割れる条件、渦を巻く条件
- **ゾクッとする瞬間**：群れの端の一点に犬を少し寄せるだけで、何百頭が一斉に向きを変える瞬間。
- **試作で確かめる仮説**：犬一匹の影響が、読める形で群れ全体に伝わるか。

### 10. 雨と川
- **背景**：雨の降る山々と、まだ川のない谷。
- **操作**：一手ごとに、一か所に雨を降らせる。
- **1回の遊び**：雨が地面を削って川になる。川を導いて乾いた村に水を届ける。洪水から村を守る。
- **世界の押し返し**：川は自分で蛇行し、削り、別の川の水を奪う（河川争奪）。
- **失うもの**：地形の変化は元に戻らない。水没した村も戻らない。
- **進み方**：川の理解が、舟で行ける場所を広げる（川そのものが道になる）。
- **理解の層**：水は低い方へ流れる → 流れが地面を削る → 曲がりは自分で大きくなる（蛇行） → 尾根の一点の雨で川全体の行き先が変わる
- **ゾクッとする瞬間**：尾根のたった一か所に降らせた雨で、大きな川の流れがまるごと隣の谷へ移る瞬間。
- **試作で確かめる仮説**：侵食の計算がスマホで十分速く動くか。地形が変わるまでの時間を、数分の遊びに収められるか。

### 11. 伝言の村
- **背景**：山あいに点在する村々。村人はそれぞれ、いくつかの習慣を持っている。
- **操作**：プレイヤーは旅人。一手ごとに、一人の村人に一つの習慣を伝える。
- **1回の遊び**：村と村の間に交流を取り戻す。祭りを複数の村に広める。
- **世界の押し返し**：村人は似た人と影響し合い、地域がまとまったり、分断されたりする。
- **失うもの**：完全に分断された村は、もう旅人を受け入れない。
- **進み方**：村々の関係の理解が、閉ざされた谷への道を開く。
- **理解の層**：似た者どうしは影響し合う → 地域ごとに文化がまとまる → 分断が生まれる仕組み → 二つの文化の両方を持つ一人が分断をつなぎ直す
- **ゾクッとする瞬間**：誰も分断を望んでいないのに、近い者どうしが似ていくだけで世界が分かれると気づく瞬間。そして一人の橋渡しでそれがつながる瞬間。
- **試作で確かめる仮説**：習慣を、抽象的にならず見て分かる形で表現できるか。

### 12. 夜の送電網
- **背景**：夜の地方。発電所と町が送電線でつながり、灯りがともっている。
- **操作**：一手ごとに、送電線を一本つなぐか切る。または一つの町の電気を一時的に止める。
- **1回の遊び**：夜の需要の波を乗り切る。一つの故障が連鎖して大停電になるのを一手で止める。
- **世界の押し返し**：需要が刻々と変わる。一か所の故障は、周りに負荷をかけて連鎖する。
- **失うもの**：停電した町は朝まで戻らない。
- **進み方**：網の理解が、より大きな網を任される条件になる。
- **理解の層**：電気の流れ → 発電所どうしが足並みを揃える（同期） → 故障の連鎖 → 線を足すとかえって不安定になることがある（ブライスのパラドックス）
- **ゾクッとする瞬間**：良かれと思って足した一本の線が網全体を不安定にし、逆に一本切ることで網が安定する瞬間。
- **試作で確かめる仮説**：同期と連鎖の振る舞いを、物理として正しく、かつ見て分かる形にできるか。

### 13. 進化の水盤
- **背景**：浅い水盤の中にいる、小さな生き物の集団。
- **操作**：一手ごとに、一か所に養分を一滴落とす。
- **1回の遊び**：生き物の集団を、毒の帯の向こう側まで進化させて渡らせる。
- **世界の押し返し**：生き物は増え、変異し、選ばれ、自分で進化する。思いどおりの形になるとは限らない。
- **失うもの**：系統の絶滅。
- **進み方**：選ばれる力（淘汰圧）の理解が、より難しい環境への挑戦を開く。
- **理解の層**：増える → 変わる → 選ばれる → 少しずつ毒を濃くした段差を作ると適応が一気に進む
- **ゾクッとする瞬間**：自分が置いた養分の段差に沿って、生き物が目の前で適応していく瞬間（実際の大腸菌の実験「MEGA-plate」と同じ現象）。
- **試作で確かめる仮説**：変異にでたらめさがあっても、進化の「方向」が読める形で現れるか（6：公正な失敗）。

### 14. 蟻の斥候
- **背景**：雨上がりの森の地面。蟻の巣と、競い合う別の巣がある。
- **操作**：プレイヤーは斥候の一匹。一手ごとに少しだけ歩いて、匂いの道を残す。
- **1回の遊び**：巣の仲間を餌場へ導く。別の巣との縄張り争いで餌場を守る。
- **世界の押し返し**：仲間は匂いの濃い道を選んで強める。雨は匂いを流す。別の巣も道を伸ばしてくる。
- **失うもの**：巣の餌。尽きると巣が弱る。
- **進み方**：匂いの道の理解が、より遠い餌場へ挑む条件になる。
- **理解の層**：匂いをたどる → 多く通る道は濃くなる → 短い道が自然に選ばれる → 一本の短い道を引くだけで巣全体の流れが変わる
- **ゾクッとする瞬間**：自分が引いた短い一本の道に、巣の何百匹がゆっくり乗り換えていく瞬間。
- **試作で確かめる仮説**：一匹の残す道が、巣全体の流れを変えるほど効くか。

### 15. 潮と石
- **背景**：浜辺の碁盤のような世界。満ち引きする潮が、自分の法則で陸を削っていく。
- **操作**：一手ごとに石を一つ置く。そのあと潮が一手動く。将棋のように交互に進む。
- **1回の遊び**：潮との一局。潮に削られずに残る陸地を、決まった広さまで築く。
- **世界の押し返し**：潮は毎手、自分の規則で陸を削り、満ちてくる。
- **失うもの**：その一局の陸地。
- **進み方**：浜ごとに潮の規則が違う（新しい法則の相手）。勝った浜の規則は手帳に残る。
- **理解の層**：石を置くと潮の流れが変わる → 残る形と削られる形 → 潮の動きの先読み → 潮の力を逆に使って陸を広げる
- **ゾクッとする瞬間**：潮を敵だと思っていたのに、潮の規則を利用すれば潮が陸を築いてくれると気づく瞬間。
- **試作で確かめる仮説**：潮の規則が、将棋のように先読みできる深さを持つか。

### 16. 記憶の森
- **背景**：星空のような、無数の光る点のつながり。それ自体が一つの小さな頭脳になっている。
- **操作**：一つの点を光らせるか消す。または一つの形を「覚えさせる」。
- **1回の遊び**：欠けた手がかりから、覚えさせた形を思い出させる。少ない手がかりで正しく思い出させる。
- **世界の押し返し**：頭脳は自分の法則で、最も近い記憶へ落ち着こうとする。覚えさせすぎると記憶どうしが混ざり、壊れる。
- **失うもの**：壊れた記憶は戻らない。
- **進み方**：記憶の仕組みの理解が、より大きな頭脳を任される条件になる。
- **理解の層**：手がかりから全体を思い出す → 似た記憶は混ざる → 覚えられる量には限界がある → 教えていない「偽の記憶」が自分で生まれる
- **ゾクッとする瞬間**：一度も教えていない形を、頭脳が自分から思い出した瞬間。LLMにも通じる「記憶とは何か」に触れる。
- **試作で確かめる仮説**：抽象的な点のつながりを、見て分かる美しい形で見せられるか。

### 17. 一つの細胞から
- **背景**：静かな水の中の、一つの細胞。
- **操作**：一手ごとに、一つの細胞の一つの遺伝子をオンかオフにする。
- **1回の遊び**：細胞は分裂し、互いに信号を送りながら役割を分けていく。目標の形（たとえば枝分かれした形）の生き物に育てる。
- **世界の押し返し**：細胞どうしの信号と遺伝子のつながりが、自分の法則で細胞の運命を決めていく。
- **失うもの**：形が崩れた個体は育たない。
- **進み方**：発見した「細胞の運命を決める遺伝子」が手帳に残り、より複雑な生き物を育てる手段になる。
- **理解の層**：遺伝子のオン・オフが細胞の状態を決める → 状態はいくつかの安定した型（細胞の種類）に落ち着く → 隣の細胞への信号 → 一つの「親玉の遺伝子」で運命が変わる
- **ゾクッとする瞬間**：一つの遺伝子を一度切り替えただけで、そこから先の体の形がまるごと変わる瞬間（実際の山中因子と同じ原理）。
- **試作で確かめる仮説**：遺伝子のつながりを、言葉なしで理解できる形で見せられるか。16と数学的に近いので、どちらか一方に絞る可能性がある。

### 18. 道と町
- **背景**：まだ町のない、広い平野。
- **操作**：季節ごとに、道を一本引く。
- **1回の遊び**：人の集まりが道に沿って生まれ、育ち、衰える。決まった場所に大きな町を育てる。消えかけた村を残す。
- **世界の押し返し**：町どうしが人と商いを奪い合う。
- **失うもの**：衰えて消えた村は戻らない。
- **進み方**：平野ごとに地形が違う。町の育ち方の理解が、広い地域を任される条件になる。
- **理解の層**：道に人が集まる → 集まるほどさらに集まる → 町と町の間隔が自然に決まる → 町の配置に六角形の模様が自然に現れる（クリスタラーの中心地理論）
- **ゾクッとする瞬間**：誰も設計していないのに、町が六角形の網目に並んでいると気づく瞬間。
- **試作で確かめる仮説**：季節の進みを、1回数分の遊びに収められるか。

### 19. 生命の起源
- **背景**：太古の海の、温かい潮だまり。いくつかの種類の分子が漂っている。
- **操作**：一手ごとに、分子を一つ投入する。
- **1回の遊び**：分子は出会うと反応して別の分子になる。互いを作り出し合う分子の輪（自己触媒）が生まれ、自分で増え始める状態を目指す。
- **世界の押し返し**：反応は自分の法則で進む。多くの場合、輪は生まれずに、ただの平衡に落ち着いてしまう。
- **失うもの**：平衡に落ち着いて「死んだ」潮だまりは戻らない。
- **進み方**：生まれた輪は手帳に残り、別の潮だまりに持ち込める。分子の輪から、膜に包まれた原始の細胞へ。
- **理解の層**：分子は出会うと反応する → ある分子が別の反応を助ける（触媒） → 助け合いが輪になると自分で増える → 輪どうしの競争
- **ゾクッとする瞬間**：投入した一つの分子が輪を閉じて、潮だまり全体が自分で増え始める瞬間。「生命はこうして始まったのかもしれない」と感じる瞬間。
- **試作で確かめる仮説**：化学の規則を、少数で、見て分かる形にできるか。

### 20. 砂の旅人
- **背景**：夜明けの砂漠。三日月形の砂丘が、風に押されてゆっくり移動している。
- **操作**：プレイヤーは旅人。一手ごとに、一握りの砂を置くか、一歩進む。
- **1回の遊び**：移動してくる砂丘からオアシスを守る。砂丘の間を抜けて、次のオアシスへ渡る。
- **世界の押し返し**：砂丘は自分で動き、ぶつかり、砂を受け渡す。
- **失うもの**：埋まったオアシスと、そこまでの水。
- **進み方**：砂丘の理解が、より深い砂漠への道を開く。
- **理解の層**：砂は風で運ばれる → 小さな盛り上がりは砂丘に育つ → 砂丘は小さいほど速い → 砂丘どうしがぶつかると砂を受け渡し、すり抜けたように見える
- **ゾクッとする瞬間**：二つの砂丘がぶつかり、小さい方が大きい方をすり抜けて前に出たように見える。実際には砂の受け渡しだと理解したとき。
- **試作で確かめる仮説**：砂丘の動きが遅すぎて、数分の遊びにならない可能性。時間の速さで調整できるか。
