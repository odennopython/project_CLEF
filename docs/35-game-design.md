# ゲームとしての仕上げ：繰り返したくなる構成と報酬（提案・判断待ち、2026-10-31）

## オーナーの問い

> 面白くなってきた。今度はゲームとして仕上げたい。連戦するローグライクのような構成がいいか。今の敵は強いのでボス級。繰り返し性のあるゲームになるが、繰り返しても何度もやりたい、楽しいと思わせる体験と報酬の作り方を設計したい。

## まず率直に：ローグライクの「型」はそのままでは柱とぶつかる

一般的なローグライクの楽しさの多くは「ランごとに拾う強化（攻撃力が上がる、新しい能力を得る）」から来ている。これは二つの柱とぶつかる。

| ぶつかる柱 | 理由 |
|---|---|
| 柱3：上達はプレイヤーの頭の中に残る | 強化で勝てると、勝因が「拾った物」になる。データを消すと弱くなる |
| 柱4：負けは「運が悪かった」でなく「読みが違った」 | 良い強化が出なかった、という負け方が生まれる |

一方で、ローグライクの **構造** には柱と相性のよい部分がある：**毎回違う組み合わせ**（柱2）、**1回の挑戦が短く、負けたら即やり直す**（柱4、柱5）、**取り消せない選択に重みがある**（柱4）。

**提案：強化ではなく「組み合わせ」と「取引」が変わるローグライク。** プレイヤーの力は一切増えない。変わるのは、出会う相手の組み合わせと、自分で選ぶ「誓い」（代償と見返りの取引）だけ。

## 繰り返したくなる理由の分解

なぜ人は同じ遊びを何百回も繰り返すのか。参考ゲーム（SEKIRO、将棋、ポケモン対戦、Kaggle）に共通する構造から分解した。

| # | 理由 | このゲームでの作り方 |
|---|---|---|
| 1 | **毎回、少し違う** | 相手の流派（戦い方の型）の組み合わせが毎回変わる。行動エンジン（[30-behavior-engine.md](30-behavior-engine.md)）の戦術の重みを流派ごとに変えるだけで、まったく違う相手になる |
| 2 | **前よりできるようになった実感** | 前は捌けなかった技が読める。数値ではなく、体の感覚として返る（柱3） |
| 3 | **次の目標がはっきりしている** | 「次の段」という一本の明確な壁 |
| 4 | **1回が短く、負けても即やり直せる** | 1回の登山は数分。負けたら待ち時間なしで麓から（柱4、柱5） |
| 5 | **負けに納得できる** | 運の要素はプレイヤーの力に入れない。負けは読みの誤り（柱4） |
| 6 | **相手も自分を学ぶ** | 回数を重ねるほど、相手がこちらの勝ち方を覚える。前回の勝ち方が通じにくくなり、毎回違う勝ち方を探すことになる（[10-boss-angles.md](10-boss-angles.md) の案E） |
| 7 | **自分の上達が美しく返ってくる** | 離れ業を成したとき、世界が静かに、美しく応える（下の「報酬」） |

## 提案する構成：「白峰を登る」

### 1回の挑戦（登山）

- 雪の参道を、麓から頂上へ登る
- 途中に **関所が三つ**。それぞれに、ある流派の剣士が一人待つ
- **頂上に、今の白峰の浪人**（ボス）
- 合わせて4戦、10分前後。関所ごとに区切りがつき、閉じてもその関所から再開できる（柱5、柱6）
- 負けたら麓から。待ち時間はない

### 流派（相手の多様さの源）

相手は同じ人体・同じ動きの仕組みで、**戦術の重みと、技の家族と、法則一つ**で流派になる。

| 流派 | 中心の戦術 | 固有の法則（一つだけ） |
|---|---|---|
| 居合 | 居合の構え、待ち | 構えている間は、斬りかかると必ず抜き打たれる |
| 旋風 | 旋風、回転の様式 | 回転の止めの一撃だけが重く、そこを弾くと大きく崩れる |
| 弓 | 弓、跳び退き | 間合いが開くほど矢が増える。詰めると刀へ持ち替える隙がある |
| 剛 | 上段、剛の様式 | 弾かれても怯まない。ただし受けると崩しが倍 |
| 影 | 虚の連鎖、回り込み | 起こりの半分が虚。本物は腰が先に動く（腰を読む流派） |
| 飛刃 | 飛ぶ斬撃、詰め | 斬撃を弾き返すと、相手に返って当たる |

関所の相手は、段が上がるほど **二つの流派を混ぜる**（柱2：法則を足すのでなく、組み合わせで深くする）。

### 誓い（ランごとの選択：強化ではなく取引）

関所と関所の間の焚き火で、**三つの誓いから一つ** を選ぶ（選ばなくてもよい）。誓いは力を足さない。**ルールを取引する**。

| 誓いの例 | 代償 | 見返り |
|---|---|---|
| 一太刀 | 一度斬られたら倒れる | 弾きの崩しが大きい |
| 刃を寝かす | 斬りの崩しが半分 | 弾きの受け付けが広い |
| 無返し | 反撃（弾き直後の上）が使えない | 一閃の機会が長い |
| 素足 | 避けると次の避けまで間が要る | 避けが遠く、見切りの時間が長い |
| 盲 | 相手の危険の閃きが見えない | 崩しが速い |

誓いは取り消せない（柱4）。どの誓いが自分の戦い方に合うかを読むことも、上達の一部になる。誓いを重ねるほど、頂上の記録が重くなる。

### 段（長い壁）

- 頂上の白峰を制すると、山の **段** が一つ上がる
- 段ごとに、相手に **法則が一つ加わる**（数値は上げない）。例：二段＝関所の相手が誓いを持つ、三段＝流派を混ぜる、四段＝ボスが二つ目の構えを持つ、五段＝ボスがこちらの直前の勝ち方を封じる…
- 最終目標は **十段の白峰を、無傷で**

## 報酬：外から与えず、内から湧かせる

ガチャ、経験値、通貨は使わない（柱3、[01-decisions.md](01-decisions.md)）。報酬は四つ。

1. **発見**：新しい流派、新しい組み合わせ、相手の新しい法則に出会う。「そうか、腰を見ればよかったのか」の瞬間
2. **型の名**：離れ業（矢を斬り落とす、飛ぶ斬撃を弾き返して当てる、旋風の全段を弾く、一度も避けずに勝つ…）を初めて成すと、その離れ業が「型」として記録される。以後その型を成すたびに、固有の音と光で世界が応える。新しい能力ではなく、**自分が成したことへの名と美しさ**
3. **社に積もる証**：頂上の社に、自分の記録が形として静かに奉納される（段ごとの刀、無傷の白い羽、連続の弾きの鈴、型ごとの絵馬）。数字も通知もない。登るたびに、社が少しずつ自分の歴史になる
4. **相手の変化**：白峰の浪人は登るたびにこちらを覚え、戦い方を変える。いつまでも「知っている相手」にならない

### 外す報酬と、その理由

| 外す物 | 理由 |
|---|---|
| 強化（攻撃力、体力、新しい能力の解禁） | 柱3。勝因が自分の理解でなくなる |
| 日替わりの挑戦、期限付きの報酬 | 柱5、柱6。「今やらないと損」を作る |
| ランキング | 他人との比較は外からの動機。入れるなら、自分の過去の記録との比較だけ |

## 判断が必要なこと

1. **ローグライク型（流派の組み合わせ＋誓い＋段）で進めてよいか**。それとも、ボスを一体ずつ増やす直線的な構成（SEKIRO 型）か
2. **1回の挑戦の長さ**：関所三つ＋頂上（10分前後）か、関所二つ＋頂上（6〜7分）か
3. **「型の名」と「社の証」を入れてよいか**（見える記録を、柱3の範囲内の「証拠」として扱う判断）
